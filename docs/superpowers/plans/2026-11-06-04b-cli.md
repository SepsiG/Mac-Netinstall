# Plan 4b — CLI (ni-cli) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A thin `ni-cli` binary over `ni-engine`: list interfaces, run preflight, fetch assets, manage profiles, and `flash` one or many RouterBOARDs from a terminal — human-readable progress or JSON lines, clean Ctrl-C, documented exit codes, a log file in `~/Library/Logs` — tested end to end by running the real binary against a simulated device over loopback.

**Architecture:** `clap` derive arguments (`cli.rs`), one function per command (`commands.rs`), `flash.rs` driving an `EngineHandle` and translating its event stream, `output.rs` turning `EngineEvent`s into lines, `logging.rs` installing a `tracing` file subscriber. All logic stays in `ni-engine`; the CLI only parses, prints and maps results to exit codes. Hidden flags (ports, destinations, server MAC, mirror URLs) let the integration test run `ni-cli flash` on `lo0` with unprivileged ports.

**Tech Stack:** Rust stable (MSRV 1.88), `clap` 4.6.7 (features `derive`, `env`; MSRV 1.85), `tracing` 0.1.44, `tracing-subscriber` 0.3.23 (`fmt`, `env-filter`, no default features), `tracing-appender` 0.2.5, `tokio` 1.54.1 (`signal`, `process` for tests), `serde_json` 1.0.154.

## Background (read first)

**Toolchain:** rustup's cargo first in `PATH` (`export PATH="$HOME/.cargo/bin:$PATH"` if `which cargo` is not `~/.cargo/bin/cargo`).

**Commands:**

```text
ni-cli interfaces [--all]
ni-cli preflight --iface en7 [--server-ip IP] [--pool FIRST-LAST] [--profile NAME]
ni-cli assets fetch --version stable [--arch arm64]... [--package wifi-qcom]...
ni-cli profiles list | show NAME | delete NAME
ni-cli profiles save --name NAME --version SPEC [--package P]... [--script FILE.rsc]
ni-cli flash --iface en7 (--profile NAME | --version SPEC [--package P]... [--script FILE])
             [--auto-repeat [--count N]] [--only-mac MAC] [--max-parallel N]
             [--cooldown SECS] [--retransmits N]
global: --json  --cache-dir DIR  --profiles-dir DIR  --log-dir DIR  --log-level FILTER (env NI_LOG)
```

`flash` without `--auto-repeat` flashes the first device that says hello and exits; other devices wait. With `--auto-repeat` every new device is flashed until Ctrl-C (or `--count` devices finished). `--retransmits 0` exists because same-seq de-duplication on real devices is unverified (roadmap, open hardware checks).

**Exit codes:** 0 success · 1 error (engine, network, assets, profiles) · 2 invalid arguments · 3 a device failed · 4 preflight failed · 130 interrupted (Ctrl-C before the single device finished; with `--auto-repeat` Ctrl-C is the normal end and gives 0, or 3 if a device failed).

## Design notes and deliberate choices

- **Output.** `--json` prints every engine event as one JSON object per line (the same serde format the Tauri UI will consume) plus preflight findings as `{"event":"preflight","severity":...,"code":...}`. Without it, short English lines; progress is printed in 10 % steps. Errors go to stderr as `error: <code> (<params>)`.
- **Logging.** A daily-rotated file `ni-cli.<date>.log` (7 kept) in `~/Library/Logs/io.github.sepsig.mac-netinstall/` via `tracing-appender`'s non-blocking writer; filter from `--log-level` / `NI_LOG` (default `info`). If the directory cannot be created, the CLI warns and runs without a log. The engine itself only uses `tracing` macros.
- **Ctrl-C / SIGTERM** are handled with `tokio::signal::unix`; the engine is stopped (sessions cancelled, ports released) and the remaining events are printed before exiting.
- **Testing flags** (`--server-mac`, `--bind-ip`, `--bootp-port`, `--tftp-port`, `--netinstall-port`, `--bootp-reply-to`, `--netinstall-dest`, `--download-base`, `--upgrade-base`) are hidden from `--help`. The integration tests always pass `--log-dir`, `--cache-dir` and `--profiles-dir` inside a temp dir, so they never touch `~/Library`.
- **Expected warnings in Tasks 1–4:** argument fields and exit codes are only read once the commands exist, so `cargo test` prints `never read` / `never used` dead-code warnings until Task 5. Task 6's clippy step uses `-D warnings`.
- **Every code block below was compiled and tested** in the same prototype as Plan 4a and replayed on a fresh clone; the final tree matches the prototype byte for byte.

```rust
//! `ni-cli`: MikroTik Netinstall for macOS, on the command line.
//!
//! A thin layer over `ni-engine`; see `ni-cli --help`. Exit codes are in
//! [`cli::exit`].

mod cli;

use clap::Parser;
use std::process::ExitCode;

fn main() -> ExitCode {
    let cli = match cli::Cli::try_parse() {
        Ok(cli) => cli,
        Err(e) => {
            // `--help` and `--version` are "errors" printed to stdout.
            let _ = e.print();
            let code = if e.use_stderr() {
                cli::exit::USAGE
            } else {
                cli::exit::OK
            };
            return ExitCode::from(code);
        }
    };
    eprintln!("not implemented yet: {:?}", cli.command);
    ExitCode::from(cli::exit::ERROR)
}
```

```rust
//! Command-line arguments.

use clap::{Args, Parser, Subcommand};
use ni_assets::VersionSpec;
use ni_proto::Mac;
use std::net::{Ipv4Addr, SocketAddr};
use std::path::PathBuf;

/// Exit codes (also listed in `--help`).
pub mod exit {
    /// Success.
    pub const OK: u8 = 0;
    /// Runtime error: engine, network, assets, profile store.
    pub const ERROR: u8 = 1;
    /// Invalid arguments.
    pub const USAGE: u8 = 2;
    /// At least one device failed to flash.
    pub const DEVICE_FAILED: u8 = 3;
    /// Preflight found an error (interface, addresses, ports, assets).
    pub const PREFLIGHT: u8 = 4;
    /// Interrupted (Ctrl-C) before the device was flashed.
    pub const INTERRUPTED: u8 = 130;
}

const EXIT_CODES: &str = "Exit codes: 0 success, 1 error, 2 invalid arguments, \
3 a device failed, 4 preflight failed, 130 interrupted.";

#[derive(Debug, Parser)]
#[command(
    name = "ni-cli",
    version,
    about = "MikroTik Netinstall for macOS: boot RouterBOARDs over Ethernet and install RouterOS.",
    after_help = EXIT_CODES
)]
pub struct Cli {
    /// Print results and engine events as JSON (one object per line).
    #[arg(long, global = true)]
    pub json: bool,
    /// Download cache [default: ~/Library/Caches/io.github.sepsig.mac-netinstall].
    #[arg(long, global = true, value_name = "DIR")]
    pub cache_dir: Option<PathBuf>,
    /// Profile directory [default: ~/Library/Application Support/io.github.sepsig.mac-netinstall/profiles].
    #[arg(long, global = true, value_name = "DIR")]
    pub profiles_dir: Option<PathBuf>,
    /// Log directory [default: ~/Library/Logs/io.github.sepsig.mac-netinstall].
    #[arg(long, global = true, value_name = "DIR")]
    pub log_dir: Option<PathBuf>,
    /// Log filter for the log file, e.g. `debug` or `ni_engine=trace`.
    #[arg(long, global = true, env = "NI_LOG", default_value = "info")]
    pub log_level: String,
    /// Testing: base URL replacing `https://download.mikrotik.com/routeros/`.
    #[arg(long, global = true, hide = true)]
    pub download_base: Option<String>,
    /// Testing: base URL replacing `https://upgrade.mikrotik.com/routeros`.
    #[arg(long, global = true, hide = true)]
    pub upgrade_base: Option<String>,
    #[command(subcommand)]
    pub command: Command,
}

#[derive(Debug, Subcommand)]
pub enum Command {
    /// List network interfaces with their kind and IPv4 addresses.
    Interfaces {
        /// Also list loopback, tunnel and interfaces without IPv4.
        #[arg(long)]
        all: bool,
    },
    /// Check an interface, the ports and (optionally) a profile's assets.
    Preflight {
        #[command(flatten)]
        net: NetArgs,
        /// Also check this stored profile's assets.
        #[arg(long)]
        profile: Option<String>,
    },
    /// Manage the download cache.
    Assets {
        #[command(subcommand)]
        command: AssetsCommand,
    },
    /// Manage stored profiles.
    Profiles {
        #[command(subcommand)]
        command: ProfilesCommand,
    },
    /// Serve BOOTP/TFTP/Netinstall on an interface and flash devices.
    ///
    /// Without --auto-repeat the first device that appears is flashed and
    /// the command exits. With it, every new device is flashed until
    /// Ctrl-C (or --count devices have finished).
    Flash(FlashArgs),
}

#[derive(Debug, Subcommand)]
pub enum AssetsCommand {
    /// Download (or verify cached) boot kernels and packages.
    Fetch {
        /// Channel (stable, long-term, testing, development) or version (7.25.1).
        #[arg(long)]
        version: VersionSpec,
        /// Package architecture(s) to fetch packages for (arm64, mipsbe, ...).
        #[arg(long = "arch")]
        archs: Vec<String>,
        /// Extra package(s) besides routeros.
        #[arg(long = "package")]
        packages: Vec<String>,
    },
}

#[derive(Debug, Subcommand)]
pub enum ProfilesCommand {
    /// List stored profiles.
    List,
    /// Print one profile as JSON.
    Show { name: String },
    /// Create or replace a profile.
    Save {
        #[arg(long)]
        name: String,
        #[command(flatten)]
        recipe: RecipeArgs,
    },
    /// Delete a profile.
    Delete { name: String },
}

/// What to install, given on the command line.
#[derive(Debug, Clone, Args)]
pub struct RecipeArgs {
    /// Channel (stable, long-term, testing, development) or version (7.25.1).
    #[arg(long)]
    pub version: VersionSpec,
    /// Extra package(s) besides routeros, e.g. wifi-qcom.
    #[arg(long = "package")]
    pub packages: Vec<String>,
    /// RouterOS script (.rsc) to run on first boot.
    #[arg(long)]
    pub script: Option<PathBuf>,
}

#[derive(Debug, Clone, Args)]
pub struct NetArgs {
    /// Interface the routers are connected to, e.g. en7.
    #[arg(long)]
    pub iface: String,
    /// Our IPv4 address on it [default: its first one].
    #[arg(long)]
    pub server_ip: Option<Ipv4Addr>,
    /// Address range handed out, as FIRST-LAST [default: the subnet's hosts].
    #[arg(long, value_parser = parse_pool)]
    pub pool: Option<(Ipv4Addr, Ipv4Addr)>,
    /// Testing: our Netinstall source MAC (for interfaces without one).
    #[arg(long, hide = true)]
    pub server_mac: Option<Mac>,
    /// Testing: listener address [default: 0.0.0.0].
    #[arg(long, hide = true)]
    pub bind_ip: Option<Ipv4Addr>,
    /// Testing: BOOTP port [default: 67].
    #[arg(long, hide = true)]
    pub bootp_port: Option<u16>,
    /// Testing: TFTP port [default: 69].
    #[arg(long, hide = true)]
    pub tftp_port: Option<u16>,
    /// Testing: Netinstall port [default: 5000].
    #[arg(long, hide = true)]
    pub netinstall_port: Option<u16>,
    /// Testing: BOOTP reply destination [default: 255.255.255.255:68].
    #[arg(long, hide = true)]
    pub bootp_reply_to: Option<SocketAddr>,
    /// Testing: Netinstall destination [default: 255.255.255.255:5000].
    #[arg(long, hide = true)]
    pub netinstall_dest: Option<SocketAddr>,
}

#[derive(Debug, Clone, Args)]
pub struct FlashArgs {
    #[command(flatten)]
    pub net: NetArgs,
    /// Use this stored profile.
    #[arg(long, conflicts_with_all = ["version", "packages", "script"], required_unless_present = "version")]
    pub profile: Option<String>,
    /// Channel or version to install (instead of --profile).
    #[arg(long)]
    pub version: Option<VersionSpec>,
    /// Extra package(s) besides routeros (with --version).
    #[arg(long = "package")]
    pub packages: Vec<String>,
    /// RouterOS script (.rsc) to run on first boot (with --version).
    #[arg(long)]
    pub script: Option<PathBuf>,
    /// Keep going: flash every device that appears, until Ctrl-C.
    #[arg(long)]
    pub auto_repeat: bool,
    /// With --auto-repeat: exit after this many devices finished.
    #[arg(long, requires = "auto_repeat")]
    pub count: Option<usize>,
    /// Serve only this device (MAC address).
    #[arg(long)]
    pub only_mac: Option<Mac>,
    /// Devices flashed at the same time.
    #[arg(long, default_value_t = 4, value_parser = clap::value_parser!(u16).range(1..=64))]
    pub max_parallel: u16,
    /// Seconds a finished device is ignored (it reboots).
    #[arg(long, default_value_t = 300)]
    pub cooldown: u64,
    /// Re-sends of an unanswered Netinstall frame (0 disables them; whether
    /// devices de-duplicate re-sent chunks is unverified on hardware).
    #[arg(long, default_value_t = 3)]
    pub retransmits: u32,
}

fn parse_pool(s: &str) -> Result<(Ipv4Addr, Ipv4Addr), String> {
    let (a, b) = s
        .split_once('-')
        .ok_or_else(|| "expected FIRST-LAST, e.g. 192.168.88.10-192.168.88.200".to_string())?;
    let parse = |x: &str| {
        x.trim()
            .parse::<Ipv4Addr>()
            .map_err(|e| format!("{x:?}: {e}"))
    };
    Ok((parse(a)?, parse(b)?))
}
```

```rust
//! Printing engine events: JSON lines, or short English lines for people.

use ni_engine::{DeviceState, EngineEvent, Failure, Finding, Severity, WaitReason};
use ni_proto::Mac;
use std::collections::HashMap;

/// Turns events into output lines; keeps a little state so progress is
/// printed in 10 % steps instead of for every chunk.
#[derive(Default)]
pub struct Printer {
    json: bool,
    /// Last printed progress step (0-10) per device / per download.
    devices: HashMap<Mac, (String, u64)>,
    downloads: HashMap<String, u64>,
}

fn percent(done: u64, total: u64) -> u64 {
    (done.saturating_mul(100)).checked_div(total).unwrap_or(100)
}

impl Printer {
    pub fn new(json: bool) -> Self {
        Printer {
            json,
            ..Default::default()
        }
    }

    /// The line to print for `e`, if any.
    pub fn line(&mut self, e: &EngineEvent) -> Option<String> {
        if self.json {
            return Some(serde_json::to_string(e).expect("events serialize"));
        }
        match e {
            EngineEvent::Started(s) => Some(format!(
                "serving on {} ({}), fetching boot kernels...",
                s.interface, s.server_ip
            )),
            EngineEvent::Stopped => Some("stopped".into()),
            EngineEvent::KernelsReady { version } => Some(format!(
                "boot kernels {version} ready; waiting for devices (Etherboot)"
            )),
            EngineEvent::Download { file, done, total } => {
                let total = (*total)?;
                let step = percent(*done, total) / 10;
                let last = self.downloads.insert(file.clone(), step);
                (last != Some(step) && step.is_multiple_of(5))
                    .then(|| format!("downloading {file}: {}%", step * 10))
            }
            EngineEvent::Discovered { mac, info } => Some(format!(
                "{mac}  found {} ({}), license {}",
                info.model, info.arch, info.license_id
            )),
            EngineEvent::Ignored { mac, reason } => Some(format!("{mac}  ignored: {reason}")),
            EngineEvent::Device { mac, state } => self.device(*mac, state),
            EngineEvent::Error(f) => Some(format!("error: {}", failure(f))),
            EngineEvent::Warning(f) => Some(format!("warning: {}", failure(f))),
        }
    }

    fn device(&mut self, mac: Mac, state: &DeviceState) -> Option<String> {
        let text = match state {
            DeviceState::BootpSeen { boot_arch, ip } => {
                format!("booting ({boot_arch}), address {ip}")
            }
            DeviceState::KernelServing { sent, total } => {
                let step = percent(*sent, *total) / 10;
                let key = ("kernel".to_string(), step);
                if self.devices.get(&mac) == Some(&key) {
                    return None;
                }
                self.devices.insert(mac, key);
                format!("sending boot kernel: {}%", step * 10)
            }
            DeviceState::Discovered => return None,
            DeviceState::Waiting {
                reason: WaitReason::NoProfile,
            } => "waiting (no profile)".into(),
            DeviceState::Waiting {
                reason: WaitReason::Concurrency,
            } => "waiting for a free slot".into(),
            DeviceState::Preparing => "preparing packages".into(),
            DeviceState::Flashing { phase, sent, total } => {
                let step = percent(*sent, *total) / 10;
                let key = (phase.clone(), step);
                if self.devices.get(&mac) == Some(&key) {
                    return None;
                }
                self.devices.insert(mac, key);
                if phase == "uploading" {
                    format!("uploading: {}%", step * 10)
                } else {
                    phase.clone()
                }
            }
            DeviceState::Done => "done, rebooting".into(),
            DeviceState::Failed { code, params } => {
                let f = Failure {
                    code: code.clone(),
                    params: params.clone(),
                };
                format!("FAILED: {f}")
            }
        };
        Some(format!("{mac}  {text}"))
    }
}

/// What to do about some failures, for people.
pub fn hint(code: &str) -> Option<&'static str> {
    match code {
        "port_in_use" => Some(
            "another DHCP/TFTP/netinstall server is running (Internet Sharing's bootpd?); stop it first",
        ),
        "no_ipv4" => Some("give the interface a static IPv4 address in System Settings > Network"),
        "unsuitable_interface" => Some("RouterBOARDs boot over wired Ethernet only"),
        _ => None,
    }
}

/// A failure for people: `code (params)`, plus a hint if there is one.
pub fn failure(f: &Failure) -> String {
    match hint(&f.code) {
        Some(h) => format!("{f}\n  hint: {h}"),
        None => f.to_string(),
    }
}

/// A preflight finding for people.
pub fn finding(f: &Finding) -> String {
    let level = match f.severity {
        Severity::Error => "error",
        Severity::Warning => "warning",
    };
    format!("{level}: {}", failure(&f.failure))
}
```

```rust
//! `tracing` to a daily log file in `~/Library/Logs/<bundle id>/`.
//!
//! The terminal shows engine events (see `output`), not log lines; the
//! log file is for diagnosis and is what a bug report should attach.

use ni_assets::BUNDLE_ID;
use std::path::{Path, PathBuf};
use tracing_appender::non_blocking::WorkerGuard;
use tracing_appender::rolling::{RollingFileAppender, Rotation};
use tracing_subscriber::layer::SubscriberExt;
use tracing_subscriber::util::SubscriberInitExt;
use tracing_subscriber::EnvFilter;

/// Log files kept (one per day).
pub const KEEP_FILES: usize = 7;

/// `~/Library/Logs/io.github.sepsig.mac-netinstall`, or `None` without `HOME`.
pub fn default_log_dir() -> Option<PathBuf> {
    let home = std::env::var_os("HOME").filter(|h| !h.is_empty())?;
    Some(PathBuf::from(home).join("Library/Logs").join(BUNDLE_ID))
}

/// Log to `<dir>/ni-cli.<date>.log` with `filter` (an `EnvFilter`
/// directive such as `info` or `ni_engine=debug`). Keep the guard alive
/// until exit, or the last lines are lost. On failure (bad filter,
/// unwritable directory) nothing is logged and the reason is returned.
pub fn init(dir: &Path, filter: &str) -> Result<WorkerGuard, String> {
    let filter = EnvFilter::try_new(filter).map_err(|e| format!("invalid log filter: {e}"))?;
    std::fs::create_dir_all(dir).map_err(|e| format!("{}: {e}", dir.display()))?;
    let appender = RollingFileAppender::builder()
        .rotation(Rotation::DAILY)
        .filename_prefix("ni-cli")
        .filename_suffix("log")
        .max_log_files(KEEP_FILES)
        .build(dir)
        .map_err(|e| format!("{}: {e}", dir.display()))?;
    let (writer, guard) = tracing_appender::non_blocking(appender);
    tracing_subscriber::registry()
        .with(filter)
        .with(
            tracing_subscriber::fmt::layer()
                .with_writer(writer)
                .with_ansi(false),
        )
        .try_init()
        .map_err(|e| e.to_string())?;
    Ok(guard)
}
```

```rust
//! The `ni-cli` binary: arguments, exit codes, and (Task 5) a real `flash`
//! run against a simulated RouterBOARD over loopback.

use ni_assets::testutil::{tempdir, TempDir};
use serde_json::Value;
use std::process::Stdio;
use std::time::Duration;
use tokio::process::Command;

const WAIT: Duration = Duration::from_secs(20);

/// Temp dirs for cache, profiles and logs: tests never touch `~/Library`.
struct Env {
    dir: TempDir,
}

impl Env {
    fn new(tag: &str) -> Env {
        Env { dir: tempdir(tag) }
    }

    fn cmd(&self, args: &[&str]) -> Command {
        let mut c = Command::new(env!("CARGO_BIN_EXE_ni-cli"));
        let d = |sub: &str| self.dir.join(sub).display().to_string();
        c.args(["--log-dir", &d("logs"), "--cache-dir", &d("cache")])
            .args(["--profiles-dir", &d("profiles")])
            .args(args)
            .env_remove("NI_LOG")
            .stdin(Stdio::null())
            .stdout(Stdio::piped())
            .stderr(Stdio::piped())
            .kill_on_drop(true);
        c
    }

    async fn run(&self, args: &[&str]) -> (i32, String, String) {
        let out = tokio::time::timeout(WAIT, self.cmd(args).output())
            .await
            .expect("ni-cli finished")
            .unwrap();
        (
            out.status.code().unwrap_or(-1),
            String::from_utf8_lossy(&out.stdout).into_owned(),
            String::from_utf8_lossy(&out.stderr).into_owned(),
        )
    }

    /// Everything written to the log directory.
    fn logs(&self) -> String {
        let mut text = String::new();
        for entry in std::fs::read_dir(self.dir.join("logs")).unwrap().flatten() {
            text += &std::fs::read_to_string(entry.path()).unwrap();
        }
        text
    }
}
```

```rust
//! `ni-cli`: MikroTik Netinstall for macOS, on the command line.
//!
//! A thin layer over `ni-engine`; see `ni-cli --help`. Exit codes are in
//! [`cli::exit`].

mod cli;
mod commands;
mod logging;
mod output;

use clap::Parser;
use std::process::ExitCode;

fn main() -> ExitCode {
    let cli = match cli::Cli::try_parse() {
        Ok(cli) => cli,
        Err(e) => {
            // `--help` and `--version` are "errors" printed to stdout.
            let _ = e.print();
            let code = if e.use_stderr() {
                cli::exit::USAGE
            } else {
                cli::exit::OK
            };
            return ExitCode::from(code);
        }
    };
    let _log_guard = cli
        .log_dir
        .clone()
        .or_else(logging::default_log_dir)
        .and_then(|dir| match logging::init(&dir, &cli.log_level) {
            Ok(guard) => Some(guard),
            Err(e) => {
                eprintln!("warning: logging disabled: {e}");
                None
            }
        });
    tracing::info!(version = env!("CARGO_PKG_VERSION"), "ni-cli started");
    let runtime = match tokio::runtime::Runtime::new() {
        Ok(rt) => rt,
        Err(e) => {
            eprintln!("error: cannot start the async runtime: {e}");
            return ExitCode::from(cli::exit::ERROR);
        }
    };
    let code = match runtime.block_on(commands::run(cli)) {
        Ok(code) => code,
        Err(f) => {
            tracing::error!("{f}");
            eprintln!("error: {}", output::failure(&f));
            cli::exit::ERROR
        }
    };
    ExitCode::from(code)
}
```

```rust
use crate::cli::{exit, AssetsCommand, Cli, Command, NetArgs, ProfilesCommand, RecipeArgs};

/// An exit code, or an error (printed, exit code 1).
pub type Outcome = Result<u8, Failure>;

/// Settings shared by all commands.
pub struct Ctx {
    pub json: bool,
    pub cache_dir: PathBuf,
    pub profiles: ProfileStore,
    pub http: HttpConfig,
}

impl Ctx {
    pub fn new(cli: &Cli) -> Result<Ctx, Failure> {
        let no_home = || Failure::new("no_home");
        let cache_dir = match &cli.cache_dir {
            Some(d) => d.clone(),
            None => default_cache_root().ok_or_else(no_home)?,
        };
        let profiles = match &cli.profiles_dir {
            Some(d) => d.clone(),
            None => default_profiles_root().ok_or_else(no_home)?,
        };
        let mut http = HttpConfig::default();
        if let Some(b) = &cli.download_base {
            http.download_base = b.clone();
        }
        if let Some(b) = &cli.upgrade_base {
            http.upgrade_base = b.clone();
        }
        Ok(Ctx {
            json: cli.json,
            cache_dir,
            profiles: ProfileStore::new(profiles),
            http,
        })
    }

    /// An asset manager; in human mode downloads are reported on stderr.
    pub fn assets(&self) -> Result<Assets, Failure> {
        let assets = Assets::new(&self.cache_dir, self.http.clone())
            .map_err(|e| Failure::new("assets_failed").with("detail", e))?;
        if self.json {
            return Ok(assets);
        }
        Ok(assets.with_events(Arc::new(|e| match e {
            AssetEvent::DownloadStarted { file, total } => match total {
                Some(t) => eprintln!("downloading {file} ({t} bytes)"),
                None => eprintln!("downloading {file}"),
            },
            AssetEvent::DownloadFinished { file, .. } => eprintln!("downloaded {file}"),
            _ => {}
        })))
    }
}

pub async fn run(cli: Cli) -> Outcome {
    let ctx = Ctx::new(&cli)?;
    match cli.command {
        Command::Interfaces { all } => interfaces(&ctx, all),
        Command::Preflight { net, profile } => preflight(&ctx, &net, profile.as_deref()).await,
        Command::Assets {
            command:
                AssetsCommand::Fetch {
                    version,
                    archs,
                    packages,
                },
        } => fetch(&ctx, &version, &archs, &packages).await,
        Command::Profiles { command } => profiles(&ctx, command).await,
        Command::Flash(_) => Err(Failure::new("not_implemented")),
    }
}

    cfg.pool = net.pool;
    cfg.server_mac = net.server_mac;

fn interfaces(ctx: &Ctx, all: bool) -> Outcome {
    let list =
        list_interfaces().map_err(|e| Failure::new("interface_list_failed").with("detail", e))?;
    let shown: Vec<&Interface> = list
        .iter()
        .filter(|i| {
            all || (!i.ipv4.is_empty()
                && matches!(i.kind, InterfaceKind::Ethernet | InterfaceKind::WiFi))
        })
        .collect();
    let addrs = |i: &Interface| -> Vec<String> {
        i.ipv4
            .iter()
            .map(|(ip, mask)| format!("{ip}/{}", u32::from(*mask).leading_ones()))
            .collect()
    };
    if ctx.json {
        let v: Vec<_> = shown
            .iter()
            .map(|i| {
                json!({
                    "name": i.name,
                    "kind": i.kind.as_str(),
                    "display_name": i.display_name,
                    "mac": i.mac.map(|m| m.to_string()),
                    "ipv4": addrs(i),
                    "up": i.is_up,
                    "running": i.is_running,
                })
            })
            .collect();
        print_json(&v);
        return Ok(exit::OK);
    }
    for i in shown {
        let state = match (i.is_up, i.is_running) {
            (true, true) => "up",
            (true, false) => "no link",
            _ => "down",
        };
        let ips = addrs(i).join(", ");
        let name = i.display_name.as_deref().unwrap_or("");
        println!(
            "{:<10} {:<14} {:<8} {:<20} {name}",
            i.name,
            i.kind.as_str(),
            state,
            if ips.is_empty() { "-" } else { &ips }
        );
    }
    Ok(exit::OK)
}

/// Print a report; the exit code is 4 if it has errors.
pub fn print_report(ctx: &Ctx, report: &PreflightReport) -> u8 {
    for f in &report.findings {
        if ctx.json {
            let mut v = serde_json::to_value(f).expect("serializable");
            v["event"] = json!("preflight");
            print_json(&v);
        } else {
            println!("{}", finding(f));
        }
    }
    if report.ok() {
        exit::OK
    } else {
        exit::PREFLIGHT
    }
}

async fn preflight(ctx: &Ctx, net: &NetArgs, profile: Option<&str>) -> Outcome {
    let cfg = engine_config(net);
    let profile = profile.map(|name| ctx.profiles.load(name)).transpose()?;
    let assets = match profile {
        Some(_) => Some(ctx.assets()?),
        None => None,
    };
    let report = preflight::run(&cfg, assets.as_ref(), profile.as_ref()).await;
    let code = print_report(ctx, &report);
    if !ctx.json {
        if let Some(n) = &report.network {
            println!(
                "server {} / {}, pool {} - {}, MAC {}",
                n.server_ip, n.netmask, n.pool_start, n.pool_end, n.server_mac
            );
        }
        println!(
            "{}",
            if code == exit::OK {
                "preflight passed"
            } else {
                "preflight FAILED"
            }
        );
    }
    Ok(code)
}

fn asset_err(e: ni_assets::AssetError) -> Failure {
    Failure::new("assets_failed")
        .with("cause", e.code())
        .with("detail", e)
}

async fn fetch(ctx: &Ctx, spec: &VersionSpec, archs: &[String], extras: &[String]) -> Outcome {
    let assets = ctx.assets()?;
    let version = assets.resolve(spec).await.map_err(asset_err)?;
    let kernels = assets.ensure_kernels(&version).await.map_err(asset_err)?;
    let mut kernel_archs: Vec<&str> = kernels.keys().map(|a| a.as_str()).collect();
    kernel_archs.sort();
    let mut packages = Vec::new();
    for arch in archs {
        let pkg_arch = PkgArch::from_device_arch(arch).map_err(|e| asset_err(e.into()))?;
        let files = assets
            .ensure_packages(&version, pkg_arch, extras)
            .await
            .map_err(asset_err)?;
        packages.push((pkg_arch, files));
    }
    if ctx.json {
        let pkgs: Vec<_> = packages
            .iter()
            .map(|(arch, files)| {
                let files: Vec<_> = files
                    .iter()
                    .map(|f| json!({"name": f.name, "size": f.data.len()}))
                    .collect();
                json!({"arch": arch.as_str(), "files": files})
            })
            .collect();
        print_json(
            &json!({"version": version.as_str(), "kernels": kernel_archs, "packages": pkgs}),
        );
    } else {
        println!("{version}: boot kernels for {}", kernel_archs.join(", "));
        for (arch, files) in &packages {
            for f in files {
                println!("{arch}: {} ({} bytes)", f.name, f.data.len());
            }
        }
    }
    Ok(exit::OK)
}

/// A profile from command-line arguments. A script is registered in the
/// cache (as its lowercase file name) first.
pub async fn recipe_profile(
    assets: &Assets,
    name: &str,
    recipe: &RecipeArgs,
) -> Result<Profile, Failure> {
    let mut p = Profile::new(name, recipe.version.clone());
    p.extra_packages = recipe.packages.clone();
    if let Some(script) = &recipe.script {
        let local = register_script(assets, script).await?;
        p.config = ConfigMode::CustomScript { local_name: local };
    }
    p.validate()?;
    Ok(p)
}

async fn register_script(assets: &Assets, path: &Path) -> Result<String, Failure> {
    let local = assets.register_local_file(path).await.map_err(|e| {
        Failure::new("script_failed")
            .with("path", path.display())
            .with("cause", e.code())
            .with("detail", e)
    })?;
    Ok(local.name)
}

fn config_text(c: &ConfigMode) -> String {
    match c {
        ConfigMode::Default => "default config".into(),
        ConfigMode::CustomScript { local_name } => format!("script {local_name}"),
    }
}

async fn profiles(ctx: &Ctx, command: ProfilesCommand) -> Outcome {
    match command {
        ProfilesCommand::List => {
            let listing = ctx.profiles.list();
            for (path, f) in &listing.broken {
                eprintln!("warning: {}: {f}", path.display());
            }
            if ctx.json {
                print_json(&listing.profiles);
            } else if listing.profiles.is_empty() {
                println!("no profiles in {}", ctx.profiles.root().display());
            } else {
                for p in &listing.profiles {
                    let mut packages = vec!["routeros".to_string()];
                    packages.extend(p.extra_packages.iter().cloned());
                    println!(
                        "{:<24} {:<10} {:<30} {}",
                        p.name,
                        spec_to_string(&p.version),
                        packages.join(","),
                        config_text(&p.config)
                    );
                }
            }
        }
        ProfilesCommand::Show { name } => {
            let p = ctx.profiles.load(&name)?;
            println!(
                "{}",
                serde_json::to_string_pretty(&p).expect("serializable")
            );
        }
        ProfilesCommand::Save { name, recipe } => {
            let assets = ctx.assets()?;
            let p = recipe_profile(&assets, &name, &recipe).await?;
            ctx.profiles.save(&p)?;
            if ctx.json {
                print_json(&p);
            } else {
                println!("saved profile {}", p.name);
            }
        }
        ProfilesCommand::Delete { name } => {
            ctx.profiles.delete(&name)?;
            if !ctx.json {
                println!("deleted profile {name}");
            }
        }
    }
    Ok(exit::OK)
}
```

```rust
/// The next JSON line on `lines` matching `pred`.
async fn json_line(
    lines: &mut Lines<BufReader<ChildStdout>>,
    pred: impl Fn(&Value) -> bool,
) -> Value {
    let end = tokio::time::Instant::now() + WAIT;
    loop {
        let line = tokio::time::timeout_at(end, lines.next_line())
            .await
            .expect("expected line in time")
            .unwrap()
            .expect("stdout still open");
        let v: Value = serde_json::from_str(&line).unwrap_or_else(|e| panic!("{line}: {e}"));
        if pred(&v) {
            return v;
        }
    }
}
```

```rust
//! `flash`: preflight, start the engine, print events, stop cleanly.

use crate::cli::{exit, FlashArgs, RecipeArgs};
use crate::commands::{engine_config, print_report, recipe_profile, Ctx, Outcome};
use crate::output::Printer;
use ni_engine::{preflight, DeviceState, EngineEvent, EngineHandle, Failure};
use ni_proto::Mac;
use std::time::Duration;
use tokio::signal::unix::{signal, SignalKind};
use tokio::sync::broadcast::error::RecvError;
use tracing::info;

/// How a run ended.
#[derive(Debug, Default)]
struct Tally {
    done: usize,
    failed: usize,
}

pub async fn flash(ctx: &Ctx, args: FlashArgs) -> Outcome {
    let engine = EngineHandle::spawn(&ctx.cache_dir, ctx.http.clone())?;
    let profile = match (&args.profile, &args.version) {
        (Some(name), _) => ctx.profiles.load(name)?,
        (None, Some(version)) => {
            let recipe = RecipeArgs {
                version: version.clone(),
                packages: args.packages.clone(),
                script: args.script.clone(),
            };
            recipe_profile(engine.assets(), "command-line", &recipe).await?
        }
        (None, None) => return Err(Failure::new("no_profile")),
    };
    let mut cfg = engine_config(&args.net);
    cfg.profile = Some(profile.clone());
    cfg.auto_repeat = args.auto_repeat;
    cfg.only_mac = args.only_mac;
    cfg.max_parallel = usize::from(args.max_parallel);
    cfg.cooldown = Duration::from_secs(args.cooldown);
    cfg.session.max_retransmits = args.retransmits;

    let report = preflight::run(&cfg, Some(engine.assets()), Some(&profile)).await;
    let code = print_report(ctx, &report);
    if code != exit::OK {
        return Ok(code);
    }

    let mut printer = Printer::new(ctx.json);
    let mut events = engine.subscribe();
    let started = engine.start(cfg).await?;
    info!(?started, profile = %profile.name, "flash started");
    let mut interrupt = signal(SignalKind::interrupt()).map_err(signal_failure)?;
    let mut terminate = signal(SignalKind::terminate()).map_err(signal_failure)?;
    let mut target: Option<Mac> = None;
    let mut tally = Tally::default();
    let code = loop {
        let event = tokio::select! {
            _ = interrupt.recv() => break interrupted(&args, &tally),
            _ = terminate.recv() => break interrupted(&args, &tally),
            e = events.recv() => e,
        };
        let event = match event {
            Ok(e) => e,
            Err(RecvError::Lagged(n)) => {
                eprintln!("warning: {n} events skipped");
                continue;
            }
            Err(RecvError::Closed) => return Err(Failure::new("engine_gone")),
        };
        if let Some(line) = printer.line(&event) {
            println!("{line}");
        }
        match &event {
            EngineEvent::Discovered { mac, .. } if !args.auto_repeat && target.is_none() => {
                target = Some(*mac);
                engine.flash(*mac, profile.clone()).await?;
            }
            EngineEvent::Device { mac, state } => {
                let finished = match state {
                    DeviceState::Done => {
                        tally.done += 1;
                        true
                    }
                    DeviceState::Failed { .. } => {
                        tally.failed += 1;
                        true
                    }
                    _ => false,
                };
                if !finished {
                    continue;
                }
                if !args.auto_repeat && target == Some(*mac) {
                    break result(&tally);
                }
                if args.count.is_some_and(|n| tally.done + tally.failed >= n) {
                    break result(&tally);
                }
            }
            EngineEvent::Error(f) => {
                let _ = engine.stop().await;
                return Err(f.clone());
            }
            _ => {}
        }
    };
    let _ = engine.stop().await;
    while let Ok(e) = events.try_recv() {
        if let Some(line) = printer.line(&e) {
            println!("{line}");
        }
    }
    info!(
        done = tally.done,
        failed = tally.failed,
        code,
        "flash finished"
    );
    Ok(code)
}

fn signal_failure(e: std::io::Error) -> Failure {
    Failure::new("signal_failed").with("detail", e)
}

fn result(tally: &Tally) -> u8 {
    if tally.failed > 0 {
        exit::DEVICE_FAILED
    } else {
        exit::OK
    }
}

/// Ctrl-C: the normal way to end auto-repeat; before the one device of a
/// single run is finished, an interruption.
fn interrupted(args: &FlashArgs, tally: &Tally) -> u8 {
    if args.auto_repeat {
        result(tally)
    } else {
        exit::INTERRUPTED
    }
}
```

```rust
//! `ni-cli`: MikroTik Netinstall for macOS, on the command line.
//!
//! A thin layer over `ni-engine`; see `ni-cli --help`. Exit codes are in
//! [`cli::exit`].

mod cli;
mod commands;
mod flash;
mod logging;
mod output;

use clap::Parser;
use std::process::ExitCode;

fn main() -> ExitCode {
    let cli = match cli::Cli::try_parse() {
        Ok(cli) => cli,
        Err(e) => {
            // `--help` and `--version` are "errors" printed to stdout.
            let _ = e.print();
            let code = if e.use_stderr() {
                cli::exit::USAGE
            } else {
                cli::exit::OK
            };
            return ExitCode::from(code);
        }
    };
    let _log_guard = cli
        .log_dir
        .clone()
        .or_else(logging::default_log_dir)
        .and_then(|dir| match logging::init(&dir, &cli.log_level) {
            Ok(guard) => Some(guard),
            Err(e) => {
                eprintln!("warning: logging disabled: {e}");
                None
            }
        });
    tracing::info!(version = env!("CARGO_PKG_VERSION"), "ni-cli started");
    let runtime = match tokio::runtime::Runtime::new() {
        Ok(rt) => rt,
        Err(e) => {
            eprintln!("error: cannot start the async runtime: {e}");
            return ExitCode::from(cli::exit::ERROR);
        }
    };
    let code = match runtime.block_on(commands::run(cli)) {
        Ok(code) => code,
        Err(f) => {
            tracing::error!("{f}");
            eprintln!("error: {}", output::failure(&f));
            cli::exit::ERROR
        }
    };
    ExitCode::from(code)
}
```
