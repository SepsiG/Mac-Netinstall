# Plan 6a — GUI API in the engine + Tauri bridge Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give `ni-engine` the runtime controls and state the GUI needs (active profile switch with kernel re-selection, only-MAC, concurrency limit, cooldown, per-device cancel/forget, kernel state and per-device timestamps in the snapshot, a catalog of every code), and add the Tauri 2 app crate `app/src-tauri` — a thin, window-less-testable bridge (commands, settings, event forwarding, close confirmation) with a locked-down bundle configuration.

**Architecture:** The engine keeps its one-owner loop; new commands are more `Command` variants with oneshot replies, and the kernel fetch moves into the loop so it can be redone while running (a generation counter drops superseded fetches). The app crate is a library (`mac_netinstall_app`) plus a tiny binary: `core::AppCore` holds the engine handle, the profile store and the settings and implements every command as a plain async method, so `tests/bridge.rs` drives it on `lo0` against simulated RouterBOARDs exactly like ni-engine's own tests; `commands.rs` only wraps those methods as `#[tauri::command]`s. Engine events go to the window as Tauri events with the engine's JSON (codes + params, never text). Plan 6b builds the Svelte frontend on top.

**Tech Stack:** Rust stable (rustup, edition 2021; workspace MSRV 1.88, the app crate 1.90), Tauri 2.12.5 (`tauri-build` 2.7.4, `tauri-plugin-dialog` 2.8.4), `core-foundation` 0.10.1 (preferred languages), `tracing-appender` / `tracing-subscriber` (as in ni-cli), tokio 1.54.1, serde. Node 26 + npm 11 only to generate the icons with `npx @tauri-apps/cli@2.12.4` (nothing installed globally).

## Background (read first)

**Toolchain:** `export PATH="$HOME/.cargo/bin:$PATH"` so rustup's cargo comes first (see Plan 1 Task 0). The Tauri CLI is *not* installed globally: Plan 6a uses `npx --yes @tauri-apps/cli@2.12.4` once (icons); Plan 6b adds it as a devDependency.

**What the engine already offers** (`crates/ni-engine/src/engine/mod.rs`): `EngineHandle::{spawn, subscribe, assets, start, stop, flash, retry, set_auto_repeat, snapshot}`; events (`EngineEvent`, JSON tagged by `event`) and errors (`Failure { code, params }`); `ProfileStore`; `preflight::run`. The engine loop (`engine/core.rs`) owns all state; commands arrive through an mpsc channel with a oneshot reply each.

**Testing without hardware or a window:** ni-engine's tests run a real engine on `lo0` with ephemeral ports (`Ports`), a fake MikroTik mirror (`ni_assets::testutil`, feature `testing`) and simulated RouterBOARDs (`ni_sim::lan::SimLan`, feature `lan`). The app's bridge tests reuse the same pieces through `AppCore::with_config_hook`, which adjusts every `EngineConfig` the app builds (ports, server MAC, fast session timeouts).

**How a Tauri 2 app is put together here:**

```text
app/
  src-tauri/            Rust crate `mac-netinstall` (lib `mac_netinstall_app` + bin)
    build.rs            tauri_build + AppManifest: one `allow-<command>` permission per command
    tauri.conf.json     product, bundle id, window, CSP, bundle targets, macOS 13.0
    Info.plist          merged into the bundle's Info.plist (NSLocalNetworkUsageDescription)
    capabilities/       what the window may call (only our commands + event listen)
    icons/              generated PNGs
  src/lib/codes.json    code catalog exported for the frontend's translation tests
  dist/                 the built frontend (Plan 6b; a debug build does not need it)
```

## Design notes and deliberate choices

- **Kernel re-selection.** `set_active_profile` with a different version spec withdraws the served kernels (empty BOOTP boot-file map → devices are `ignored`/`no_boot_file`; empty TFTP map) before fetching the new ones, so no device boots a kernel of a version it will not get. Same spec → nothing is refetched. Devices queued by auto-repeat take the new profile; devices given one with `flash` keep theirs.
- **Per-device kernel version.** A device that netbooted keeps the kernel it booted; `flash` and preparation compare the profile's version with `Device::kernel` (set at its BOOTP reply), falling back to the served version for devices first seen by their hello. Without this a profile switch would make every already-booted device fail.
- **Kernel state** is a new `kernels` event plus a snapshot field; the old `kernels_ready` event and the `kernels_unavailable` error stay (ni-cli prints them). Download progress for the snapshot comes from the asset hook, forwarded to the loop with `try_send` (dropped if the loop is behind — the next one carries a newer count).
- **Cancel semantics.** Preparing/flashing → `failed`/`cancelled` (no cooldown; `retry` works), queued → back to `waiting`/`no_profile` (profile cleared), anything else → `not_cancellable` with the `state`. The UI confirms every cancel (Plan 6b).
- **Code catalog instead of hand-kept lists.** `ni_engine::codes` and `AssetError::CODES` are checked against the sources by tests; `app/src/lib/codes.json` is generated from them and checked by `tests/codes.rs`, so the frontend's translation tests cannot drift.
- **Security.** The window gets only `allow-<our command>` and `core:event:allow-listen/unlisten`. File dialogs (pick a `.rsc`, save the log) run in Rust through `tauri-plugin-dialog`'s Rust API, so the dialog plugin needs no JS permission and the web view never receives a path. Errors drop `path` parameters (`views::without_paths`); the cache location is only shown as `~/…` text. CSP: `default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; …; object-src 'none'` (Svelte's `style:` directives need inline styles; no `unsafe-eval`).
- **Settings** are the app's (not the engine's): JSON in Application Support next to `profiles/`, atomic writes, defaults on a broken file. A changed download timeout needs a new `Assets` (and so a new engine task); `AppCore` replaces the idle engine before the next start/preflight and the forwarder follows it through a `watch` channel.
- **Close confirmation** is decided in Rust (no window permission needed): `CloseRequested` and `RunEvent::ExitRequested` are prevented unless the `CloseGuard` is open; with no active device the app exits at once, otherwise the window gets `close-requested` and calls `quit` when the user confirms.
- **Deviation: app crate MSRV 1.90.** Tauri 2.12 requires Rust 1.90; the library crates keep MSRV 1.88.
- **Deviation: no `.icns` in the repo.** `tauri icon` writes a different `.icns` on every run, so only the PNGs are committed and the bundler builds the `.icns`.
- **Every code block below was compiled and tested** in a prototype before this plan was written, and the plan was replayed on a fresh clone of `feat/gui`; the resulting tree matches the prototype (build outputs and `node_modules` aside).

```rust
//! Runtime control for the GUI: kernel state, snapshot details, and
//! changing settings while running.

mod common;

use common::*;
use ni_engine::{EngineEvent, EngineHandle, KernelState};
use std::time::{SystemTime, UNIX_EPOCH};

fn now_ms() -> u64 {
    SystemTime::now()
        .duration_since(UNIX_EPOCH)
        .unwrap()
        .as_millis() as u64
}

/// The kernel states reported until (and including) the first one that is
/// not `downloading`.
async fn kernel_states(
    events: &mut tokio::sync::broadcast::Receiver<EngineEvent>,
) -> Vec<KernelState> {
    let mut out = Vec::new();
    loop {
        let e = next(events, |e| matches!(e, EngineEvent::Kernels { .. })).await;
        let EngineEvent::Kernels { state } = e else {
            unreachable!()
        };
        let done = state.name() != "downloading";
        out.push(state);
        if done {
            return out;
        }
    }
}

#[tokio::test(flavor = "multi_thread", worker_threads = 2)]
async fn kernel_state_goes_from_downloading_to_ready() {
    let srv = ni_assets::testutil::TestServer::start().await;
    ni_assets::testutil::mirror(&srv);
    let cache = ni_assets::testutil::tempdir("control-kernels");
    let engine = EngineHandle::spawn(cache.join("cache"), http(&srv)).unwrap();
    assert_eq!(engine.snapshot().await.unwrap().kernels, KernelState::Idle);
    let mut events = engine.subscribe();
    let lan = ni_sim::lan::SimLan::bind().await.unwrap();
    engine.start(config(&lan)).await.unwrap();
    let states = kernel_states(&mut events).await;
    assert_eq!(
        states.first(),
        Some(&KernelState::Downloading {
            spec: "stable".into(),
            done: 0,
            total: None
        })
    );
    assert_eq!(
        states.last(),
        Some(&KernelState::Ready {
            version: "7.25.1".into(),
            offline: false
        })
    );
    let snap = engine.snapshot().await.unwrap();
    assert_eq!(snap.kernels, *states.last().unwrap());
    assert_eq!(snap.kernel_version.as_deref(), Some("7.25.1"));
    assert_eq!((snap.max_parallel, snap.cooldown_secs), (4, 300));
    assert_eq!((snap.only_mac, snap.link_down), (None, None));
    engine.stop().await.unwrap();
    assert_eq!(engine.snapshot().await.unwrap().kernels, KernelState::Idle);
}

#[tokio::test(flavor = "multi_thread", worker_threads = 2)]
async fn without_kernels_the_snapshot_says_unavailable() {
    let cache = ni_assets::testutil::tempdir("control-nokernels");
    let engine = EngineHandle::spawn(cache.join("cache"), offline_http()).unwrap();
    let mut events = engine.subscribe();
    let lan = ni_sim::lan::SimLan::bind().await.unwrap();
    engine.start(config(&lan)).await.unwrap();
    let states = kernel_states(&mut events).await;
    let last = states.last().unwrap();
    assert_eq!(last.name(), "unavailable");
    let KernelState::Unavailable { code, params } = last else {

    assert_eq!(params.get("cause").map(String::as_str), Some("network"));
    let snap = engine.snapshot().await.unwrap();
    assert!(snap.running, "running, but serving no kernels");
    assert_eq!(snap.kernel_version, None);
    assert_eq!(snap.kernels, *last);
}
```

```rust
//! sessions (one per device MAC) and the BOOTP/TFTP runner tasks.

//! Commands go in through an [`EngineHandle`] (an mpsc channel); events

/// Asset downloads as engine events (cache hits are not reported).
fn download_event(e: AssetEvent) -> Option<EngineEvent> {
    match e {
        AssetEvent::DownloadStarted { file, total } => Some(EngineEvent::Download {
            file,
            done: 0,
            total,
        }),
        AssetEvent::DownloadProgress { file, done, total } => {
            Some(EngineEvent::Download { file, done, total })
        }
        AssetEvent::DownloadFinished { file, size } => Some(EngineEvent::Download {
            file,
            done: size,
            total: Some(size),
        }),
        AssetEvent::CacheHit { .. } => None,
    }
}

/// The `netinstall-<version>.tar.gz` download carries the boot kernels.
fn is_kernel_tarball(file: &str) -> bool {
    file.starts_with("netinstall-") && file.ends_with(".tar.gz")
}

impl EngineHandle {
    /// Create the asset cache at `cache_root` and spawn the engine task
    /// (idle until [`EngineHandle::start`]). Must be called inside a tokio
    /// runtime. Error: `assets_failed`.
    pub fn spawn(cache_root: impl Into<PathBuf>, http: HttpConfig) -> Result<Self, Failure> {
        let (events, _) = broadcast::channel(EVENT_CAPACITY);
        let weak = events.downgrade();
        let sink = weak.clone();
        let (internal, internal_rx) = mpsc::channel(64);
        let progress = internal.clone();
        let assets = Assets::new(cache_root, http)
            .map_err(|e| asset_failure("assets_failed", &e))?
            .with_events(Arc::new(move |e| {
                let Some(ev) = download_event(e) else { return };
                if let EngineEvent::Download { file, done, total } = &ev {
                    if is_kernel_tarball(file) {
                        // Dropped if the engine is behind; the next one
                        // carries the newer count anyway.
                        let _ = progress.try_send(core::Internal::Download {
                            file: file.clone(),
                            done: *done,
                            total: *total,
                        });
                    }
                }
                if let Some(tx) = sink.upgrade() {
                    let _ = tx.send(ev);
                }
            }));
        let assets = Arc::new(assets);
        let (cmds, rx) = mpsc::channel(32);
        tokio::spawn(core::run(
            assets.clone(),
            events,
            rx,
            (internal, internal_rx),
        ));
        Ok(EngineHandle {
            cmds,
            events: weak,
            assets,
        })
    }

    /// Events from now on. If the engine task has ended, the receiver
    /// reports `RecvError::Closed` at once.
    pub fn subscribe(&self) -> broadcast::Receiver<EngineEvent> {
        match self.events.upgrade() {
            Some(tx) => tx.subscribe(),
            None => broadcast::channel(1).1,
        }
    }

    /// The engine's asset manager (for preflight, registering scripts, ...).
    pub fn assets(&self) -> &Arc<Assets> {
        &self.assets
    }

    async fn call<T>(
        &self,
        make: impl FnOnce(oneshot::Sender<T>) -> Command,
    ) -> Result<T, Failure> {
        let (tx, rx) = oneshot::channel();
        self.cmds.send(make(tx)).await.map_err(|_| gone())?;
        rx.await.map_err(|_| gone())
    }

    /// Bind the listeners and start serving. Boot kernels are fetched in
    /// the background ([`EngineEvent::KernelsReady`]). With a configured
    /// server IP this works while the interface has no link (reported as
    /// a `link_down` warning right after `started`). Errors:
    /// `already_running`, `invalid_cooldown`, profile validation codes,
    /// `interface_list_failed`, network codes from
    /// [`crate::resolve_network`] (incl. `pool_includes_reserved`),
    /// `invalid_network`, `port_in_use`, `bind_failed`.
    pub async fn start(&self, cfg: EngineConfig) -> Result<StartInfo, Failure> {
        self.call(|tx| Command::Start(Box::new(cfg), tx)).await?
    }

    /// Cancel all sessions and release the ports. Error: `not_running`.
    pub async fn stop(&self) -> Result<(), Failure> {
        self.call(Command::Stop).await?
    }

    /// Install `profile` on a device. A device that has not said hello yet
    /// keeps the profile for when it does. A device already waiting for a
    /// slot keeps its place in the queue. Errors: `not_running`,
    /// `unknown_device`, `device_busy`, `device_done`, profile validation,
    /// `profile_version_mismatch` (`version`, `kernel_version`): an exact
    /// version other than the boot kernels' (the device already runs the
    /// kernel it was served, so it cannot install another version); a
    /// channel is checked once resolved, and the device fails with that
    /// code.
    pub async fn flash(&self, mac: Mac, profile: Profile) -> Result<(), Failure> {
        self.call(|tx| Command::Flash(mac, Box::new(profile), tx))
            .await?
    }

    /// Re-arm a failed device. Errors: `not_running`, `unknown_device`,
    /// `not_failed`. (A failed device that netboots again is reset by its
    /// BOOTP request and, with auto-repeat or an assigned profile, flashed
    /// again without `retry`.)
    pub async fn retry(&self, mac: Mac) -> Result<(), Failure> {
        self.call(|tx| Command::Retry(mac, tx)).await?
    }

    /// With auto-repeat on, waiting devices get the active profile. Turning
    /// it off takes devices that wait for a slot only because of it (no
    /// profile assigned with `flash`) out of the queue (`waiting` /
    /// `no_profile`). Errors: `not_running`, `no_profile` (turning it on
    /// without one).
    pub async fn set_auto_repeat(&self, on: bool) -> Result<(), Failure> {
        self.call(|tx| Command::AutoRepeat(on, tx)).await?
    }

    pub async fn snapshot(&self) -> Result<Snapshot, Failure> {
        self.call(Command::Snapshot).await
    }
}
```

Changing the profile in the GUI while serving. A profile whose version spec differs from the one the kernels were fetched for withdraws the served kernels (empty BOOTP boot-file map and TFTP file map) and fetches new ones; the snapshot says `downloading` meanwhile. Each device now remembers the kernel version it booted (`Device::kernel`, set from its BOOTP reply), and `flash` / preparation check the profile against *that* version — a device that booted 7.25.1 can still be installed with 7.25.1 after the active profile moved to 7.24.6. `None` clears the profile and turns auto-repeat off. The test mirror serves a second version (7.24.6) with a slow tarball so the switch is observable.

```rust
/// A profile installing exactly `version` (plus `wireless`).
fn exact(name: &str, version: &str) -> Profile {
    let mut p = Profile::new(name, VersionSpec::Exact(Version::parse(version).unwrap()));
    p.extra_packages = vec!["wireless".into()];
    p
}

#[tokio::test(flavor = "multi_thread", worker_threads = 2)]
async fn a_new_active_version_withdraws_and_refetches_the_kernels() {
    let mut rig = rig(|_| {}).await;
    // 7.24.6 exists too; its tarball arrives slowly, so the switch is
    // observable.
    mirror_version(&rig.srv, "7.24.6");
    rig.srv.route(
        "/dl/7.24.6/netinstall-7.24.6.tar.gz",
        Reply::Slow {
            body: netinstall_tarball(),
            chunk: 64 * 1024,
            delay: Duration::from_millis(150),
        },
    );
    rig.engine
        .set_active_profile(Some(exact("old", "7.24.6")))
        .await
        .unwrap();
    let e = next(&mut rig.events, |e| {
        matches!(e, EngineEvent::Kernels { .. })
    })
    .await;
    assert_eq!(
        e,
        EngineEvent::Kernels {
            state: KernelState::Downloading {
                spec: "7.24.6".into(),
                done: 0,
                total: None
            }
        }
    );
    // Running, but no kernels: a netbooting device gets no boot file.
    let snap = rig.engine.snapshot().await.unwrap();
    assert!(snap.running);
    assert_eq!(snap.kernel_version, None);
    assert_eq!(snap.kernels.name(), "downloading");
    assert_eq!(snap.profile.as_deref(), Some("old"));
    let reply = rig
        .lan
        .boot(
            A,
            "ARM64__boot",
            rig.started.bootp,
            Duration::from_millis(300),
        )
        .await;
    assert_eq!(reply, None);
    let states = kernel_states(&mut rig.events).await;
    assert!(
        states
            .iter()
            .any(|s| matches!(s, KernelState::Downloading { done, .. } if *done > 0)),
        "download progress is reported: {states:?}"
    );
    assert_eq!(
        states.last(),
        Some(&KernelState::Ready {
            version: "7.24.6".into(),
            offline: false
        })
    );
    // Now A boots and gets 7.24.6.
    let sim = boot(&rig, A, sim_config(A)).await;
    rig.lan.add(sim).await;
    let e = state(&mut rig.events, A, "flashing").await;
    let EngineEvent::Device {
        state: DeviceState::Flashing { version, .. },
        ..
    } = e
    else {
        unreachable!()
    };
    assert_eq!(version, "7.24.6");
    state(&mut rig.events, A, "done").await;
}

async fn a_device_keeps_the_kernel_version_it_booted() {
    let mut rig = rig(|cfg| cfg.auto_repeat = false).await;
    mirror_version(&rig.srv, "7.24.6");
    let sim = boot(&rig, A, sim_config(A)).await; // boots 7.25.1 kernels
    rig.lan.add(sim).await;
    state(&mut rig.events, A, "waiting").await;
    rig.engine
        .set_active_profile(Some(exact("old", "7.24.6")))
        .await
        .unwrap();
    next(&mut rig.events, |e| {
        matches!(e, EngineEvent::KernelsReady { .. })
    })
    .await;
    let err = rig
        .engine
        .flash(A, exact("old", "7.24.6"))
        .await
        .unwrap_err();

        (err.code.as_str(), err.param("kernel_version")),
        ("profile_version_mismatch", Some("7.25.1"))

    rig.engine.flash(A, exact("new", "7.25.1")).await.unwrap();
    state(&mut rig.events, A, "done").await;
    let snap = rig.engine.snapshot().await.unwrap();
    assert_eq!(snap.devices[0].version.as_deref(), Some("7.25.1"));
    assert_eq!(snap.kernel_version.as_deref(), Some("7.24.6"));
```

```rust
    fn cancel(&mut self, mac: Mac) -> Result<(), Failure> {
        let run = self.running()?;
        let dev = run
            .devices
            .get_mut(&mac)
            .ok_or_else(|| Failure::new("unknown_device").with("mac", mac))?;
        if dev.is_active() {
            // A preparation still running is dropped when it reports back
            // (the device is no longer `preparing`).
            if let Some(mut session) = dev.session.take() {
                session.cancel();

            warn!(%mac, "install cancelled");
            self.set_state(mac, DeviceState::failed(Failure::new("cancelled")));
            return Ok(());

        if dev.queued.is_some() {

        let run = self.running()?;
        let dev = run

        run.devices.remove(&mac);
        run.gate.clear_cooldown(mac);
```

```js
// Draws the app icon source (1024x1024 PNG) without any image library:
// a blue rounded square with a white "install" glyph (an arrow into a
// tray). `npx tauri icon app-icon.png` turns it into the bundle icons.
// Usage: node scripts/make-icon.mjs app-icon.png
import { writeFileSync } from "node:fs";
import { deflateSync } from "node:zlib";

const N = 1024;
const px = new Uint8Array(N * N * 4);

// Signed distance to a rounded box centred at (cx, cy).
function roundBox(x, y, cx, cy, hw, hh, r) {
  const qx = Math.abs(x - cx) - hw + r;
  const qy = Math.abs(y - cy) - hh + r;
  const ox = Math.max(qx, 0);
  const oy = Math.max(qy, 0);
  return Math.hypot(ox, oy) + Math.min(Math.max(qx, qy), 0) - r;
}

// Distance to the segment (ax, ay)-(bx, by).
function segment(x, y, ax, ay, bx, by) {
  const dx = bx - ax;
  const dy = by - ay;
  const t = Math.max(0, Math.min(1, ((x - ax) * dx + (y - ay) * dy) / (dx * dx + dy * dy)));
  return Math.hypot(x - ax - t * dx, y - ay - t * dy);
}

const cover = (d) => Math.max(0, Math.min(1, 0.5 - d)); // 1 px anti-aliasing

for (let y = 0; y < N; y++) {
  for (let x = 0; x < N; x++) {
    const i = (y * N + x) * 4;
    const bg = cover(roundBox(x + 0.5, y + 0.5, 512, 512, 412, 412, 92));
    if (bg === 0) continue;
    // Vertical gradient #2D7FF9 -> #0B4FC2.
    const t = y / N;
    let r = 0x2d + (0x0b - 0x2d) * t;
    let g = 0x7f + (0x4f - 0x7f) * t;
    let b = 0xf9 + (0xc2 - 0xf9) * t;
    const p = [x + 0.5, y + 0.5];
    const w = 34; // half stroke width
    const glyph = Math.min(
      segment(...p, 512, 250, 512, 590) - w, // arrow shaft
      segment(...p, 512, 600, 392, 480) - w, // arrow head, left
      segment(...p, 512, 600, 632, 480) - w, // arrow head, right
      segment(...p, 300, 640, 300, 760) - w, // tray, left
      segment(...p, 300, 760, 724, 760) - w, // tray, bottom
      segment(...p, 724, 760, 724, 640) - w, // tray, right
    );
    const a = cover(glyph);
    r += (255 - r) * a;
    g += (255 - g) * a;
    b += (255 - b) * a;
    px[i] = Math.round(r);
    px[i + 1] = Math.round(g);

function crc32(buf) {
  let c = ~0;
  for (const byte of buf) {
    c ^= byte;
    for (let k = 0; k < 8; k++) c = c & 1 ? (c >>> 1) ^ 0xedb88320 : c >>> 1;
  }
  return ~c >>> 0;
}

function chunk(type, data) {
  const head = Buffer.alloc(8);
  head.writeUInt32BE(data.length, 0);
  head.write(type, 4, "ascii");
  const crc = Buffer.alloc(4);
  crc.writeUInt32BE(crc32(Buffer.concat([head.subarray(4), data])), 0);
  return Buffer.concat([head, data, crc]);
}
```

```rust
use ni_engine::{check_cooldown, check_max_parallel, Failure, MIN_COOLDOWN};
use serde::{Deserialize, Serialize};
use std::io::Write;
use std::net::Ipv4Addr;
use std::path::{Path, PathBuf};
use std::time::Duration;

/// Languages the UI is translated to.
pub const LANGUAGES: &[&str] = &["en", "hu"];
/// Shortest download timeout accepted (seconds).
pub const MIN_DOWNLOAD_TIMEOUT: u64 = 60;
/// Longest download timeout accepted (seconds; a day).
pub const MAX_DOWNLOAD_TIMEOUT: u64 = 24 * 60 * 60;

/// What the app remembers between runs. Missing fields take their
/// defaults, so older files keep working.
#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
#[serde(default)]
pub struct Settings {
    /// `"en"` or `"hu"`; `None` follows the macOS language.
    pub language: Option<String>,
    pub last_interface: Option<String>,
    /// Also list Wi-Fi, bridges, tunnels, ... in the interface picker.
    pub show_all_interfaces: bool,
    /// Server IP to use while the interface has no address (no cable
    /// yet); default: the interface's address.
    pub server_ip: Option<Ipv4Addr>,
    pub netmask: Option<Ipv4Addr>,
    /// BOOTP pool (both or neither); default: the subnet.
    pub pool_start: Option<Ipv4Addr>,
    pub pool_end: Option<Ipv4Addr>,
    pub max_parallel: usize,
    pub cooldown_secs: u64,
    pub auto_repeat: bool,
    pub last_profile: Option<String>,
    /// Longest time one download may take.
    pub download_timeout_secs: u64,
}

impl Default for Settings {
    fn default() -> Self {
        Settings {
            language: None,
            last_interface: None,
            show_all_interfaces: false,
            server_ip: None,
            netmask: None,
            pool_start: None,
            pool_end: None,
            max_parallel: 4,
            cooldown_secs: 300,
            auto_repeat: false,
            last_profile: None,
            download_timeout_secs: 30 * 60,
        }
    }
}

fn invalid(field: &str) -> Failure {
    Failure::new("invalid_setting").with("field", field)
}

impl Settings {
    /// Codes: `invalid_setting` (`field`, and `min` / `max` where
    /// bounded), `invalid_max_parallel`, `invalid_cooldown`.
    pub fn validate(&self) -> Result<(), Failure> {
        if let Some(lang) = &self.language {
            if !LANGUAGES.contains(&lang.as_str()) {
                return Err(invalid("language"));
            }
        }
        if let Some(mask) = self.netmask {
            let m = u32::from(mask);
            if m.leading_ones() + m.trailing_zeros() != 32 || m.leading_ones() < 8 {
                return Err(invalid("netmask"));
            }
        }
        match (self.pool_start, self.pool_end) {
            (None, None) => {}
            (Some(a), Some(b)) if u32::from(a) <= u32::from(b) => {}
            _ => return Err(invalid("pool")),
        }
        check_max_parallel(self.max_parallel)?;
        check_cooldown(Duration::from_secs(self.cooldown_secs), MIN_COOLDOWN)?;
        if !(MIN_DOWNLOAD_TIMEOUT..=MAX_DOWNLOAD_TIMEOUT).contains(&self.download_timeout_secs) {
            return Err(invalid("download_timeout")
                .with("min", MIN_DOWNLOAD_TIMEOUT)
                .with("max", MAX_DOWNLOAD_TIMEOUT));
        }
        Ok(())
    }

    pub fn download_timeout(&self) -> Duration {
        Duration::from_secs(self.download_timeout_secs)
    }
}

/// `settings.json` in a directory.
#[derive(Debug, Clone)]
pub struct SettingsStore {
    path: PathBuf,
}

fn io_failure(op: &str, e: std::io::Error) -> Failure {
    Failure::new("settings_io").with("op", op).with("detail", e)
}

impl SettingsStore {
    pub fn new(path: impl Into<PathBuf>) -> Self {
        SettingsStore { path: path.into() }
    }

    pub fn path(&self) -> &Path {
        &self.path
    }

    /// The stored settings; defaults if there is no file, or if it cannot
    /// be read or parsed (a broken file must not lock the user out; it is
    /// replaced on the next save).
    pub fn load(&self) -> Settings {
        let Ok(data) = std::fs::read(&self.path) else {
            return Settings::default();
        };
        match serde_json::from_slice::<Settings>(&data) {
            Ok(s) if s.validate().is_ok() => s,
            Ok(_) | Err(_) => {
                tracing::warn!(path = %self.path.display(), "ignoring invalid settings file");
                Settings::default()
            }
        }
    }

    /// Validate and write: a temporary file next to it, flushed to disk,
    /// then renamed over the old one (never a half-written file).
    pub fn save(&self, settings: &Settings) -> Result<(), Failure> {
        settings.validate()?;
        let dir = self.path.parent().unwrap_or(Path::new("."));
        std::fs::create_dir_all(dir).map_err(|e| io_failure("mkdir", e))?;
        let mut json = serde_json::to_vec_pretty(settings).expect("settings serialize");
        json.push(b'\n');
        let tmp = self
            .path
            .with_extension(format!("json.{}.tmp", std::process::id()));
        let write = || -> std::io::Result<()> {
            let mut f = std::fs::File::create(&tmp)?;
            f.write_all(&json)?;
            f.sync_all()
        };
        write().map_err(|e| {
            let _ = std::fs::remove_file(&tmp);
            io_failure("write", e)
        })?;
        std::fs::rename(&tmp, &self.path).map_err(|e| {
            let _ = std::fs::remove_file(&tmp);
            io_failure("rename", e)
        })
    }
}
```

```rust
//! Engine events → the window, across engine replacements.

use ni_engine::{EngineEvent, EngineHandle};
use tokio::sync::broadcast::error::RecvError;
use tokio::sync::watch;

/// Tauri event carrying an [`EngineEvent`] (the engine's JSON).
pub const ENGINE_EVENT: &str = "engine-event";
/// Tauri event telling the window it missed events (payload: how many;
/// 0 when the engine task was replaced): it should reload the snapshot.
pub const ENGINE_LAGGED: &str = "engine-lagged";
/// Tauri event asking the window to confirm quitting while devices are
/// being prepared or flashed (payload: how many).
pub const CLOSE_REQUESTED: &str = "close-requested";

/// What the forwarder passes on.
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Forwarded {
    Event(EngineEvent),
    Lagged(u64),
}

/// Pass every event of the current engine task to `emit`, following
/// replacements; returns when the engine watch is closed.
pub async fn forward_events(
    mut engines: watch::Receiver<EngineHandle>,
    emit: impl Fn(Forwarded) + Send,
) {
    loop {
        let mut events = engines.borrow_and_update().subscribe();
        loop {
            tokio::select! {
                r = events.recv() => match r {
                    Ok(e) => emit(Forwarded::Event(e)),
                    Err(RecvError::Lagged(n)) => emit(Forwarded::Lagged(n)),
                    Err(RecvError::Closed) => {
                        // This task ended; wait for its replacement.
                        if engines.changed().await.is_err() {
                            return;
                        }
                        emit(Forwarded::Lagged(0));
                        break;
                    }
                },
                changed = engines.changed() => {
                    if changed.is_err() {
                        return;
                    }
                    emit(Forwarded::Lagged(0));
                    break;
                }
            }
        }
    }
}
```

```rust
async fn next(rig: &mut Rig, pred: impl Fn(&Forwarded) -> bool) -> Forwarded {
    let end = tokio::time::Instant::now() + WAIT;
    loop {
        match tokio::time::timeout_at(end, rig.events.recv()).await {
            Ok(Some(f)) if pred(&f) => return f,
            Ok(Some(_)) => {}
            Ok(None) => panic!("forwarder ended"),
            Err(_) => panic!("no matching event within {WAIT:?}"),
        }
    }
}

    .await;
```

```rust
/// Where the app keeps its files.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Paths {
    /// Downloads (`~/Library/Caches/<bundle id>`).
    pub cache: PathBuf,
    /// Profiles (`~/Library/Application Support/<bundle id>/profiles`).
    pub profiles: PathBuf,
    /// `~/Library/Application Support/<bundle id>/settings.json`.
    pub settings: PathBuf,
}

impl Paths {
    /// The standard locations; `no_home` without `HOME`.
    pub fn for_user() -> Result<Paths, Failure> {
        let (Some(cache), Some(profiles)) = (default_cache_root(), default_profiles_root()) else {
            return Err(Failure::new("no_home"));
        };
        let settings = profiles.parent().map_or_else(
            || PathBuf::from("settings.json"),
            |p| p.join("settings.json"),
        );
        Ok(Paths {
            cache,
            profiles,
            settings,
        })
    }

    /// Everything under `root` (tests).
    pub fn under(root: &Path) -> Paths {
        Paths {
            cache: root.join("cache"),
            profiles: root.join("profiles"),
            settings: root.join("settings.json"),
        }
    }
}

/// `invalid_mac` (`mac`) unless `s` is a MAC address.
pub fn parse_mac(s: &str) -> Result<Mac, Failure> {
    s.parse()
        .map_err(|_| Failure::new("invalid_mac").with("mac", s))

/// The interfaces, for the picker. Error: `interface_list_failed`.
pub fn list_interfaces() -> Result<Vec<InterfaceView>, Failure> {
    let ifaces = ni_net::list_interfaces()
        .map_err(|e| Failure::new("interface_list_failed").with("detail", e))?;
    let routed = ni_net::default_route_interfaces().unwrap_or_default();
    Ok(ifaces
        .iter()
        .map(|i| InterfaceView::new(i, &routed))
        .collect())
}

/// `path` with the home folder shown as `~`.
pub fn display_path(path: &Path) -> String {
    let home = std::env::var_os("HOME").map(PathBuf::from);
    match home.as_deref().and_then(|h| path.strip_prefix(h).ok()) {
        Some(rest) => format!("~/{}", rest.display()),
        None => path.display().to_string(),
    }
}

/// Total size of the regular files under `dir` (0 if it is missing).
fn dir_size(dir: &Path) -> u64 {
    let mut total = 0;
    let mut stack = vec![dir.to_path_buf()];
    while let Some(d) = stack.pop() {
        for entry in std::fs::read_dir(&d).into_iter().flatten().flatten() {
            match entry.file_type() {
                Ok(t) if t.is_dir() => stack.push(entry.path()),
                Ok(t) if t.is_file() => total += entry.metadata().map_or(0, |m| m.len()),
                _ => {}
            }
        }
    }
    total
}

fn asset_cause(code: &str, e: &AssetError) -> Failure {
    Failure::new(code).with("cause", e.code())
}

/// The app's state behind the commands.
pub struct AppCore {
    paths: Paths,
    http: HttpConfig,
    engine: watch::Sender<EngineHandle>,
    /// Download timeout of the running engine task's asset manager.
    engine_timeout: Mutex<Duration>,
    profiles: ProfileStore,
    store: SettingsStore,
    settings: Mutex<Settings>,
    hook: Option<ConfigHook>,
}

fn lock<T>(m: &Mutex<T>) -> MutexGuard<'_, T> {
    m.lock().unwrap_or_else(PoisonError::into_inner)
}

impl AppCore {
    /// Load the settings and spawn the engine (inside a tokio runtime).
    /// `http` gives the mirror; its download timeout comes from the
    /// settings. Error: `assets_failed`.
    pub fn new(paths: Paths, http: HttpConfig) -> Result<AppCore, Failure> {
        let store = SettingsStore::new(&paths.settings);
        let settings = store.load();
        let timeout = settings.download_timeout();
        let engine = EngineHandle::spawn(
            &paths.cache,
            HttpConfig {
                download_timeout: timeout,
                ..http.clone()
            },
        )?;
        Ok(AppCore {
            profiles: ProfileStore::new(&paths.profiles),
            paths,
            http,
            engine: watch::Sender::new(engine),
            engine_timeout: Mutex::new(timeout),
            store,
            settings: Mutex::new(settings),
            hook: None,
        })
    }

    /// Apply `hook` to every engine configuration (tests).
    pub fn with_config_hook(mut self, hook: ConfigHook) -> Self {
        self.hook = Some(hook);
        self
    }

    /// The current engine task.
    pub fn engine(&self) -> EngineHandle {
        self.engine.borrow().clone()
    }

    /// Follows engine replacements (a new download timeout needs a new
    /// engine task); the event forwarder re-subscribes on each change.
    pub fn watch_engine(&self) -> watch::Receiver<EngineHandle> {
        self.engine.subscribe()
    }

    pub fn paths(&self) -> &Paths {
        &self.paths
    }

    // ------------------------------------------------------------ settings

    pub fn settings(&self) -> Settings {
        lock(&self.settings).clone()
    }

    /// Validate, store and apply settings. While running, the concurrency
    /// limit and the cooldown take effect at once; a new download timeout
    /// applies from the next start.
    pub async fn set_settings(&self, s: Settings) -> Result<Settings, Failure> {
        self.store.save(&s)?;
        *lock(&self.settings) = s.clone();
        let engine = self.engine();
        if engine.snapshot().await?.running {
            engine.set_max_parallel(s.max_parallel).await?;
            engine
                .set_cooldown(Duration::from_secs(s.cooldown_secs))
                .await?;
        }
        Ok(s)
    }

    /// Change a few fields and store them; a failure to store is only
    /// logged (remembering the last interface must not fail a start).
    fn remember(&self, change: impl FnOnce(&mut Settings)) {
        let mut s = lock(&self.settings);
        change(&mut s);
        if let Err(f) = self.store.save(&s) {
            tracing::warn!("cannot store settings: {f}");
        }
    }

    /// Replace the engine task if the download timeout changed and it is
    /// not running.
    async fn ensure_engine(&self) -> Result<EngineHandle, Failure> {
        let wanted = self.settings().download_timeout();
        let engine = self.engine();
        if *lock(&self.engine_timeout) == wanted || engine.snapshot().await?.running {
            return Ok(engine);
        }
        let fresh = EngineHandle::spawn(
            &self.paths.cache,
            HttpConfig {
                download_timeout: wanted,
                ..self.http.clone()
            },
        )?;
        *lock(&self.engine_timeout) = wanted;
        self.engine.send_replace(fresh.clone());
        tracing::info!(
            secs = wanted.as_secs(),
            "engine restarted for a new download timeout"
        );
        Ok(fresh)
    }

    // ------------------------------------------------------------ engine

    fn load_profile(&self, name: &str) -> Result<Profile, Failure> {
        self.profiles.load(name).map_err(without_paths)
    }

    /// The engine configuration for `req` and the current settings.
    pub fn engine_config(&self, req: &StartRequest) -> Result<EngineConfig, Failure> {
        let s = self.settings();
        let mut cfg = EngineConfig::new(&req.interface);
        cfg.server_ip = s.server_ip;
        cfg.netmask = s.netmask;
        cfg.pool = s.pool_start.zip(s.pool_end);
        cfg.max_parallel = s.max_parallel;
        cfg.cooldown = Duration::from_secs(s.cooldown_secs);
        cfg.profile = req
            .profile
            .as_deref()
            .map(|n| self.load_profile(n))
            .transpose()?;
        cfg.auto_repeat = req.auto_repeat;
        if let Some(hook) = &self.hook {
            hook(&mut cfg);
        }
        Ok(cfg)
    }

    /// Run the preflight checks for `req`.
    pub async fn preflight(&self, req: &StartRequest) -> Result<PreflightReport, Failure> {
        let cfg = self.engine_config(req)?;
        let engine = self.ensure_engine().await?;
        Ok(preflight::run(&cfg, Some(engine.assets()), cfg.profile.as_ref()).await)
    }

    /// Start serving; remembers the interface, profile and auto-repeat.
    pub async fn start(&self, req: &StartRequest) -> Result<StartInfo, Failure> {
        let cfg = self.engine_config(req)?;
        let engine = self.ensure_engine().await?;
        let info = engine.start(cfg).await?;
        self.remember(|s| {
            s.last_interface = Some(req.interface.clone());
            s.last_profile = req.profile.clone();
            s.auto_repeat = req.auto_repeat;
        });
        Ok(info)
    }

    pub async fn stop(&self) -> Result<(), Failure> {
        self.engine().stop().await
    }

    pub async fn snapshot(&self) -> Result<Snapshot, Failure> {
        self.engine().snapshot().await
    }

    pub async fn flash(&self, mac: &str, profile: &str) -> Result<(), Failure> {
        let mac = parse_mac(mac)?;
        let profile = self.load_profile(profile)?;
        self.engine().flash(mac, profile).await
    }

    pub async fn retry(&self, mac: &str) -> Result<(), Failure> {
        self.engine().retry(parse_mac(mac)?).await
    }

    pub async fn cancel(&self, mac: &str) -> Result<(), Failure> {
        self.engine().cancel(parse_mac(mac)?).await
    }

    pub async fn forget(&self, mac: &str) -> Result<(), Failure> {
        self.engine().forget(parse_mac(mac)?).await
    }

    pub async fn set_auto_repeat(&self, on: bool) -> Result<(), Failure> {
        self.engine().set_auto_repeat(on).await?;
        self.remember(|s| s.auto_repeat = on);
        Ok(())
    }

    /// Change the active profile by name (`None`: none).
    pub async fn set_active_profile(&self, name: Option<&str>) -> Result<(), Failure> {
        let profile = name.map(|n| self.load_profile(n)).transpose()?;
        self.engine().set_active_profile(profile).await?;
        self.remember(|s| s.last_profile = name.map(String::from));
        Ok(())
    }

    pub async fn set_only_mac(&self, mac: Option<&str>) -> Result<(), Failure> {
        let mac = mac.map(parse_mac).transpose()?;
        self.engine().set_only_mac(mac).await
    }

    pub async fn set_max_parallel(&self, n: usize) -> Result<(), Failure> {
        self.engine().set_max_parallel(n).await?;
        self.remember(|s| s.max_parallel = n);
        Ok(())
    }

    pub async fn set_cooldown(&self, secs: u64) -> Result<(), Failure> {
        self.engine()
            .set_cooldown(Duration::from_secs(secs))
            .await?;
        self.remember(|s| s.cooldown_secs = secs);
        Ok(())
    }

    // ------------------------------------------------------------ profiles

    pub fn list_profiles(&self) -> ProfilesView {
        let listing = self.profiles.list();
        ProfilesView {
            profiles: listing.profiles,
            broken: listing
                .broken
                .into_iter()
                .map(|(path, f)| BrokenProfile {
                    file: path
                        .file_name()
                        .map(|n| n.to_string_lossy().into_owned())
                        .unwrap_or_default(),
                    code: f.code,
                })
                .collect(),
        }
    }

    fn profile_exists(&self, name: &str) -> bool {
        !matches!(self.profiles.load(name), Err(f) if f.code == "profile_not_found")
    }

    /// Store `profile`; `previous` is its name before editing (`None` for a
    /// new one). Errors: profile validation codes, `profile_exists`
    /// (`name`; another profile has that name), `profile_io`.
    pub fn save_profile(&self, profile: &Profile, previous: Option<&str>) -> Result<(), Failure> {
        profile.validate()?;
        let same = |a: &str, b: &str| a.to_lowercase() == b.to_lowercase();
        let renamed = previous.filter(|p| !same(p, &profile.name));
        if (previous.is_none() || renamed.is_some()) && self.profile_exists(&profile.name) {
            return Err(Failure::new("profile_exists").with("name", &profile.name));
        }
        self.profiles.save(profile).map_err(without_paths)?;
        if let Some(old) = renamed {
            match self.profiles.delete(old) {
                Ok(()) => {}
                Err(f) if f.code == "profile_not_found" => {}
                Err(f) => return Err(without_paths(f)),
            }
            if self.settings().last_profile.as_deref() == Some(old) {
                self.remember(|s| s.last_profile = Some(profile.name.clone()));
            }
        }
        Ok(())
    }

    pub fn delete_profile(&self, name: &str) -> Result<(), Failure> {
        self.profiles.delete(name).map_err(without_paths)?;
        if self.settings().last_profile.as_deref() == Some(name) {
            self.remember(|s| s.last_profile = None);
        }
        Ok(())
    }

    /// Extra packages of `version` (a channel or a version) for `arch`.
    /// Error: `packages_unavailable` (`cause`: an asset error code).
    pub async fn available_packages(
        &self,
        version: &str,
        arch: &str,
    ) -> Result<PackagesView, Failure> {
        let fail = |e: AssetError| asset_cause("packages_unavailable", &e);
        let spec: VersionSpec = version.parse().map_err(|e| fail(AssetError::from(e)))?;
        let pkg_arch = PkgArch::from_device_arch(arch).map_err(|e| fail(e.into()))?;
        let engine = self.engine();
        let assets = engine.assets();
        let resolved = assets.resolve(&spec).await.map_err(fail)?;
        let packages = assets
            .available_packages(&resolved, pkg_arch)
            .await
            .map_err(fail)?;
        Ok(PackagesView {
            version: resolved.to_string(),
            arch: pkg_arch.as_str().to_string(),
            packages,
        })
    }

    /// Register a picked `.rsc` file. Errors: `not_a_script` (`name`),
    /// `script_failed` (`cause`).
    pub async fn register_script(&self, path: &Path) -> Result<ScriptView, Failure> {
        let name = path
            .file_name()
            .map(|n| n.to_string_lossy().into_owned())
            .unwrap_or_default();
        if !name.to_lowercase().ends_with(".rsc") {
            return Err(Failure::new("not_a_script").with("name", name));
        }
        let file = self
            .engine()
            .assets()
            .register_local_file(path)
            .await
            .map_err(|e| asset_cause("script_failed", &e))?;
        debug_assert_eq!(file.kind, LocalKind::Script);
        Ok(ScriptView {
            name: file.name,
            size: file.size,
        })
    }

    // ------------------------------------------------------------ cache, log

    pub async fn cache_info(&self) -> CacheInfo {
        let root = self.paths.cache.clone();
        let bytes = tokio::task::spawn_blocking(move || dir_size(&root))
            .await
            .unwrap_or(0);
        CacheInfo {
            location: display_path(&self.paths.cache),
            bytes,
        }
    }

    /// Delete downloaded versions (registered scripts are kept). Errors:
    /// `engine_running`, `cache_failed` (`cause`).
    pub async fn clear_cache(&self) -> Result<(), Failure> {
        let engine = self.engine();
        if engine.snapshot().await?.running {
            return Err(Failure::new("engine_running"));
        }
        engine
            .assets()
            .clear_downloads()
            .await
            .map_err(|e| asset_cause("cache_failed", &e))
    }

    /// Write the log text the window collected. Error: `log_io`.
    pub fn write_log(&self, path: &Path, text: &str) -> Result<(), Failure> {
        std::fs::write(path, text).map_err(|e| Failure::new("log_io").with("detail", e))
    }
}
```

The `#[tauri::command]` wrappers (snake_case argument names, `Failure` as the error type), with the file dialogs run in Rust (`tauri-plugin-dialog`'s `DialogExt`, callback + oneshot) so the web view never sees a path. `run()` wires the dialog plugin, `AppCore`, the event forwarder (`engine-event`, `engine-lagged`) and the close guard: closing the window or quitting (`RunEvent::ExitRequested`) while a device is prepared or flashed emits `close-requested` with the count instead, and the window calls `quit` once confirmed. `main.rs` adds a hidden `--list-interfaces` flag that prints what the (signed) app sees — the MAC-masking check of Plan 6b Task 11.

```rust
pub async fn pick_script(app: AppHandle, core: State<'_, AppCore>) -> R<Option<ScriptView>> {
    let (tx, rx) = oneshot::channel();
    app.dialog()
        .file()
        .add_filter("RouterOS script", &["rsc"])
        .pick_file(move |file| {
            let _ = tx.send(file);

    let Some(file) = rx.await.map_err(|_| Failure::new("dialog_failed"))? else {
        return Ok(None);

    let path = file
        .into_path()

    core.register_script(&path).await.map(Some)
```

```rust
pub mod views;

use crate::core::{AppCore, Paths};
use crate::forward::{forward_events, Forwarded, CLOSE_REQUESTED, ENGINE_EVENT, ENGINE_LAGGED};
use ni_assets::HttpConfig;
use std::sync::atomic::{AtomicBool, Ordering};
use tauri::{AppHandle, Emitter, Manager, RunEvent, WindowEvent};

/// Set once quitting is confirmed (or nothing is being flashed), so the
/// close and exit handlers let it through.
#[derive(Debug, Default)]
pub struct CloseGuard(AtomicBool);

impl CloseGuard {
    pub fn allow(&self) {
        self.0.store(true, Ordering::SeqCst);
    }

    pub fn allowed(&self) -> bool {
        self.0.load(Ordering::SeqCst)
    }
}

/// Quit at once if no device is being prepared or flashed; otherwise ask
/// the window (`close-requested`), which calls `quit` when confirmed.
async fn request_close(app: AppHandle) {
    let busy = match app.state::<AppCore>().snapshot().await {
        Ok(s) => s.devices.iter().filter(|d| d.state.is_active()).count(),
        Err(_) => 0,
    };
    if busy == 0 {
        app.state::<CloseGuard>().allow();
        app.exit(0);
    } else {
        let _ = app.emit(CLOSE_REQUESTED, busy);
    }
}

/// Run the app (blocks until it quits).
pub fn run() {
    let filter = std::env::var("NI_LOG").unwrap_or_else(|_| "info".into());
    let _log = logging::default_log_dir().and_then(|dir| logging::init(&dir, &filter).ok());
    tracing::info!(
        version = env!("CARGO_PKG_VERSION"),
        "Mac Netinstall started"
    );
    let app = tauri::Builder::default()
        .plugin(tauri_plugin_dialog::init())
        .setup(|app| {
            let paths = Paths::for_user()?;
            let core = tauri::async_runtime::block_on(async {
                AppCore::new(paths, HttpConfig::default())
            })?;
            let engines = core.watch_engine();
            app.manage(core);
            app.manage(CloseGuard::default());
            let handle = app.handle().clone();
            tauri::async_runtime::spawn(forward_events(engines, move |f| {
                let _ = match f {
                    Forwarded::Event(e) => handle.emit(ENGINE_EVENT, e),
                    Forwarded::Lagged(n) => handle.emit(ENGINE_LAGGED, n),
                };
            }));
            Ok(())
        })
        .on_window_event(|window, event| {
            if let WindowEvent::CloseRequested { api, .. } = event {
                let app = window.app_handle();
                if !app.state::<CloseGuard>().allowed() {
                    api.prevent_close();
                    tauri::async_runtime::spawn(request_close(app.clone()));
                }
            }
        })
        .invoke_handler(tauri::generate_handler![
            commands::list_interfaces,
            commands::preflight,
            commands::start,
            commands::stop,
            commands::flash,
            commands::retry,
            commands::cancel,
            commands::forget,
            commands::set_auto_repeat,
            commands::set_active_profile,
            commands::set_only_mac,
            commands::set_max_parallel,
            commands::set_cooldown,
            commands::snapshot,
            commands::list_profiles,
            commands::save_profile,
            commands::delete_profile,
            commands::available_packages,
            commands::pick_script,
            commands::get_settings,
            commands::set_settings,
            commands::cache_info,
            commands::clear_cache,
            commands::export_log,
            commands::preferred_languages,
            commands::quit,
        ])
        .build(tauri::generate_context!())
        .expect("cannot build the Tauri app");
    app.run(|app, event| {
        // Cmd-Q and the menu's Quit: same rule as closing the window.
        if let RunEvent::ExitRequested { api, .. } = event {
            if !app.state::<CloseGuard>().allowed() {
                api.prevent_exit();
                tauri::async_runtime::spawn(request_close(app.clone()));
            }
        }
    });
}
```

```rust
//! translation check (`app/src/lib/codes.json`, see `tests/codes.rs`).

use serde::Serialize;

/// Codes the bridge reports itself (besides the engine's).
pub const APP_FAILURES: &[&str] = &[
    "cache_failed",
    "dialog_failed",
    "engine_running",
    "invalid_mac",
    "invalid_setting",
    "log_io",
    "no_home",
    "not_a_script",
    "packages_unavailable",
    "profile_exists",
    "script_failed",
    "settings_io",
];

/// The engine's catalog plus [`APP_FAILURES`].
#[derive(Debug, Clone, Serialize)]
pub struct AppCatalog {
    #[serde(flatten)]
    pub engine: ni_engine::codes::Catalog,
    pub app_failures: Vec<&'static str>,
}

pub fn catalog() -> AppCatalog {
    AppCatalog {
        engine: ni_engine::codes::catalog(),
        app_failures: APP_FAILURES.to_vec(),
    }
}

/// The catalog as the JSON file the frontend tests read.
pub fn catalog_json() -> String {
    let mut s = serde_json::to_string_pretty(&catalog()).expect("catalog serializes");
    s.push('\n');
    s
}

#[cfg(test)]
mod tests {
    use super::*;

    /// The bridge's sources, without their test modules.
    const SOURCES: &[&str] = &[
        include_str!("core.rs"),
        include_str!("commands.rs"),
        include_str!("settings.rs"),
        include_str!("lib.rs"),

        let engine = ni_engine::codes::FAILURES;

            let src = src.split("#[cfg(test)]\nmod tests").next().unwrap();
            for prefix in ["Failure::new(\"", "asset_cause(\""] {

                    let code = &rest[..rest.find('"').unwrap()];
                    assert!(

                        "{code} is not listed"
                    );
                }
            }
        }
        for code in APP_FAILURES {
            assert!(!engine.contains(code), "{code} is an engine code already");
```
