# Plan 6b — GUI frontend (Svelte) + i18n Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The Mac Netinstall window — interface picker, preflight advice, Start/Stop, profile picker and editor, auto-repeat, device table with per-device actions, kernel status, log panel, settings and a quit confirmation — in English and Hungarian, tested with a mock backend; then a signed-ad-hoc `.app` + `.dmg` build and the roadmap update.

**Architecture:** Svelte 5 (runes) + TypeScript + Vite in `app/`. `src/lib/api.ts` is the only module that talks to Tauri (`invoke` / `listen`) and exposes a `Backend` interface; components take it from Svelte context, so every component test renders with `tests/mock.ts`. Rust sends codes only: `src/lib/messages.ts` turns codes and parameters into sentences through a small typed i18n store over `intl-messageformat`, and tests check that `en.json` and `hu.json` cover every code listed in `src/lib/codes.json` (generated by Plan 6a). `EngineState` (a runes class) is fed by snapshots and events.

## Background (read first)

**Running things:** all `npm`/`npx` commands run in `app/` (the steps say `cd app && …`); the Rust commands run at the repository root. `npm run check` is svelte-check with `--fail-on-warnings`; it warns while there is no `.svelte` file at all, so Tasks 1–4 type-check with `npx tsc -p tsconfig.json` and Task 5 onwards with `npm run check`.

**What the window gets from Rust** (Plan 6a): commands returning JSON or rejecting with `{code, params}`; events `engine-event` (an engine event, tagged by `event`), `engine-lagged`, `close-requested`. Device states are tagged by `state` (`bootp_seen`, `kernel_serving`, `discovered`, `waiting`, `preparing`, `flashing`, `done`, `failed`); in an `engine-event` they are flattened next to `event` and `mac`, in a snapshot they are the `state` object of each device.

**Svelte 5 in one paragraph:** components declare props with `let { a, b = $bindable() } = $props()`, state with `$state`, computed values with `$derived`, side effects with `$effect`; event handlers are attributes (`onclick={…}`); `{#snippet}` / `{@render}` replace slots. Stores still work (`$t` below). Files ending in `.svelte.ts` may use runes outside components (`EngineState`).

## Design notes and deliberate choices

- **i18n library: a typed store instead of `svelte-i18n`.** svelte-i18n 4.0.1 works with Svelte 5, but it pulls esbuild 0.19 (an `npm audit` advisory), `es5-ext` (an install script) and a CLI into the tree. `src/lib/i18n.ts` is ~60 lines over `intl-messageformat` (ICU plurals, the same message syntax svelte-i18n uses), with `MessageKey` typed from `en.json` and English fallback.
- **Keys are flat** (`code.port_in_use`, `cause.network`, `state.flashing`, `hint.no_ipv4`, …). Parameter values that are codes are translated before formatting (`service`, `cause`, `reason` → `link.*`, `kind`, `phase`, `state`, `field`), so Hungarian sentences never contain raw codes. `detail` parameters (English diagnostics) are never shown in messages. Hungarian avoids `a(z)` before a placeholder (`{interface}: …`, `… ({service})`), since the article depends on the inserted word.
- **Default language** follows macOS (`preferred_languages` from Rust; Hungarian if the first starts with `hu`), switchable in Settings (`language: null | "en" | "hu"`).
- **Tests use a mock backend**, never Tauri: `tests/mock.ts` returns sensible data and lets a test emit events. jsdom has no real layout, so tests query by role, label and text.
- **Native feel:** system font at 13 px, compact toolbar rows, macOS-like light/dark colours via `prefers-color-scheme`, sheets for dialogs, tabular numbers for progress, text selection only in the log and hints.
- **Interfaces:** Ethernet only by default; "Show all" lists Wi-Fi, bridges, tunnels, `awdl` etc. (with their kind); a remembered interface is always listed.
- **Signing (Task 11):** the bundle is ad-hoc signed with the bundle identifier (`signingIdentity: "-"`): a linker-signed bundle gets `02:00:00:00:00:00` for MAC addresses from macOS, an identifier-signed one gets the real ones. Still not Developer ID signed or notarized.
- **Every code block below was compiled and tested** in a prototype, and the plan was replayed on a fresh clone; the resulting tree matches the prototype (`node_modules`, `dist`, `target` aside).

```ts
// The only module that talks to Tauri. Components get a `Backend` (from
// context), so tests can pass a mock instead.
import { invoke } from "@tauri-apps/api/core";
import { listen, type UnlistenFn } from "@tauri-apps/api/event";
import type {
  CacheInfo,
  EngineEvent,
  Failure,
  InterfaceView,
  PackagesView,
  PreflightReport,
  Profile,
  ProfilesView,
  ScriptView,
  Settings,
  Snapshot,
  StartInfo,
  StartRequest,
} from "./types";

export type Unlisten = () => void;

export interface Backend {
  listInterfaces(): Promise<InterfaceView[]>;
  preflight(req: StartRequest): Promise<PreflightReport>;
  start(req: StartRequest): Promise<StartInfo>;
  stop(): Promise<void>;
  flash(mac: string, profile: string): Promise<void>;
  retry(mac: string): Promise<void>;
  cancel(mac: string): Promise<void>;
  forget(mac: string): Promise<void>;
  setAutoRepeat(on: boolean): Promise<void>;
  setActiveProfile(name: string | null): Promise<void>;
  setOnlyMac(mac: string | null): Promise<void>;
  setMaxParallel(n: number): Promise<void>;
  setCooldown(secs: number): Promise<void>;
  snapshot(): Promise<Snapshot>;
  listProfiles(): Promise<ProfilesView>;
  saveProfile(profile: Profile, previous: string | null): Promise<void>;
  deleteProfile(name: string): Promise<void>;
  availablePackages(version: string, arch: string): Promise<PackagesView>;
  /** Opens a file dialog (in Rust); `null` if cancelled. */
  pickScript(): Promise<ScriptView | null>;
  getSettings(): Promise<Settings>;
  setSettings(settings: Settings): Promise<Settings>;
  cacheInfo(): Promise<CacheInfo>;
  clearCache(): Promise<void>;
  /** Opens a save dialog (in Rust); `false` if cancelled. */
  exportLog(text: string): Promise<boolean>;
  preferredLanguages(): Promise<string[]>;
  quit(): Promise<void>;
  onEvent(cb: (e: EngineEvent) => void): Promise<Unlisten>;
  /** Events were missed (or the engine restarted): reload the snapshot. */
  onLagged(cb: () => void): Promise<Unlisten>;
  /** Quitting while devices are busy: payload is how many. */
  onCloseRequested(cb: (busy: number) => void): Promise<Unlisten>;
}

/** Errors from commands are `Failure`s; anything else becomes `internal`. */
export function toFailure(e: unknown): Failure {
  if (typeof e === "object" && e !== null && typeof (e as Failure).code === "string") {
    return e as Failure;
  }
  return { code: "internal", params: { detail: String(e) } };
}

async function on<T>(name: string, cb: (payload: T) => void): Promise<Unlisten> {
  const un: UnlistenFn = await listen<T>(name, (e) => cb(e.payload));
  return un;
}

/** The real backend: Tauri commands and events. */
export function tauriBackend(): Backend {
  return {
    listInterfaces: () => invoke("list_interfaces"),
    preflight: (req) => invoke("preflight", { req }),
    start: (req) => invoke("start", { req }),
    stop: () => invoke("stop"),
    flash: (mac, profile) => invoke("flash", { mac, profile }),
    retry: (mac) => invoke("retry", { mac }),
    cancel: (mac) => invoke("cancel", { mac }),
    forget: (mac) => invoke("forget", { mac }),
    setAutoRepeat: (on) => invoke("set_auto_repeat", { on }),
    setActiveProfile: (name) => invoke("set_active_profile", { name }),
    setOnlyMac: (mac) => invoke("set_only_mac", { mac }),
    setMaxParallel: (n) => invoke("set_max_parallel", { n }),
    setCooldown: (secs) => invoke("set_cooldown", { secs }),
    snapshot: () => invoke("snapshot"),
    listProfiles: () => invoke("list_profiles"),
    saveProfile: (profile, previous) => invoke("save_profile", { profile, previous }),
    deleteProfile: (name) => invoke("delete_profile", { name }),
    availablePackages: (version, arch) => invoke("available_packages", { version, arch }),
    pickScript: () => invoke("pick_script"),
    getSettings: () => invoke("get_settings"),
    setSettings: (settings) => invoke("set_settings", { settings }),
    cacheInfo: () => invoke("cache_info"),
    clearCache: () => invoke("clear_cache"),
    exportLog: (text) => invoke("export_log", { text }),
    preferredLanguages: () => invoke("preferred_languages"),
    quit: () => invoke("quit"),
    onEvent: (cb) => on<EngineEvent>("engine-event", cb),
    onLagged: (cb) => on<number>("engine-lagged", () => cb()),
    onCloseRequested: (cb) => on<number>("close-requested", cb),
  };
}
```

```ts
// Field names are the JSON names: snake_case, as Rust sends them.

export type Params = Record<string, string>;

/** A stable code with parameters (`ni_engine::Failure`). */
export interface Failure {
  code: string;
  params?: Params;
}

export type WaitReason = "no_profile" | "concurrency";

export type DeviceState =
  | { state: "bootp_seen"; boot_arch: string; ip: string }
  | { state: "kernel_serving"; sent: number; total: number }
  | { state: "discovered" }
  | { state: "waiting"; reason: WaitReason }
  | { state: "preparing"; version?: string }
  | { state: "flashing"; version: string; phase: string; sent: number; total: number }
  | { state: "done" }
  | { state: "failed"; code: string; params?: Params };

export type KernelState =
  | { state: "idle" }
  | { state: "downloading"; spec: string; done: number; total: number | null }
  | { state: "ready"; version: string; offline: boolean }
  | { state: "unavailable"; code: string; params?: Params };

  model: string;
  arch: string;
  license_id: string;
  min_os: string;
}

  interface: string;
  server_ip: string;
  bootp: string;
  tftp: string;
  netinstall: string;

  server_ip: string;
  netmask: string;
  pool_start: string;
  pool_end: string;
  server_mac: string;
}

  ip: string | null;
```

```ts
// A small typed i18n store: flat message keys, ICU message syntax
// (`{count, plural, one {# device} other {# devices}}`) via
// intl-messageformat. English is the source of truth; a key missing in
// another language falls back to English, then to the key itself.
//
// Why not svelte-i18n: its 4.x release pulls esbuild 0.19 (flagged by
// npm audit) and es5-ext (install script) into the dependency tree for a
// CLI we do not use; this is ~60 lines and checked by tests.
import { IntlMessageFormat } from "intl-messageformat";
import { derived, get, writable } from "svelte/store";
import en from "../locales/en.json";
import hu from "../locales/hu.json";

export type Lang = "en" | "hu";
export const LANGS: readonly Lang[] = ["en", "hu"];
export type MessageKey = keyof typeof en;
export type Values = Record<string, string | number>;

const dictionaries: Record<Lang, Record<string, string>> = { en, hu };
const cache = new Map<string, IntlMessageFormat>();

export const locale = writable<Lang>("en");

/** `en` / `hu` from a setting, else from the macOS preferred languages. */
export function pickLanguage(setting: string | null, preferred: readonly string[]): Lang {
  if (setting === "en" || setting === "hu") return setting;
  const first = preferred[0]?.toLowerCase() ?? "";
  return first.startsWith("hu") ? "hu" : "en";
}

/** Whether `key` has a message (in English, the source of truth). */
export function has(key: string): boolean {
  return key in dictionaries.en;
}

/** The message `key` in `lang`, formatted with `values`. */
export function format(lang: Lang, key: string, values: Values = {}): string {
  const source = dictionaries[lang][key] ?? dictionaries.en[key];
  if (source === undefined) return key;
  const id = `${lang}\u0000${key}`;
  let fmt = cache.get(id);
  if (!fmt) {
    fmt = new IntlMessageFormat(source, lang);
    cache.set(id, fmt);
  }
  try {
    return String(fmt.format(values));
  } catch {
    return source; // a missing value: show the raw text rather than nothing
  }
}

/** `$t(key, values)` in components; follows `locale`. */
export const t = derived(locale, (lang) => (key: MessageKey | string, values?: Values) =>
  format(lang, key, values),
);

/** The current language, outside components. */
export function currentLang(): Lang {
  return get(locale);
}
```

```ts
// Numbers, sizes and times for display.
import type { Lang } from "./i18n";

/** Whole percent of `done` / `total` (0 without a total), at most 100. */
export function percent(done: number, total: number | null | undefined): number {
  if (!total || total <= 0) return 0;
  return Math.min(100, Math.floor((done * 100) / total));
}

/** `1.5 MB` / `1,5 MB`. */
export function bytes(n: number, lang: Lang): string {
  const units = ["B", "KB", "MB", "GB"];
  let v = n;
  let i = 0;
  while (v >= 1000 && i < units.length - 1) {
    v /= 1000;
    i++;
  }
  const digits = i === 0 || v >= 100 ? 0 : 1;
  const num = new Intl.NumberFormat(lang, { maximumFractionDigits: digits }).format(v);
  return `${num} ${units[i]}`;
}

/** `2 minutes ago` / `2 perccel ezelőtt`, from Unix milliseconds. */
export function ago(thenMs: number, nowMs: number, lang: Lang): string {
  const secs = Math.round((thenMs - nowMs) / 1000);
  const rtf = new Intl.RelativeTimeFormat(lang, { numeric: "auto" });
  if (Math.abs(secs) < 60) return rtf.format(secs, "second");
  const mins = Math.round(secs / 60);
  if (Math.abs(mins) < 60) return rtf.format(mins, "minute");
  return rtf.format(Math.round(mins / 60), "hour");
}

/** `14:03:07` in the given language's conventions. */
export function clock(ms: number, lang: Lang): string {
  return new Intl.DateTimeFormat(lang, {
    hour: "2-digit",
    minute: "2-digit",
    second: "2-digit",
  }).format(ms);
}
```

```ts
// Codes and parameters → translated text. Rust sends only codes; this is
// the one place that turns them into sentences.
import { format, has, type Lang, type Values } from "./i18n";
import type { DeviceState, EngineEvent, Failure, Params } from "./types";

/** Parameter values that are codes themselves, by parameter name. */
const PARAM_DOMAINS: Record<string, string> = {
  cause: "cause",
  field: "field",
  kind: "kind",
  phase: "phase",
  reason: "link",
  service: "service",
  state: "state",
};

/** Message values for `params`, with coded values translated. */
export function values(lang: Lang, params: Params | undefined): Values {
  const out: Values = {};
  for (const [k, v] of Object.entries(params ?? {})) {
    const domain = PARAM_DOMAINS[k];
    out[k] = domain && has(`${domain}.${v}`) ? format(lang, `${domain}.${v}`) : v;
  }
  return out;
}

/** A failure (error, warning, finding, failed state) as a sentence. */
export function describe(lang: Lang, f: Failure): string {
  const key = `code.${f.code}`;
  if (!has(key)) return format(lang, "code.unknown", { code: f.code });
  return format(lang, key, values(lang, f.params));
}

/** What to do about it, if there is advice for this code. */
export function hint(lang: Lang, code: string): string | null {
  return has(`hint.${code}`) ? format(lang, `hint.${code}`) : null;
}

/** A device state as a short status text. */
export function stateText(lang: Lang, s: DeviceState): string {
  switch (s.state) {
    case "waiting":
      return format(lang, `wait.${s.reason}`);
    case "flashing":
      return format(lang, `phase.${s.phase}`);
    case "failed":
      return describe(lang, { code: s.code, params: s.params });
    default:
      return format(lang, `state.${s.state}`);
  }
}

export type Level = "info" | "warning" | "error";

/** One log line, kept untranslated so it follows language changes. */
export interface LogEntry {
  at: number;
  level: Level;
  mac?: string;
  /** A message key with its values, or a failure. */
  key?: string;
  values?: Values;
  failure?: Failure;
  /** For `device` events: the state (translated when shown). */
  state?: DeviceState;
}

/** The log entry for an event, or `null` for progress noise. */
export function logEntry(e: EngineEvent, at: number): LogEntry | null {
  switch (e.event) {
    case "started":
      return { at, level: "info", key: "log.started", values: { interface: e.interface, ip: e.server_ip } };
    case "stopped":
      return { at, level: "info", key: "log.stopped" };
    case "kernels_ready":
      return { at, level: "info", key: "log.kernels_ready", values: { version: e.version } };
    case "download":
      return e.done === 0 ? { at, level: "info", key: "log.download", values: { file: e.file } } : null;
    case "discovered":
      return {
        at,
        level: "info",
        mac: e.mac,
        key: "log.discovered",
        values: { model: e.model, arch: e.arch, license: e.license_id },
      };
    case "ignored":
      return { at, level: "info", mac: e.mac, key: "log.ignored", values: { reason: e.reason } };
    case "device": {
      const { event: _event, mac, ...state } = e;
      const s = state as DeviceState;
      // Progress updates of the same phase are noise in a log.
      if (s.state === "kernel_serving" && s.sent > 0) return null;
      if (s.state === "flashing" && s.sent > 0 && s.phase === "uploading") return null;
      const level: Level = s.state === "failed" ? "error" : "info";
      return { at, level, mac, state: s };
    }
    case "error":
      return { at, level: "error", failure: { code: e.code, params: e.params } };
    case "warning":
      return { at, level: "warning", failure: { code: e.code, params: e.params } };
    case "kernels":
      return null; // the status bar shows it; kernels_ready / error log it
  }
}

/** The text of a log entry in `lang`. */
export function logText(lang: Lang, entry: LogEntry): string {
  if (entry.failure) return describe(lang, entry.failure);
  if (entry.state) {
    if (entry.state.state === "failed") {
      return format(lang, "log.failed", { message: stateText(lang, entry.state) });
    }
    return stateText(lang, entry.state);
  }
  const vals = { ...entry.values };
  if (entry.key === "log.ignored" && typeof vals.reason === "string") {
    const k = `ignored.${vals.reason}`;
    if (has(k)) vals.reason = format(lang, k);
  }
  return format(lang, entry.key ?? "code.unknown", vals);
}
```

```ts
// The engine as the window sees it: built from snapshots and kept current
// by events. Pure state, no Tauri: tests feed it events directly.
import { logEntry, type LogEntry } from "./messages";
import type {
  DeviceInfoView,
  DeviceState,
  DeviceView,
  EngineEvent,
  KernelState,
  Snapshot,
  StartInfo,
} from "./types";

/** Most log entries kept (oldest dropped first). */
export const MAX_LOG = 2000;

export interface DeviceRow {
  mac: string;
  ip: string | null;
  boot_arch: string | null;
  info: DeviceInfoView | null;
  version: string | null;
  attempt: number;
  updated_ms: number;
  state: DeviceState;
}

function row(d: DeviceView): DeviceRow {
  return {
    mac: d.mac,
    ip: d.ip,
    boot_arch: d.boot_arch,
    info: d.info,
    version: d.version,
    attempt: d.attempt,
    updated_ms: d.updated_ms,
    state: d.state,
  };
}

export class EngineState {
  running = $state(false);
  started = $state<StartInfo | null>(null);
  kernels = $state<KernelState>({ state: "idle" });
  autoRepeat = $state(false);
  profile = $state<string | null>(null);
  onlyMac = $state<string | null>(null);
  linkDown = $state<string | null>(null);
  devices = $state<Record<string, DeviceRow>>({});
  log = $state<LogEntry[]>([]);

  /** Devices sorted by MAC. */
  get rows(): DeviceRow[] {
    return Object.values(this.devices).sort((a, b) => a.mac.localeCompare(b.mac));
  }

  /** Devices being prepared or flashed. */
  get busy(): number {
    return this.rows.filter((d) => d.state.state === "preparing" || d.state.state === "flashing")
      .length;
  }

  applySnapshot(s: Snapshot): void {
    this.running = s.running;
    this.started = s.started;
    this.kernels = s.kernels;
    this.autoRepeat = s.auto_repeat;
    this.profile = s.profile;
    this.onlyMac = s.only_mac;
    this.linkDown = s.link_down;
    const devices: Record<string, DeviceRow> = {};
    for (const d of s.devices) devices[d.mac] = row(d);
    this.devices = devices;
  }

  private device(mac: string): DeviceRow {
    let d = this.devices[mac];
    if (!d) {
      d = {
        mac,
        ip: null,
        boot_arch: null,
        info: null,
        version: null,
        attempt: 0,
        updated_ms: Date.now(),
        state: { state: "discovered" },
      };
      this.devices[mac] = d;
    }
    return d;
  }

  apply(e: EngineEvent, now: number = Date.now()): void {
    const entry = logEntry(e, now);
    if (entry) {
      this.log.push(entry);
      if (this.log.length > MAX_LOG) this.log.splice(0, this.log.length - MAX_LOG);
    }
    switch (e.event) {
      case "started": {
        const { event: _e, ...info } = e;
        this.running = true;
        this.started = info;
        this.devices = {};
        this.linkDown = null;
        break;
      }
      case "stopped":
        this.running = false;
        this.kernels = { state: "idle" };
        this.linkDown = null;
        break;
      case "kernels": {
        const { event: _e, ...state } = e;
        this.kernels = state as KernelState;
        break;
      }
      case "device": {
        const { event: _e, mac, ...state } = e;
        const d = this.device(mac);
        const s = state as DeviceState;
        if (s.state === "preparing" && d.state.state !== "preparing") d.attempt += 1;
        if (s.state === "bootp_seen") {
          d.ip = s.ip;
          d.boot_arch = s.boot_arch;
        }
        if ((s.state === "preparing" && s.version) || s.state === "flashing") {
          d.version = s.version ?? d.version;
        }
        d.state = s;
        d.updated_ms = now;
        break;
      }
      case "discovered": {
        const { event: _e, mac, ...info } = e;
        this.device(mac).info = info;
        break;
      }
      case "warning":
        if (e.code === "link_down") this.linkDown = e.params?.reason ?? "no_ip";
        if (e.code === "link_up") this.linkDown = null;
        break;
      default:
        break;
    }
  }

  clearLog(): void {
    this.log = [];
  }
}
```

```ts
// The backend is shared through Svelte context, so tests can render any
// component with a mock (`render(C, { context: backendContext(mock) })`).
import { getContext, setContext } from "svelte";
import type { Backend } from "./api";

const KEY = Symbol("backend");

export function setBackend(backend: Backend): void {
  setContext(KEY, backend);
}

export function useBackend(): Backend {
  const b = getContext<Backend | undefined>(KEY);
  if (!b) throw new Error("no backend in context");
  return b;
}

/** A context map for testing-library's `render`. */
export function backendContext(backend: Backend): Map<symbol, Backend> {
  return new Map([[KEY, backend]]);
}
```

```ts
// Profile form rules, mirroring ni-engine's validation so most mistakes
// are shown before saving (the backend checks again).
import { CHANNELS, type Profile } from "./types";

/** Architectures RouterOS packages are published for. */
export const ARCHES = ["arm64", "arm", "mipsbe", "mmips", "smips", "ppc", "tile"] as const;

const NAME = /^[A-Za-z0-9 ._+-]{1,64}$/;
const VERSION = /^\d+\.\d+(\.\d+)?((alpha|beta|rc)\d+)?$/;

export function validName(name: string): boolean {
  return NAME.test(name) && !name.startsWith(".") && !name.startsWith(" ") && !name.endsWith(" ");
}

export function validVersion(v: string): boolean {
  return VERSION.test(v);
}

export function isChannel(v: string): boolean {
  return (CHANNELS as readonly string[]).includes(v);
}

export interface ProfileForm {
  name: string;
  useChannel: boolean;
  channel: string;
  exact: string;
  packages: string[];
  useScript: boolean;
  script: string | null;
}

export function toForm(p: Profile | null): ProfileForm {
  if (!p) {
    return { name: "", useChannel: true, channel: "stable", exact: "", packages: [], useScript: false, script: null };
  }
  const channel = isChannel(p.version);
  return {
    name: p.name,
    useChannel: channel,
    channel: channel ? p.version : "stable",
    exact: channel ? "" : p.version,
    packages: [...p.extra_packages],
    useScript: p.config.mode === "custom_script",
    script: p.config.mode === "custom_script" ? p.config.local_name : null,
  };
}

/** Message keys of the form's problems, by field. */
export function formErrors(f: ProfileForm): Partial<Record<"name" | "version" | "script", string>> {
  const out: Partial<Record<"name" | "version" | "script", string>> = {};
  if (!validName(f.name)) out.name = "profile.err_name";
  if (!f.useChannel && !validVersion(f.exact.trim())) out.version = "profile.err_version";
  if (f.useScript && !f.script) out.script = "profile.err_script";
  return out;
}

export function fromForm(f: ProfileForm): Profile {
  return {
    name: f.name,
    version: f.useChannel ? f.channel : f.exact.trim(),
    extra_packages: [...f.packages],
    config: f.useScript && f.script ? { mode: "custom_script", local_name: f.script } : { mode: "default" },
  };
}
```

```ts
// The settings form: strings in, `Settings` out, with field checks.
import { isIpv4 } from "./format";
import type { Settings } from "./types";

export const LIMITS = {
  max_parallel: [1, 64],
  cooldown_secs: [30, 86_400],
  download_timeout_min: [1, 1440],
} as const;

export interface SettingsForm {
  language: string; // "" = follow macOS
  server_ip: string;
  netmask: string;
  pool_start: string;
  pool_end: string;
  max_parallel: string;
  cooldown_secs: string;
  download_timeout_min: string;
}

export type FieldError = { key: string; values?: Record<string, number> };

export function toSettingsForm(s: Settings): SettingsForm {
  return {
    language: s.language ?? "",
    server_ip: s.server_ip ?? "",
    netmask: s.netmask ?? "",
    pool_start: s.pool_start ?? "",
    pool_end: s.pool_end ?? "",
    max_parallel: String(s.max_parallel),
    cooldown_secs: String(s.cooldown_secs),
    download_timeout_min: String(Math.round(s.download_timeout_secs / 60)),
  };
}

function int(s: string, [min, max]: readonly [number, number]): number | null {
  if (!/^\d+$/.test(s.trim())) return null;
  const n = Number(s.trim());
  return n >= min && n <= max ? n : null;
}

/** Problems by field name (message key + values). */
export function settingsErrors(f: SettingsForm): Record<string, FieldError> {
  const out: Record<string, FieldError> = {};
  for (const k of ["server_ip", "netmask", "pool_start", "pool_end"] as const) {
    if (f[k].trim() !== "" && !isIpv4(f[k].trim())) out[k] = { key: "settings.err_ip" };
  }
  if ((f.pool_start.trim() === "") !== (f.pool_end.trim() === "")) {
    out.pool_end ??= { key: "settings.err_pool" };
  }
  for (const k of ["max_parallel", "cooldown_secs", "download_timeout_min"] as const) {
    const [min, max] = LIMITS[k];
    if (int(f[k], LIMITS[k]) === null) out[k] = { key: "settings.err_range", values: { min, max } };
  }
  return out;
}

/** The settings the form describes (`base` keeps the fields it lacks). */
export function fromSettingsForm(f: SettingsForm, base: Settings): Settings {
  const ip = (s: string) => (s.trim() === "" ? null : s.trim());
  return {
    ...base,
    language: f.language === "" ? null : f.language,
    server_ip: ip(f.server_ip),
    netmask: ip(f.netmask),
    pool_start: ip(f.pool_start),
    pool_end: ip(f.pool_end),
    max_parallel: Number(f.max_parallel.trim()),
    cooldown_secs: Number(f.cooldown_secs.trim()),
    download_timeout_secs: Number(f.download_timeout_min.trim()) * 60,
  };
}
```

```svelte
      engine.profile = name;
      if (!name) engine.autoRepeat = false;

      if (ok === undefined) autoRepeat = !on;
```

```markdown
  `AssetError::CODES` lists the asset causes. The app exports them with its own codes to
  `app/src/lib/codes.json` (`UPDATE_CODES=1 cargo test -p mac-netinstall --test codes`), and the
  frontend tests require an English and Hungarian message for each.
- **App stack:** Tauri 2.12.5 (`tauri-build` 2.7.4, `tauri-plugin-dialog` 2.8.4 used from Rust
  only; `@tauri-apps/cli`/`api` 2.12.4 as npm packages), Svelte 5.57.3, Vite 8.3.6, TypeScript
  6.0.3 (svelte-check 4.7.8 does not accept TypeScript 7), Vitest 5.1.0 + jsdom 31 +
  @testing-library/svelte 5.4.2, intl-messageformat 12.1.4. The app crate needs Rust 1.90
  (Tauri 2.12); the other crates keep MSRV 1.88. `npm audit`: 2 low (deepmerge via
  vite-plugin-svelte, build time only).
- **i18n:** a ~60-line typed store over intl-messageformat instead of svelte-i18n 4.0.1, which
  pulls esbuild 0.19 (npm audit advisory) and es5-ext (install script) into the tree.
- **Security:** the web view gets only the app's commands (`allow-<command>` permissions
  generated by `tauri-build`'s app manifest) and `core:event:allow-listen/unlisten`; no shell,
  fs, http or dialog permissions; file dialogs run in Rust, so the web view never sees a path
  (the cache location is shown as `~/…` text only). CSP: `default-src 'self'`, no `unsafe-eval`
  (`style-src` allows inline styles, which Svelte's `style:` directives use).
- **Build:** debug builds of the app crate need no `dist/` (they use `devUrl`); `npx tauri build`
  embeds it. DMG creation runs an AppleScript that needs Automation permission for Finder;
  `CI=true` skips it. `CI=true npx tauri build --target aarch64-apple-darwin --bundles app,dmg`:
  `Mac Netinstall.app` 19 MiB (binary 20.0 MB), `Mac Netinstall_0.1.0_aarch64.dmg` 6.0 MiB. Info.plist
  has `NSLocalNetworkUsageDescription`, `CFBundleIdentifier` io.github.sepsig.mac-netinstall,
  `LSMinimumSystemVersion` 13.0, `CFBundleLocalizations` en/hu.
- **MAC masking in the bundle (answered for ad-hoc builds):** without a signing identity Tauri
  leaves the binary *linker-signed* (identifier `mac_netinstall-<hash>`), and the bundled app is
  masked (`mac-netinstall --list-interfaces`: Wi-Fi `en0` `null`, Ethernet only through the IOKit
  fallback). With `bundle.macOS.signingIdentity: "-"` Tauri ad-hoc signs with the bundle
  identifier (and hardened runtime): the app sees real MACs (`en0` matches `ifconfig`), and it
  launches and runs normally. The app is therefore ad-hoc signed by default (still no Developer ID,
  no notarization). Still open: a Developer ID-signed build (an *Apple Development* signature was
  masked in Plan 4a).
```
