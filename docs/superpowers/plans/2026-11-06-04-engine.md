# Plan 4a — Engine (ni-engine) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A `ni-engine` crate that runs Netinstall for many devices at once — one tokio task owning the Netinstall socket and every install session, controlling the BOOTP and TFTP runners — with profiles, a concurrency limit, auto-repeat with a post-flash cooldown, preflight checks and a serde event stream; proven end to end over loopback against simulated RouterBOARDs.

**Architecture:** The engine loop (`engine/core.rs`) is the only owner of the Netinstall UDP socket and of all `ni_proto::ServerSession`s, keyed by device MAC. It spawns `ni_bootp::serve_shared` and `ni_tftp::serve_watched` (new runner entry points with shared state, a MAC policy, progress events and bounded channels), downloads boot kernels through `ni-assets` in the background and publishes them to both runners when ready. Commands arrive through `EngineHandle` (an mpsc channel with a oneshot reply each); events leave on a bounded `tokio::sync::broadcast` channel as `EngineEvent` — stable codes and parameters, never localized text. Everything that would need broadcast or privileged ports is configurable (`Ports`), so the tests run a real engine on `lo0` with ephemeral ports and simulated devices (`ni_sim::lan`).

**Tech Stack:** Rust stable (rustup, edition 2021, MSRV 1.88), `tokio` 1.54.1, `serde` 1.0.229 + `serde_json` 1.0.154, `thiserror` 2, `tracing` 0.1.44 (macros only), `system-configuration` 0.8.0 (new, in `ni-net`). Depends on all earlier crates.

## Background (read first)

**Toolchain:** rustup's cargo must come first in `PATH` (`which cargo` → `~/.cargo/bin/cargo`). If not, run `export PATH="$HOME/.cargo/bin:$PATH"` for the session (see Plan 1 Task 0).

**How a RouterBOARD is flashed, and which part of the engine does what:**

```text
RouterBOOT (Etherboot)                    mac-netinstall engine
 BOOTP request, option 60 = arch  ─────►  ni-bootp runner: lease + boot file (if the gate allows the MAC)
 TFTP RRQ kernel-<arch>.elf       ─────►  ni-tftp runner: kernel bytes (published after download)
 kernel boots, Netinstall hello   ─────►  engine loop: Discovered → Waiting / Preparing
                                  ◄─────  Preparing: ni-assets packages + script → InstallPlan
 OFFR / format / FILE / chunks /  ◄────►  Flashing: ServerSession driven with real time
 TERM                                     Done → MAC in cooldown (BOOTP and hellos ignored)
```

Device states (`DeviceState`, one per MAC): `bootp_seen` → `kernel_serving` → `discovered` → `waiting` (`no_profile` | `concurrency`) → `preparing` → `flashing` (`phase`, bytes) → `done` | `failed` (`code`, `params`).

**Loopback testing:** `lo0` cannot send to `255.255.255.255` (Plan 2 fact), so `Ports` makes every port and destination configurable: tests bind port 0 and send BOOTP replies / Netinstall frames to the sockets of a `ni_sim::lan::SimLan`, which plays any number of RouterBOARDs (BOOTP client, TFTP client, `DeviceSim` per MAC, fault injection). Synthetic kernels and packages come from `ni-assets`' fake mirror (a local HTTP server), now exported through a `testing` feature. Nothing from MikroTik is used.

## Design notes and deliberate choices

- **One owner.** `engine/core.rs` holds all mutable state; runners and download tasks report back through channels (`Internal` messages, tagged with a start "epoch" so results from before a stop are dropped). The loop never blocks: asset work runs in spawned tasks, BOOTP/TFTP in their own tasks.
- **Runner API extensions (minimal, existing tests untouched):**
  - `ni-bootp`: `BootpResponder::{set_boot_files, mac_of, handle_with}`, `IgnoreReason::Denied(arch)`, `LeasePool::mac_of`; `BootpHandle` (an `Arc<Mutex<BootpResponder>>` plus an optional `MacPolicy = Arc<dyn Fn(Mac) -> bool>`) and `serve_shared(socket, handle, reply_to, mpsc::Sender)`. The policy is only consulted for supported RouterBOOT vendor classes, before a lease is made.
  - `ni-tftp`: `serve_watched(listener, watch::Receiver<Arc<FileMap>>, cfg, progress_step, mpsc::Sender)` and `TftpEvent::Progress { acked, size }` (only from `serve_watched`, so `serve`'s event sequence is unchanged).
  - Both new runners use bounded channels with `try_send`: when the engine is behind, events are dropped instead of queued (a datagram flood cannot grow memory). The old `serve` functions keep their signatures and delegate to the same loops.
- **Deviation: no TFTP MAC policy.** The roadmap asked for a policy hook "for BOOTP/TFTP". TFTP peers are known by IP only and RouterBOOT always does BOOTP first, so the gate sits at BOOTP: a device in cooldown (or not `--only-mac`) gets no lease and no boot file. Hellos are checked against the same gate.
- **Deviation: the concurrency limit applies to preparing + flashing**, not to BOOTP/TFTP. Kernel transfers are short (≤ 8 MB) and RouterBOOT gives up quickly; holding devices back at BOOTP would only make them retry. Discovered devices beyond the limit wait (`waiting`/`concurrency`) and start in MAC-queue order when a slot frees up.
- **IP → MAC correlation** uses `BootpHandle::mac_of` (TFTP events → `kernel_serving`). On loopback the simulated TFTP client's address (127.0.0.1) is not its lease (lo0 has no other address), so the end-to-end tests do not see `kernel_serving`; the lookup itself is tested in `ni-bootp/tests/shared.rs`.
- **Auto-repeat and cooldown.** With auto-repeat on, a discovered device gets the active profile; otherwise it waits for `flash(mac, profile)`. A finished device is put in cooldown (default 5 min) for BOOTP and hellos; after the cooldown it is a new device. A failed device keeps failing its hellos until `retry(mac)` re-arms it (and clears its cooldown). `stop` cancels running sessions (`failed`/`cancelled`).
- **Kernels.** `start` returns as soon as the listeners are bound; the kernels of the active profile's version (stable without a profile) are fetched in the background (`kernels_ready`). If the version cannot be resolved (offline), the newest fully cached kernel set is used with a `kernels_offline_fallback` warning. Devices with the same version spec reuse that resolution, so a whole run installs one version.
- **Interface watchdog:** every `link_check` (2 s) the interface must still be up and carry the server IP; otherwise `error`/`interface_gone` and the engine stops.
- **Preflight** is pure where possible (`check_network` takes an interface list); `check_ports` binds and releases the listeners exactly like `start` (no `SO_REUSEPORT`, so another DHCP/TFTP/netinstall server shows up as `port_in_use`). macOS's Local Network permission cannot be queried; this is documented in the module.
- **Interface kinds** (`ni-net`): `IFT_*` from the `AF_LINK` `sdl_type`, name prefixes (`awdl`, `llw`, `nan`, `utun`, `bridge`, `anpi`, `ap<n>`) and SystemConfiguration's interface type to tell Wi-Fi from Ethernet (both `IFT_ETHER`), which also gives display names such as "Thunderbolt Bridge". This adds the `system-configuration` 0.8.0 dependency (MSRV 1.64).
- **Fix found while prototyping (ni-assets):** `Assets` futures were not `Send` — `Http::download` held a `&dyn Fn(AssetEvent)` (not `Sync`) across `.await` — so they could not run in spawned tasks. Task 5 adds a compile-time test and the `+ Sync` bound.
- **Profiles** are JSON files named after the lowercase profile name (APFS is case-insensitive). `version` is stored as a string (`"stable"`, `"7.25.1"`). `ConfigMode` has `default` and `custom_script` only; `keep` / `no-default` / `empty` are Plan 5 (an explicit comment marks the spot).
- **The engine loop is delivered in one task (Task 13).** Its parts (commands, runner events, sessions, admission) are interdependent; Task 13's end-to-end tests drive the main path, and Task 14 adds tests for the multi-device rules implemented there (they pass without changes; a failure there is a bug in Task 13's code).
- **Every code block below was compiled and tested** in a prototype before this plan was written, and the plan was replayed on a fresh clone of `feat/engine`; the final tree matches the prototype byte for byte.

```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash)]

    /// Wired Ethernet (built-in, USB or Thunderbolt adapters): the only
    /// kind that can network-boot a RouterBOARD.
    Ethernet,
    /// IEEE 802.11 (`en0` on most Macs).
    WiFi,
    Loopback,

/// Classify from the BSD name, the `AF_LINK` `sdl_type` (if any) and
/// whether SystemConfiguration reports the interface as Wi-Fi.
pub fn classify(name: &str, link_type: Option<u8>, is_wifi: bool) -> InterfaceKind {
    let prefixed = |prefixes: &[&str]| prefixes.iter().any(|p| name.starts_with(p));
    if prefixed(&["awdl", "llw", "nan"]) {
        return InterfaceKind::AppleWireless;
    }
    if prefixed(&["anpi"]) {
        // Apple's internal network peripheral links (`anpi0`, ...).
        return InterfaceKind::Other;
    }
    let digits_after = |p: &str| {
        name.strip_prefix(p)
            .is_some_and(|rest| !rest.is_empty() && rest.bytes().all(|b| b.is_ascii_digit()))
    };
    if digits_after("ap") {
        // The Wi-Fi access-point interface (`ap1`), unknown to
        // SystemConfiguration.
        return InterfaceKind::WiFi;
    }
    if prefixed(&["utun", "ipsec", "gif", "stf", "ppp"]) {
        return InterfaceKind::Tunnel;
    }
    if prefixed(&["bridge"]) {
        return InterfaceKind::Bridge;
    }
    match link_type {
        Some(IFT_LOOP) => InterfaceKind::Loopback,
        Some(IFT_BRIDGE) => InterfaceKind::Bridge,
        Some(IFT_GIF | IFT_STF) => InterfaceKind::Tunnel,
        Some(IFT_ETHER) if is_wifi => InterfaceKind::WiFi,
        Some(IFT_ETHER) => InterfaceKind::Ethernet,
        _ if prefixed(&["lo"]) => InterfaceKind::Loopback,
        _ => InterfaceKind::Other,
    }
}
```

```rust
/// Download `name` (512-byte blocks); `Err` carries a TFTP error code.
async fn download(server: SocketAddr, name: &str) -> Result<Vec<u8>, ErrorCode> {
    let sock = UdpSocket::bind("127.0.0.1:0").await.unwrap();
    let rrq = Packet::Rrq(Request {
        filename: name.into(),
        mode: "octet".into(),
        options: Vec::new(),
    });
    sock.send_to(&rrq.encode(), server).await.unwrap();
    let mut data = Vec::new();
    let mut buf = vec![0u8; 2048];
    loop {
        let (n, from) = tokio::time::timeout(Duration::from_secs(2), sock.recv_from(&mut buf))
            .await
            .expect("packet within 2 s")
            .unwrap();
        match Packet::parse(&buf[..n]).unwrap() {
            Packet::Data { block, data: d } => {
                data.extend_from_slice(&d);
                sock.send_to(&Packet::Ack(block).encode(), from)
                    .await
                    .unwrap();
                if d.len() < 512 {
                    return Ok(data);
                }
            }
            Packet::Error { code, .. } => return Err(code),
            other => panic!("unexpected {other:?}"),
        }
    }
}

async fn next_event(s: &mut Server) -> TftpEvent {
    tokio::time::timeout(Duration::from_secs(2), s.events.recv())
        .await
        .expect("event within 2 s")
        .unwrap()
}
```

```rust
        .await
        .expect("frame within 2 s")
        .unwrap();

}
```

```rust
//! Simulated RouterBOARDs on a real UDP network (feature `lan`).
//!
//! Used by the engine's end-to-end tests over loopback, where nothing can
//! be broadcast: the engine is configured to send BOOTP replies to
//! [`SimLan::bootp_addr`] and Netinstall frames to
//! [`SimLan::netinstall_addr`] instead of `255.255.255.255`. Once the
//! engine runs, [`SimLan::connect`] tells the devices where it listens.
//!
//! - [`SimLan::boot`]: a RouterBOOT-like BOOTP request (retried every
//!   250 ms) until the server answers with a boot file;
//! - [`tftp_get`]: download that boot file;
//! - [`SimLan::add`]: from then on a [`DeviceSim`] for that MAC runs
//!   on the shared Netinstall socket. Every received frame is offered to
//!   every device, as on a broadcast segment.
//!
//! Fault injection: [`SimLan::set_mute`] drops everything a device sends
//! except hellos; [`SimLan::reset`] replaces a device with a fresh one
//! (as if it rebooted into Netinstall mode).

use crate::{DeviceSim, ReceivedFile};
use ni_proto::{DeviceInfo, Frame, Mac};
use ni_tftp::{Packet, Request};
use std::collections::{BTreeMap, BTreeSet};
use std::io;
use std::net::{Ipv4Addr, SocketAddr};
use std::time::{Duration, Instant};
use tokio::net::UdpSocket;
use tokio::sync::{mpsc, oneshot};
use tokio::task::JoinHandle;

/// What a BOOTP server told a simulated device.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct BootReply {
    /// `yiaddr`: the address assigned to the device.
    pub ip: Ipv4Addr,
    /// `siaddr`: where to fetch the boot file (TFTP).
    pub server: Ipv4Addr,
    /// Boot file name.
    pub file: String,
}

/// A RouterBOOT-like plain BOOTP request (no DHCP message type).
pub fn bootp_request(mac: Mac, vendor_class: &str, xid: u32) -> Vec<u8> {
    let mut b = vec![0u8; 236];
    b[0] = 1;
    b[1] = 1;
    b[2] = 6;
    b[4..8].copy_from_slice(&xid.to_be_bytes());
    b[28..34].copy_from_slice(&mac.0);
    b.extend_from_slice(&[99, 130, 83, 99, 60, vendor_class.len() as u8]);
    b.extend_from_slice(vendor_class.as_bytes());
    b.push(255);
    b.resize(300, 0);
    b
}

/// Parse a BOOTP reply addressed to `mac` (op 2, matching `chaddr`).
pub fn parse_boot_reply(buf: &[u8], mac: Mac) -> Option<BootReply> {
    if buf.len() < 236 || buf[0] != 2 || buf[28..34] != mac.0 {
        return None;
    }
    let ip = |at: usize| Ipv4Addr::new(buf[at], buf[at + 1], buf[at + 2], buf[at + 3]);
    let file = &buf[108..236];
    let end = file.iter().position(|&b| b == 0).unwrap_or(file.len());
    Some(BootReply {
        ip: ip(16),
        server: ip(20),
        file: String::from_utf8_lossy(&file[..end]).into_owned(),
    })
}

/// Download `file` from the TFTP server at `server` (512-byte blocks, no
/// options), as RouterBOOT does. Errors: an ERROR packet, or no packet
/// for 2 s.
pub async fn tftp_get(server: SocketAddr, file: &str) -> io::Result<Vec<u8>> {
    let sock = UdpSocket::bind("127.0.0.1:0").await?;
    let rrq = Packet::Rrq(Request {
        filename: file.into(),
        mode: "octet".into(),
        options: Vec::new(),
    });
    sock.send_to(&rrq.encode(), server).await?;
    let mut data = Vec::new();
    let mut buf = vec![0u8; 2048];
    loop {
        let (n, from) = tokio::time::timeout(Duration::from_secs(2), sock.recv_from(&mut buf))
            .await
            .map_err(|_| io::Error::new(io::ErrorKind::TimedOut, "TFTP timeout"))??;
        match Packet::parse(&buf[..n]) {
            Ok(Packet::Data { block, data: d }) => {
                data.extend_from_slice(&d);
                sock.send_to(&Packet::Ack(block).encode(), from).await?;
                if d.len() < 512 {
                    return Ok(data);
                }
            }
            Ok(Packet::Error { code, message }) => {
                return Err(io::Error::other(format!("TFTP error {code:?}: {message}")))
            }
            other => return Err(io::Error::other(format!("unexpected {other:?}"))),
        }
    }
}

/// A device's state, as seen by the test.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct DeviceReport {
    pub received: Vec<ReceivedFile>,
    pub terminated: bool,
    pub violations: Vec<String>,
    /// Frames addressed to this device since it was added or reset.
    pub frames_to_device: usize,
}

enum Cmd {
    Connect(SocketAddr),
    Add(Box<DeviceSim>),
    Reset(Mac),
    Mute(Mac, bool),
    Report(Mac, oneshot::Sender<Option<DeviceReport>>),
}

struct Device {
    sim: DeviceSim,
    frames: usize,
}

/// Simulated devices on two loopback sockets; see the module docs.
pub struct SimLan {
    bootp: UdpSocket,
    bootp_addr: SocketAddr,
    netinstall_addr: SocketAddr,
    cmds: mpsc::Sender<Cmd>,
    task: JoinHandle<()>,
}

impl Drop for SimLan {
    fn drop(&mut self) {
        self.task.abort();
    }
}

impl SimLan {
    /// Bind the BOOTP client and Netinstall sockets on `127.0.0.1`.
    pub async fn bind() -> io::Result<SimLan> {
        let bootp = UdpSocket::bind("127.0.0.1:0").await?;
        let netinstall = UdpSocket::bind("127.0.0.1:0").await?;
        let (cmds, rx) = mpsc::channel(16);
        Ok(SimLan {
            bootp_addr: bootp.local_addr()?,
            netinstall_addr: netinstall.local_addr()?,
            bootp,
            cmds,
            task: tokio::spawn(run(netinstall, rx)),
        })
    }

    /// Where the engine must send BOOTP replies.
    pub fn bootp_addr(&self) -> SocketAddr {
        self.bootp_addr
    }

    /// Where the engine must send Netinstall frames.
    pub fn netinstall_addr(&self) -> SocketAddr {
        self.netinstall_addr
    }

    /// Send device frames to the engine's Netinstall socket at `server`
    /// (until then they are dropped).
    pub async fn connect(&self, server: SocketAddr) {
        let _ = self.cmds.send(Cmd::Connect(server)).await;
    }

    /// Send BOOTP requests for `mac` to `server` every 250 ms until a reply
    /// arrives or `timeout` passes (`None`).
    pub async fn boot(
        &self,
        mac: Mac,
        vendor_class: &str,
        server: SocketAddr,
        timeout: Duration,
    ) -> Option<BootReply> {
        let end = tokio::time::Instant::now() + timeout;
        let mut buf = vec![0u8; 1500];
        let mut xid = u32::from_be_bytes([mac.0[2], mac.0[3], mac.0[4], mac.0[5]]);
        loop {
            xid = xid.wrapping_add(1);
            let _ = self
                .bootp
                .send_to(&bootp_request(mac, vendor_class, xid), server)
                .await;
            let wait = (tokio::time::Instant::now() + Duration::from_millis(250)).min(end);
            while let Ok(Ok((n, _))) =
                tokio::time::timeout_at(wait, self.bootp.recv_from(&mut buf)).await
            {
                if let Some(reply) = parse_boot_reply(&buf[..n], mac) {
                    return Some(reply);
                }
            }
            if tokio::time::Instant::now() >= end {
                return None;
            }
        }
    }

    /// Start running `sim` on the Netinstall socket (it says hello at once).
    pub async fn add(&self, sim: DeviceSim) {
        let _ = self.cmds.send(Cmd::Add(Box::new(sim))).await;
    }

    /// Replace the device with a fresh simulator (same configuration), as
    /// if it rebooted into Netinstall mode.
    pub async fn reset(&self, mac: Mac) {
        let _ = self.cmds.send(Cmd::Reset(mac)).await;
    }

    /// While muted, a device's frames are dropped, except hellos. May be
    /// set before the device is added.
    pub async fn set_mute(&self, mac: Mac, muted: bool) {
        let _ = self.cmds.send(Cmd::Mute(mac, muted)).await;
    }

    pub async fn report(&self, mac: Mac) -> Option<DeviceReport> {
        let (tx, rx) = oneshot::channel();
        self.cmds.send(Cmd::Report(mac, tx)).await.ok()?;
        rx.await.ok().flatten()
    }

    /// Wait until the device has been told to reboot (`TERM`).
    pub async fn wait_terminated(&self, mac: Mac, timeout: Duration) -> Option<DeviceReport> {
        let end = tokio::time::Instant::now() + timeout;
        loop {
            let report = self.report(mac).await?;
            if report.terminated {
                return Some(report);
            }
            if tokio::time::Instant::now() >= end {
                return None;
            }
            tokio::time::sleep(Duration::from_millis(20)).await;
        }
    }
}

async fn run(sock: UdpSocket, mut cmds: mpsc::Receiver<Cmd>) {
    let mut server: Option<SocketAddr> = None;
    let mut devices: BTreeMap<Mac, Device> = BTreeMap::new();
    let mut muted: BTreeSet<Mac> = BTreeSet::new();
    let mut buf = vec![0u8; 2048];
    loop {
        let now = Instant::now();
        for (mac, dev) in devices.iter_mut() {
            dev.sim.handle_timeout(now);
            while let Some(frame) = dev.sim.poll_transmit() {
                if muted.contains(mac) && !DeviceInfo::is_hello(&frame) {
                    continue;
                }
                if let Some(server) = server {
                    let _ = sock.send_to(&frame.encode(), server).await;
                }
            }
        }
        let next = devices
            .values()
            .filter_map(|d| d.sim.poll_timeout())
            .min()
            .unwrap_or(now + Duration::from_secs(1));
        tokio::select! {
            cmd = cmds.recv() => match cmd {
                None => return,
                Some(Cmd::Connect(addr)) => server = Some(addr),
                Some(Cmd::Add(sim)) => {
                    let mac = sim.info().mac;
                    devices.insert(mac, Device { sim: *sim, frames: 0 });
                }
                Some(Cmd::Reset(mac)) => {
                    if let Some(dev) = devices.get_mut(&mac) {
                        dev.sim = DeviceSim::new(dev.sim.config().clone(), Instant::now());
                        dev.frames = 0;
                    }
                }
                Some(Cmd::Mute(mac, on)) => {
                    if on {
                        muted.insert(mac);
                    } else {
                        muted.remove(&mac);
                    }
                }
                Some(Cmd::Report(mac, reply)) => {
                    let report = devices.get(&mac).map(|d| DeviceReport {
                        received: d.sim.received_files().to_vec(),
                        terminated: d.sim.is_terminated(),
                        violations: d.sim.violations().to_vec(),
                        frames_to_device: d.frames,
                    });
                    let _ = reply.send(report);
                }
            },
            received = sock.recv_from(&mut buf) => {
                let Ok((n, _)) = received else { continue };
                let Ok(frame) = Frame::decode(&buf[..n]) else { continue };
                let now = Instant::now();
                for (mac, dev) in devices.iter_mut() {
                    if frame.dst == *mac {
                        dev.frames += 1;
                    }
                    dev.sim.handle_frame(&frame, now);
                }
            }
            _ = tokio::time::sleep_until(next.into()) => {}
        }
    }
}
```

//!
//! ```json
//! {
//!   "name": "hAP ax2 stable",
//!   "version": "stable",
//!   "extra_packages": ["wifi-qcom"],
//!   "config": { "mode": "custom_script", "local_name": "setup.rsc" }
//! }
//! ```
//!

/// `VersionSpec` as a plain string: `"stable"` or `"7.25.1"`.
pub mod spec_str {

    }

        String::deserialize(d)?.parse().map_err(de::Error::custom)
    }

        VersionSpec::Exact(v) => v.as_str().to_string(),

/// A reusable install recipe.
#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
pub struct Profile {
    pub name: String,
    #[serde(with = "spec_str")]
    pub version: VersionSpec,
    /// Packages besides `routeros`, e.g. `wifi-qcom`.
    #[serde(default)]
    pub extra_packages: Vec<String>,
    #[serde(default)]
    pub config: ConfigMode,
}

impl Profile {
    /// A profile installing just `routeros` of `version` with the default
    /// configuration.
    pub fn new(name: &str, version: VersionSpec) -> Self {
        Profile {
            name: name.to_string(),
            version,
            extra_packages: Vec::new(),
            config: ConfigMode::Default,
        }
    }

    /// Check the profile can be stored and used. Codes: `invalid_name`,
    /// `invalid_package_name`, `duplicate_package`, `too_many_packages`,
    /// `invalid_script_name`.
    pub fn validate(&self) -> Result<(), Failure> {
        if !valid_name(&self.name) {
            return Err(Failure::new("invalid_name").with("name", &self.name));
        }
        if self.extra_packages.len() > MAX_EXTRA_PACKAGES {
            return Err(Failure::new("too_many_packages").with("max", MAX_EXTRA_PACKAGES));
        }
        for (i, p) in self.extra_packages.iter().enumerate() {
            if !valid_package_name(p) || p == "routeros" {
                return Err(Failure::new("invalid_package_name").with("package", p));
            }
            if self.extra_packages[..i].contains(p) {
                return Err(Failure::new("duplicate_package").with("package", p));
            }
        }
        if let ConfigMode::CustomScript { local_name } = &self.config {
            let ok = !local_name.is_empty()
                && local_name.len() <= MAX_LOCAL_NAME
                && local_name.ends_with(".rsc")
                && !local_name.contains(['/', '\\'])
                && !local_name.starts_with('.')
                && *local_name == local_name.to_lowercase();
            if !ok {
                return Err(Failure::new("invalid_script_name").with("name", local_name));
            }
        }
        Ok(())
    }
}

/// Names are also file names: 1-64 bytes of letters, digits, space, `.`,
/// `_`, `-`, `+`; not starting with `.` or space, not ending with space.
fn valid_name(name: &str) -> bool {
    !name.is_empty()
        && name.len() <= MAX_NAME
        && !name.starts_with(['.', ' '])
        && !name.ends_with(' ')
        && name
            .chars()
            .all(|c| c.is_ascii_alphanumeric() || " ._-+".contains(c))
}

/// are lowercase because APFS is case-insensitive: `Lab` and `lab` are the

/// Result of [`ProfileStore::list`].
#[derive(Debug, Default)]
pub struct Listing {

fn io_failure(op: &str, path: &Path, e: io::Error) -> Failure {
    Failure::new("profile_io")
        .with("op", op)
        .with("path", path.display())
        .with("detail", e)
}

impl ProfileStore {
    pub fn new(root: impl Into<PathBuf>) -> Self {
        ProfileStore { root: root.into() }
    }

    pub fn root(&self) -> &Path {
        &self.root
    }

    fn path(&self, name: &str) -> Result<PathBuf, Failure> {
        if !valid_name(name) {
            return Err(Failure::new("invalid_name").with("name", name));
        }
        Ok(self.root.join(format!("{}.json", name.to_lowercase())))
    }

    /// Load one profile. `profile_not_found` if there is none; a stored
    /// file that fails validation is `invalid_profile`.
    pub fn load(&self, name: &str) -> Result<Profile, Failure> {
        let path = self.path(name)?;
        let data = match std::fs::read(&path) {
            Ok(d) => d,
            Err(e) if e.kind() == io::ErrorKind::NotFound => {
                return Err(Failure::new("profile_not_found").with("name", name))
            }
            Err(e) => return Err(io_failure("read", &path, e)),
        };
        parse(&data, &path)
    }

    /// Validate and write (replacing a profile of the same name, whatever
    /// its case). Written to a temporary file first, then renamed.
    pub fn save(&self, profile: &Profile) -> Result<(), Failure> {
        profile.validate()?;
        let path = self.path(&profile.name)?;
        std::fs::create_dir_all(&self.root).map_err(|e| io_failure("mkdir", &self.root, e))?;
        let mut json = serde_json::to_vec_pretty(profile).expect("profiles serialize");
        json.push(b'\n');
        let tmp = path.with_extension(format!("json.{}.tmp", std::process::id()));
        std::fs::write(&tmp, &json).map_err(|e| io_failure("write", &tmp, e))?;
        std::fs::rename(&tmp, &path).map_err(|e| {
            let _ = std::fs::remove_file(&tmp);
            io_failure("rename", &path, e)
        })
    }

    /// Remove a profile; `profile_not_found` if there is none.
    pub fn delete(&self, name: &str) -> Result<(), Failure> {
        let path = self.path(name)?;
        match std::fs::remove_file(&path) {
            Ok(()) => Ok(()),
            Err(e) if e.kind() == io::ErrorKind::NotFound => {
                Err(Failure::new("profile_not_found").with("name", name))
            }
            Err(e) => Err(io_failure("remove", &path, e)),
        }
    }

    /// All `*.json` files in the root (a missing root is empty).
    pub fn list(&self) -> Listing {
        let mut out = Listing::default();
        let Ok(entries) = std::fs::read_dir(&self.root) else {
            return out;
        };
        for entry in entries.flatten() {
            let path = entry.path();
            if path.extension().is_none_or(|e| e != "json") {
                continue;
            }
            let loaded = std::fs::read(&path)
                .map_err(|e| io_failure("read", &path, e))
                .and_then(|data| parse(&data, &path));
            match loaded {
                Ok(p) => out.profiles.push(p),
                Err(f) => out.broken.push((path, f)),
            }
        }
        out.profiles.sort_by_key(|p| p.name.to_lowercase());
        out.broken.sort_by(|a, b| a.0.cmp(&b.0));
        out
    }
}

fn parse(data: &[u8], path: &Path) -> Result<Profile, Failure> {
    let profile: Profile = serde_json::from_slice(data).map_err(|e| {
        Failure::new("invalid_profile")
            .with("path", path.display())
            .with("detail", e)
    })?;
    profile.validate().map_err(|f| {
        Failure::new("invalid_profile")
            .with("path", path.display())
            .with("detail", f)
    })?;
    let stem = path.file_stem().and_then(|s| s.to_str()).unwrap_or("");
    if stem != profile.name.to_lowercase() {
        return Err(Failure::new("invalid_profile")
            .with("path", path.display())
            .with("detail", "file name does not match the profile name"));
    }
    Ok(profile)
}

```rust
/// Network and broadcast address of `ip`/`mask` (`mask` must be a prefix).
pub fn subnet(ip: Ipv4Addr, mask: Ipv4Addr) -> (Ipv4Addr, Ipv4Addr) {
    let (ip, mask) = (u32::from(ip), u32::from(mask));
    ((ip & mask).into(), (ip | !mask).into())
}

/// Default pool: the subnet's first 254 host addresses (the whole subnet
/// of a /24). The server IP inside it is skipped by the BOOTP pool.
/// For /31 and /32 the pool is the subnet itself.
pub fn default_pool(server_ip: Ipv4Addr, netmask: Ipv4Addr) -> (Ipv4Addr, Ipv4Addr) {
    let (net, bcast) = subnet(server_ip, netmask);
    let (net, bcast) = (u32::from(net), u32::from(bcast));
    if bcast - net < 2 {
        return (net.into(), bcast.into());
    }
    let first = net + 1;
    let last = (bcast - 1).min(net + 254);
    (first.into(), last.into())
}

/// Resolve `cfg` against the interface list. Codes: `unknown_interface`,
/// `no_ipv4`, `server_ip_not_on_interface`, `no_mac`.
pub fn resolve_network(ifaces: &[Interface], cfg: &EngineConfig) -> Result<NetPlan, Failure> {
    let iface = ifaces
        .iter()
        .find(|i| i.name == cfg.interface)
        .ok_or_else(|| Failure::new("unknown_interface").with("interface", &cfg.interface))?;
    let (server_ip, netmask) = match cfg.server_ip {
        None => *iface
            .ipv4
            .first()
            .ok_or_else(|| Failure::new("no_ipv4").with("interface", &iface.name))?,
        Some(ip) => *iface.ipv4.iter().find(|(a, _)| *a == ip).ok_or_else(|| {
            Failure::new("server_ip_not_on_interface")
                .with("interface", &iface.name)
                .with("ip", ip)
        })?,
    };
    let (pool_start, pool_end) = cfg.pool.unwrap_or_else(|| default_pool(server_ip, netmask));
    let server_mac = cfg
        .server_mac
        .or(iface.mac)
        .ok_or_else(|| Failure::new("no_mac").with("interface", &iface.name))?;
    Ok(NetPlan {
        server_ip,
        netmask,
        pool_start,
        pool_end,
        server_mac,
    })
}
```

```rust
//! Which devices may be served: post-flash cooldown and "only this MAC".
//!
//! Shared between the engine loop (Netinstall hellos) and the BOOTP runner
//! (through [`Gate::policy`]), so a device in cooldown gets no boot file.

use ni_bootp::MacPolicy;
use ni_proto::Mac;
use std::collections::HashMap;
use std::sync::{Arc, Mutex, MutexGuard, PoisonError};
use std::time::Instant;

/// Verdict for one device.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Verdict {
    Allow,
    /// Recently flashed.
    Cooldown,
    /// Another device was selected (`only_mac`).
    NotSelected,
}

impl Verdict {
    /// The `reason` of an `ignored` event.
    pub fn reason(self) -> &'static str {
        match self {
            Verdict::Allow => "allowed",
            Verdict::Cooldown => "cooldown",
            Verdict::NotSelected => "not_selected",
        }
    }
}

#[derive(Debug, Default)]
struct State {
    cooldown_until: HashMap<Mac, Instant>,
    only: Option<Mac>,
}

/// Cheap to clone; clones share state.
#[derive(Debug, Clone, Default)]
pub struct Gate(Arc<Mutex<State>>);

impl Gate {
    fn lock(&self) -> MutexGuard<'_, State> {
        self.0.lock().unwrap_or_else(PoisonError::into_inner)
    }

    pub fn check(&self, mac: Mac, now: Instant) -> Verdict {
        let mut s = self.lock();
        if s.only.is_some_and(|only| only != mac) {
            return Verdict::NotSelected;
        }
        match s.cooldown_until.get(&mac) {
            Some(&until) if now < until => Verdict::Cooldown,
            Some(_) => {
                s.cooldown_until.remove(&mac);
                Verdict::Allow
            }
            None => Verdict::Allow,
        }
    }

    pub fn start_cooldown(&self, mac: Mac, until: Instant) {
        self.lock().cooldown_until.insert(mac, until);
    }

    pub fn clear_cooldown(&self, mac: Mac) {
        self.lock().cooldown_until.remove(&mac);
    }

    pub fn set_only(&self, only: Option<Mac>) {
        self.lock().only = only;
    }

    /// For [`ni_bootp::BootpHandle::set_policy`]: allow iff
    /// [`Gate::check`] says [`Verdict::Allow`] now.
    pub fn policy(&self) -> MacPolicy {
        let gate = self.clone();
        Arc::new(move |mac| gate.check(mac, Instant::now()) == Verdict::Allow)
    }
}
```

```rust
//! Checks before `start`: interface, addresses, ports, assets.
//!
//! The pure parts ([`check_network`]) take an interface list, so they are
//! tested without touching the machine; [`check_ports`] binds and releases
//! the listeners exactly as `start` would (no `SO_REUSEPORT`), so a running
//! DHCP/TFTP server (e.g. Internet Sharing's `bootpd`, launchd `tftpd`) or
//! another netinstall shows up as `port_in_use`.
//!
//! Not checkable: macOS's Local Network permission cannot be queried by an
//! app. Without it, sends to the local network fail with `EHOSTUNREACH`
//! (reported as `recv_error` / `bootp_send_failed` warnings later).

use crate::config::{resolve_network, subnet, EngineConfig, NetPlan};
use crate::event::Failure;
use crate::profile::{ConfigMode, Profile};
use ni_assets::Assets;
use ni_net::{bind_udp, list_interfaces, BindOptions, Interface, InterfaceKind, NetError};
use serde::{Deserialize, Serialize};

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "snake_case")]
pub enum Severity {
    /// `start` would fail or devices could not boot.
    Error,
    /// Works, but probably not what was meant.
    Warning,
}

/// One preflight result.
#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
pub struct Finding {
    pub severity: Severity,
    #[serde(flatten)]
    pub failure: Failure,
}

impl Finding {
    fn error(f: Failure) -> Self {
        Finding {
            severity: Severity::Error,
            failure: f,
        }
    }

    fn warning(f: Failure) -> Self {
        Finding {
            severity: Severity::Warning,
            failure: f,
        }
    }
}

/// All findings, plus the resolved network if the interface allowed it.
#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
pub struct PreflightReport {
    pub findings: Vec<Finding>,
    pub network: Option<NetPlan>,
}

impl PreflightReport {
    /// No [`Severity::Error`] findings.
    pub fn ok(&self) -> bool {
        self.findings.iter().all(|f| f.severity != Severity::Error)
    }
}

/// Interface and address checks. Errors: `unknown_interface`,
/// `interface_down`, `no_ipv4`, `server_ip_not_on_interface`, `no_mac`,
/// `invalid_netmask`, `server_ip_not_host`, `pool_inverted`,
/// `pool_outside_subnet`. Warnings: `link_down` (no cable yet?),
/// `unsuitable_interface` (`kind`: wifi, loopback, bridge, tunnel,
/// apple_wireless, other).
pub fn check_network(ifaces: &[Interface], cfg: &EngineConfig) -> (Vec<Finding>, Option<NetPlan>) {
    let mut out = Vec::new();
    let Some(iface) = ifaces.iter().find(|i| i.name == cfg.interface) else {
        let f = Failure::new("unknown_interface").with("interface", &cfg.interface);
        return (vec![Finding::error(f)], None);
    };
    if !iface.is_up {
        out.push(Finding::error(
            Failure::new("interface_down").with("interface", &iface.name),
        ));
    } else if !iface.is_running {
        out.push(Finding::warning(
            Failure::new("link_down").with("interface", &iface.name),
        ));
    }
    if iface.kind != InterfaceKind::Ethernet {
        out.push(Finding::warning(
            Failure::new("unsuitable_interface")
                .with("interface", &iface.name)
                .with("kind", iface.kind.as_str()),
        ));
    }
    let plan = match resolve_network(ifaces, cfg) {
        Ok(plan) => plan,
        Err(f) => {
            out.push(Finding::error(f));
            return (out, None);
        }
    };
    let mask = u32::from(plan.netmask);
    if mask.leading_ones() + mask.trailing_zeros() != 32 {
        out.push(Finding::error(
            Failure::new("invalid_netmask").with("netmask", plan.netmask),
        ));
        return (out, None);
    }
    let (net, bcast) = subnet(plan.server_ip, plan.netmask);
    if mask.leading_ones() <= 30 && (plan.server_ip == net || plan.server_ip == bcast) {
        out.push(Finding::error(
            Failure::new("server_ip_not_host").with("ip", plan.server_ip),
        ));
    }
    if u32::from(plan.pool_start) > u32::from(plan.pool_end) {
        out.push(Finding::error(
            Failure::new("pool_inverted")
                .with("start", plan.pool_start)
                .with("end", plan.pool_end),
        ));
    }
    let inside = |ip| subnet(ip, plan.netmask).0 == net;
    if !inside(plan.pool_start) || !inside(plan.pool_end) {
        out.push(Finding::error(
            Failure::new("pool_outside_subnet")
                .with("start", plan.pool_start)
                .with("end", plan.pool_end)
                .with("network", format!("{net}/{}", mask.leading_ones())),
        ));
    }
    (out, Some(plan))
}

/// Bind (and release) each listener as `start` would. Errors:
/// `port_in_use` (`service`, `port`), `bind_failed` (`service`, `detail`).
/// Ports given as 0 are skipped (they cannot collide).
pub fn check_ports(cfg: &EngineConfig) -> Vec<Finding> {
    let p = &cfg.ports;
    [
        ("bootp", p.bootp),
        ("tftp", p.tftp),
        ("netinstall", p.netinstall),
    ]
    .into_iter()
    .filter(|(_, port)| *port != 0)
    .filter_map(|(service, port)| {
        let opts = BindOptions::new(port)
            .addr(p.bind_ip)
            .interface(cfg.interface.clone());
        bind_udp(&opts)
            .err()
            .map(|e| Finding::error(bind_failure(service, &e)))
    })
    .collect()
}

/// A failed listener bind as a [`Failure`]: `port_in_use` for
/// `AddrInUse`, `unknown_interface`, else `bind_failed`.
pub fn bind_failure(service: &str, e: &NetError) -> Failure {
    match e {
        NetError::AddrInUse { port } => Failure::new("port_in_use")
            .with("service", service)
            .with("port", port),
        NetError::UnknownInterface(name) => {
            Failure::new("unknown_interface").with("interface", name)
        }
        other => Failure::new("bind_failed")
            .with("service", service)
            .with("detail", other),
    }
}

/// Can the profile's assets be had? Errors: `version_unavailable`
/// (`cause`: the asset error code), `script_missing`. Warning:
/// `kernels_not_cached` (they will be downloaded at start).
pub async fn check_assets(assets: &Assets, profile: &Profile) -> Vec<Finding> {
    let mut out = Vec::new();
    if let Err(f) = profile.validate() {
        return vec![Finding::error(f)];
    }
    match assets.resolve(&profile.version).await {
        Err(e) => out.push(Finding::error(
            Failure::new("version_unavailable")
                .with("cause", e.code())
                .with("detail", &e),
        )),
        Ok(version) => {
            let cached = assets.cached_versions().await.unwrap_or_default();
            if !cached.contains(&version) {
                out.push(Finding::warning(
                    Failure::new("kernels_not_cached").with("version", &version),
                ));
            }
        }
    }
    if let ConfigMode::CustomScript { local_name } = &profile.config {
        if let Err(e) = assets.local_file(local_name).await {
            out.push(Finding::error(
                Failure::new("script_missing")
                    .with("name", local_name)
                    .with("cause", e.code()),
            ));
        }
    }
    out
}

/// Everything: network (with the live interface list), ports, and the
/// assets of `profile` if given.
pub async fn run(
    cfg: &EngineConfig,
    assets: Option<&Assets>,
    profile: Option<&Profile>,
) -> PreflightReport {
    let ifaces = list_interfaces().unwrap_or_default();
    let (mut findings, network) = check_network(&ifaces, cfg);
    if network.is_some() {
        findings.extend(check_ports(cfg));
    }
    if let (Some(assets), Some(profile)) = (assets, profile) {
        findings.extend(check_assets(assets, profile).await);
    }
    PreflightReport { findings, network }
}
```

```rust
//! Turning a profile and a device's arch into an [`InstallPlan`], and
//! fetching the boot kernels.

use crate::event::Failure;
use crate::profile::{ConfigMode, Profile};
use ni_assets::{kernel_file_name, AssetError, Assets, KernelSet, PkgArch, Version, VersionSpec};
use ni_bootp::BootArch;
use ni_proto::InstallPlan;
use ni_tftp::FileMap;
use std::collections::HashMap;

/// An asset error as a device/engine failure: `code` with the asset
/// error's code as `cause`.
pub fn asset_failure(code: &str, e: &AssetError) -> Failure {
    Failure::new(code).with("cause", e.code()).with("detail", e)
}

/// Resolve the profile's version (or use `version` if the caller resolved
/// it already), then fetch packages and the script. Errors:
/// `assets_failed` (`cause`), `invalid_plan` (`detail`).
pub async fn prepare(
    assets: &Assets,
    profile: &Profile,
    version: Option<Version>,
    device_arch: &str,
) -> Result<InstallPlan, Failure> {
    let fail = |e: AssetError| asset_failure("assets_failed", &e);
    let arch = PkgArch::from_device_arch(device_arch).map_err(|e| fail(e.into()))?;
    let version = match version {
        Some(v) => v,
        None => assets.resolve(&profile.version).await.map_err(fail)?,
    };
    let packages = assets
        .ensure_packages(&version, arch, &profile.extra_packages)
        .await
        .map_err(fail)?;
    let config_script = match &profile.config {
        ConfigMode::Default => None,
        ConfigMode::CustomScript { local_name } => {
            Some(assets.local_file(local_name).await.map_err(fail)?)
        }
    };
    let plan = InstallPlan {
        packages,
        config_script,
    };
    plan.validate()
        .map_err(|e| Failure::new("invalid_plan").with("detail", e))?;
    Ok(plan)
}

/// Kernels for `spec`. If the version cannot be resolved (offline), the
/// newest version with a complete cached kernel set is used instead, and
/// the second value is `true`.
pub async fn kernels(
    assets: &Assets,
    spec: &VersionSpec,
) -> Result<(Version, KernelSet, bool), Failure> {
    let (version, fallback) = match assets.resolve(spec).await {
        Ok(v) => (v, false),
        Err(e) => {
            let cached = assets.cached_versions().await.unwrap_or_default();
            match cached.into_iter().max() {
                Some(v) => (v, true),
                None => return Err(asset_failure("kernels_unavailable", &e)),
            }
        }
    };
    let set = assets
        .ensure_kernels(&version)
        .await
        .map_err(|e| asset_failure("kernels_unavailable", &e))?;
    Ok((version, set, fallback))
}

/// The BOOTP boot file map and the TFTP file map for a kernel set.
pub fn boot_maps(set: &KernelSet) -> (HashMap<BootArch, String>, FileMap) {
    let mut boot = HashMap::new();
    let mut files = FileMap::new();
    for (&arch, data) in set {
        let name = kernel_file_name(arch);
        boot.insert(arch, name.clone());
        files.insert(name, data.clone());
    }
    (boot, files)
}
```

```rust
/// The next event matching `pred` (others are skipped); panics after
/// [`WAIT`].
pub async fn next(
    events: &mut broadcast::Receiver<EngineEvent>,
    pred: impl Fn(&EngineEvent) -> bool,
) -> EngineEvent {
    let end = tokio::time::Instant::now() + WAIT;
    loop {
        match tokio::time::timeout_at(end, events.recv()).await {
            Ok(Ok(e)) if pred(&e) => return e,
            Ok(Ok(_)) => {}
            Ok(Err(e)) => panic!("event stream: {e}"),
            Err(_) => panic!("no matching event within {WAIT:?}"),
        }
    }
}

/// Wait for `mac` to enter the state named `state`.
pub async fn state(
    events: &mut broadcast::Receiver<EngineEvent>,
    mac: Mac,
    state: &str,
) -> EngineEvent {
    next(
        events,
        |e| matches!(e, EngineEvent::Device { mac: m, state: s } if *m == mac && s.name() == state),
    )
    .await
}

/// Collect events until `mac` is done or failed; returns them all.
pub async fn until_finished(
    events: &mut broadcast::Receiver<EngineEvent>,
    mac: Mac,
) -> Vec<EngineEvent> {
    let mut seen = Vec::new();
    loop {
        let e = next(events, |_| true).await;
        let end = matches!(&e, EngineEvent::Device { mac: m, state } if *m == mac && matches!(state.name(), "done" | "failed"));
        seen.push(e);
        if end {
            return seen;
        }
    }
}

/// The state names `mac` went through, in order.
pub fn states(events: &[EngineEvent], mac: Mac) -> Vec<&'static str> {
    events
        .iter()
        .filter_map(|e| match e {
            EngineEvent::Device { mac: m, state } if *m == mac => Some(state.name()),
            _ => None,
        })
        .collect()
}
```

```rust
//! The engine: one tokio task owning the Netinstall socket, all install
//! sessions (one per device MAC) and the BOOTP/TFTP runner tasks.
//!
//! Commands go in through an [`EngineHandle`] (an mpsc channel); events
//! come out on a bounded `tokio::sync::broadcast` channel
//! ([`EngineHandle::subscribe`]). A slow subscriber misses events
//! (`RecvError::Lagged`) instead of slowing the engine down;
//! [`EngineHandle::snapshot`] gives the full current state at any time.
//!
//! The task ends (stopping everything) when the last handle is dropped.

mod core;
mod device;
mod start;

use crate::config::{EngineConfig, NetPlan};
use crate::event::{DeviceInfoView, DeviceState, EngineEvent, Failure, StartInfo};
use crate::prepare::asset_failure;
use crate::profile::Profile;

use serde::{Deserialize, Serialize};

use std::path::PathBuf;
use std::sync::Arc;
use tokio::sync::{broadcast, mpsc, oneshot};

/// Capacity of the event broadcast channel.
pub const EVENT_CAPACITY: usize = 1024;

/// One device in a [`Snapshot`].
#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
pub struct DeviceView {
    #[serde(with = "crate::event::mac_str")]
    pub mac: Mac,
    pub ip: Option<Ipv4Addr>,
    pub boot_arch: Option<String>,
    pub info: Option<DeviceInfoView>,
    /// Name of the profile assigned with `flash` (or in use).
    pub profile: Option<String>,
    pub state: DeviceState,
}

/// The engine's state at one moment.
#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
pub struct Snapshot {
    pub running: bool,
    pub started: Option<StartInfo>,
    pub network: Option<NetPlan>,
    /// Version of the boot kernels being served, once ready.
    pub kernel_version: Option<String>,
    pub auto_repeat: bool,
    /// Name of the active profile.
    pub profile: Option<String>,
    /// Sorted by MAC.
    pub devices: Vec<DeviceView>,
}

type Reply<T> = oneshot::Sender<Result<T, Failure>>;

pub(crate) enum Command {
    Start(Box<EngineConfig>, Reply<StartInfo>),
    Stop(Reply<()>),
    Flash(Mac, Box<Profile>, Reply<()>),
    Retry(Mac, Reply<()>),
    AutoRepeat(bool, Reply<()>),
    Snapshot(oneshot::Sender<Snapshot>),
}

/// Controls a running engine task. Cheap to clone.
#[derive(Clone)]
pub struct EngineHandle {
    cmds: mpsc::Sender<Command>,
    events: broadcast::Sender<EngineEvent>,
    assets: Arc<Assets>,
}

fn gone() -> Failure {
    Failure::new("engine_gone")
}

/// Asset downloads as engine events (cache hits are not reported).
fn download_event(e: AssetEvent) -> Option<EngineEvent> {
    match e {
        AssetEvent::DownloadStarted { file, total } => Some(EngineEvent::Download {
            file,
            done: 0,
            total,
        }),
        AssetEvent::DownloadProgress { file, done, total } => {
            Some(EngineEvent::Download { file, done, total })
        }
        AssetEvent::DownloadFinished { file, size } => Some(EngineEvent::Download {
            file,
            done: size,
            total: Some(size),
        }),
        AssetEvent::CacheHit { .. } => None,
    }
}

impl EngineHandle {
    /// Create the asset cache at `cache_root` and spawn the engine task
    /// (idle until [`EngineHandle::start`]). Must be called inside a tokio
    /// runtime. Error: `assets_failed`.
    pub fn spawn(cache_root: impl Into<PathBuf>, http: HttpConfig) -> Result<Self, Failure> {
        let (events, _) = broadcast::channel(EVENT_CAPACITY);
        let sink = events.clone();
        let assets = Assets::new(cache_root, http)
            .map_err(|e| asset_failure("assets_failed", &e))?
            .with_events(Arc::new(move |e| {
                if let Some(ev) = download_event(e) {
                    let _ = sink.send(ev);
                }
            }));
        let assets = Arc::new(assets);
        let (cmds, rx) = mpsc::channel(32);
        tokio::spawn(core::run(assets.clone(), events.clone(), rx));
        Ok(EngineHandle {
            cmds,
            events,
            assets,
        })
    }

    /// Events from now on.
    pub fn subscribe(&self) -> broadcast::Receiver<EngineEvent> {
        self.events.subscribe()
    }

    /// The engine's asset manager (for preflight, registering scripts, ...).
    pub fn assets(&self) -> &Arc<Assets> {
        &self.assets
    }

    async fn call<T>(
        &self,
        make: impl FnOnce(oneshot::Sender<T>) -> Command,
    ) -> Result<T, Failure> {
        let (tx, rx) = oneshot::channel();
        self.cmds.send(make(tx)).await.map_err(|_| gone())?;
        rx.await.map_err(|_| gone())
    }

    /// Bind the listeners and start serving. Boot kernels are fetched in
    /// the background ([`EngineEvent::KernelsReady`]). Errors:
    /// `already_running`, `invalid_profile`-family codes, network codes
    /// from [`crate::resolve_network`], `invalid_network`, `port_in_use`,
    /// `bind_failed`.
    pub async fn start(&self, cfg: EngineConfig) -> Result<StartInfo, Failure> {
        self.call(|tx| Command::Start(Box::new(cfg), tx)).await?
    }

    /// Cancel all sessions and release the ports. Error: `not_running`.
    pub async fn stop(&self) -> Result<(), Failure> {
        self.call(Command::Stop).await?
    }

    /// Install `profile` on a device. A device that has not said hello yet
    /// keeps the profile for when it does. Errors: `not_running`,
    /// `unknown_device`, `device_busy`, `device_done`, profile validation.
    pub async fn flash(&self, mac: Mac, profile: Profile) -> Result<(), Failure> {
        self.call(|tx| Command::Flash(mac, Box::new(profile), tx))
            .await?
    }

    /// Re-arm a failed device. Errors: `not_running`, `unknown_device`,
    /// `not_failed`.
    pub async fn retry(&self, mac: Mac) -> Result<(), Failure> {
        self.call(|tx| Command::Retry(mac, tx)).await?
    }

    /// With auto-repeat on, waiting devices get the active profile.
    /// Errors: `not_running`, `no_profile` (turning it on without one).
    pub async fn set_auto_repeat(&self, on: bool) -> Result<(), Failure> {
        self.call(|tx| Command::AutoRepeat(on, tx)).await?
    }

    pub async fn snapshot(&self) -> Result<Snapshot, Failure> {
        self.call(Command::Snapshot).await
    }
}
```

```rust
/// Capacity of each runner's event channel (events beyond are dropped).
pub(crate) const RUNNER_EVENTS: usize = 256;
/// TFTP progress granularity.
pub(crate) const TFTP_PROGRESS_STEP: u64 = 64 * 1024;

/// Run a server future; report its end (it only ends on a fatal error).
fn spawn_runner(
    service: &'static str,
    server: impl Future<Output = io::Result<()>> + Send + 'static,
    internal: mpsc::Sender<Internal>,
    epoch: u64,
) -> JoinHandle<()> {
    tokio::spawn(async move {
        let detail = match server.await {
            Ok(()) => "stopped".to_string(),
            Err(e) => e.to_string(),
        };
        let _ = internal
            .send(Internal::RunnerExited {
                epoch,
                service,
                detail,
            })
            .await;
    })
}

pub(crate) fn start(
    cfg: EngineConfig,
    assets: Arc<Assets>,
    internal: mpsc::Sender<Internal>,
    epoch: u64,
) -> Result<(Running, Io), Failure> {
    if let Some(p) = &cfg.profile {
        p.validate()?;
    }
    let ifaces =
        list_interfaces().map_err(|e| Failure::new("interface_list_failed").with("detail", e))?;
    let net = resolve_network(&ifaces, &cfg)?;
    let responder = BootpResponder::new(BootpConfig {
        server_ip: net.server_ip,
        netmask: net.netmask,
        pool_start: net.pool_start,
        pool_end: net.pool_end,
        boot_files: HashMap::new(),
        lease_secs: cfg.lease_secs,
    })
    .map_err(|e| Failure::new("invalid_network").with("detail", e))?;
    let bind = |service: &str, port: u16, broadcast: bool| {
        let opts = BindOptions::new(port)
            .addr(cfg.ports.bind_ip)
            .interface(cfg.interface.clone())
            .broadcast(broadcast);
        bind_udp(&opts).map_err(|e| bind_failure(service, &e))
    };
    let bootp_sock = bind("bootp", cfg.ports.bootp, true)?;
    let tftp_sock = bind("tftp", cfg.ports.tftp, false)?;
    let socket = bind("netinstall", cfg.ports.netinstall, true)?;
    let public = |s: &UdpSocket| -> Result<SocketAddr, Failure> {
        let a = s
            .local_addr()
            .map_err(|e| Failure::new("bind_failed").with("detail", e))?;
        Ok(if a.ip().is_unspecified() {
            SocketAddr::from((net.server_ip, a.port()))
        } else {
            a
        })
    };
    let info = StartInfo {
        interface: cfg.interface.clone(),
        server_ip: net.server_ip,
        bootp: public(&bootp_sock)?,
        tftp: public(&tftp_sock)?,
        netinstall: public(&socket)?,
    };

    let gate = Gate::default();
    gate.set_only(cfg.only_mac);
    let bootp = BootpHandle::new(responder);
    bootp.set_policy(Some(gate.policy()));
    let (bootp_tx, bootp_rx) = mpsc::channel(RUNNER_EVENTS);
    let (tftp_tx, tftp_rx) = mpsc::channel(RUNNER_EVENTS);
    let (files_tx, files_rx) = watch::channel(Arc::new(FileMap::new()));
    let tftp_cfg = TftpConfig {
        transfer: cfg.tftp.clone(),
        server_ip: net.server_ip,
        interface: Some(cfg.interface.clone()),
    };
    let mut tasks = vec![
        spawn_runner(
            "bootp",
            serve_shared(
                bootp_sock,
                bootp.clone(),
                cfg.ports.bootp_reply_to,
                bootp_tx,
            ),
            internal.clone(),
            epoch,
        ),
        spawn_runner(
            "tftp",
            serve_watched(tftp_sock, files_rx, tftp_cfg, TFTP_PROGRESS_STEP, tftp_tx),
            internal.clone(),
            epoch,
        ),
    ];
    let spec = cfg
        .profile
        .as_ref()
        .map(|p| p.version.clone())
        .unwrap_or(VersionSpec::Channel(Channel::Stable));
    let kernel_assets = assets.clone();
    let kernel_tx = internal.clone();
    tasks.push(tokio::spawn(async move {
        let result = kernels(&kernel_assets, &spec).await;
        let _ = kernel_tx.send(Internal::Kernels { epoch, result }).await;
    }));
    let next_link_check = cfg.link_check.map(|d| Instant::now() + d);
    let running = Running {
        cfg,
        net,
        info,
        bootp,
        tftp_files: files_tx,
        tasks,
        gate,
        devices: BTreeMap::new(),
        kernel_version: None,
        queue_seq: 0,
        ignored: HashMap::new(),
        next_link_check,
    };
    let io = Io {
        socket,
        bootp_rx,
        tftp_rx,
        recv_errors: Default::default(),
    };
    Ok((running, io))
}
```

```rust
use ni_tftp::{FileMap, TftpEvent};
use std::collections::{BTreeMap, HashMap};
use std::future::pending;
use std::io;
use std::net::{IpAddr, SocketAddr};
use std::sync::Arc;
use std::time::{Duration, Instant};
use tokio::net::UdpSocket;
use tokio::sync::{broadcast, mpsc, watch};
use tokio::task::JoinHandle;
use tracing::{debug, info, warn};

/// Minimum time between two throttled progress states of one device.
const PROGRESS_INTERVAL: Duration = Duration::from_millis(200);
/// Minimum time between two `ignored` events per device and reason.
const IGNORED_INTERVAL: Duration = Duration::from_secs(10);

/// Messages from tasks the engine spawned.
pub(crate) enum Internal {
    Kernels {
        epoch: u64,
        result: Result<(Version, KernelSet, bool), Failure>,
    },
    Prepared {
        epoch: u64,
        mac: Mac,
        attempt: u64,
        result: Result<InstallPlan, Failure>,
    },
    RunnerExited {
        epoch: u64,
        service: &'static str,
        detail: String,
    },
}

/// Sockets and channels the loop polls while running.
pub(crate) struct Io {
    pub socket: UdpSocket,
    pub bootp_rx: mpsc::Receiver<BootpEvent>,
    pub tftp_rx: mpsc::Receiver<TftpEvent>,
    pub recv_errors: RecvErrorGuard,
}

/// State while started.
pub(crate) struct Running {
    pub cfg: EngineConfig,
    pub net: NetPlan,
    pub info: StartInfo,
    pub bootp: BootpHandle,
    pub tftp_files: watch::Sender<Arc<FileMap>>,
    /// Runners, the kernel download and preparations; aborted on stop.
    pub tasks: Vec<JoinHandle<()>>,
    pub gate: Gate,
    pub devices: BTreeMap<Mac, Device>,
    pub kernel_version: Option<Version>,
    pub queue_seq: u64,
    pub ignored: HashMap<(Mac, &'static str), Instant>,
    pub next_link_check: Option<Instant>,
}

struct Core {
    assets: Arc<Assets>,
    events: broadcast::Sender<EngineEvent>,
    internal: mpsc::Sender<Internal>,
    epoch: u64,
    run: Option<Running>,
}

async fn recv_opt<T>(rx: Option<&mut mpsc::Receiver<T>>) -> Option<T> {
    match rx {
        Some(rx) => rx.recv().await,
        None => pending().await,
    }
}

/// Receive a datagram; transient errors are returned after a short
/// backoff, so a persistent error cannot spin the loop.
async fn recv_from_opt(
    socket: Option<&UdpSocket>,
    buf: &mut [u8],
) -> io::Result<(usize, SocketAddr)> {
    let Some(socket) = socket else {
        return pending().await;
    };
    let r = socket.recv_from(buf).await;
    if matches!(&r, Err(e) if ni_net::is_transient_recv_error(e)) {
        tokio::time::sleep(RecvErrorGuard::BACKOFF).await;
    }
    r
}

async fn sleep_opt(deadline: Option<Instant>) {
    match deadline {
        Some(t) => tokio::time::sleep_until(t.into()).await,
        None => pending().await,
    }
}

pub(crate) async fn run(
    assets: Arc<Assets>,
    events: broadcast::Sender<EngineEvent>,
    mut cmds: mpsc::Receiver<Command>,
) {
    let (internal, mut internal_rx) = mpsc::channel(64);
    let mut core = Core {
        assets,
        events,
        internal,
        epoch: 0,
        run: None,
    };
    let mut io: Option<Io> = None;
    let mut buf = vec![0u8; 2048];
    loop {
        let deadline = core.next_deadline();
        let (socket, bootp_rx, tftp_rx) = match io.as_mut() {
            Some(io) => (
                Some(&io.socket),
                Some(&mut io.bootp_rx),
                Some(&mut io.tftp_rx),
            ),
            None => (None, None, None),
        };
        tokio::select! {
            cmd = cmds.recv() => match cmd {
                Some(cmd) => core.command(cmd, &mut io),
                None => {
                    core.stop(&mut io);
                    return;
                }
            },
            Some(msg) = internal_rx.recv() => core.internal(msg, &mut io),
            Some(ev) = recv_opt(bootp_rx) => core.on_bootp(ev),
            Some(ev) = recv_opt(tftp_rx) => core.on_tftp(ev),
            r = recv_from_opt(socket, &mut buf) => core.on_datagram(r, &buf, &mut io),
            _ = sleep_opt(deadline) => {}
        }
        core.drive(&mut io).await;
    }
}

impl Core {
    fn emit(&self, e: EngineEvent) {
        let _ = self.events.send(e);
    }

    fn next_deadline(&self) -> Option<Instant> {
        let run = self.run.as_ref()?;
        run.devices
            .values()
            .filter_map(|d| d.session.as_ref()?.poll_timeout())
            .chain(run.next_link_check)
            .min()
    }

    // ------------------------------------------------------------ commands

    fn command(&mut self, cmd: Command, io: &mut Option<Io>) {
        match cmd {
            Command::Start(cfg, reply) => {
                let _ = reply.send(self.start(*cfg, io));
            }
            Command::Stop(reply) => {
                let r = match self.run {
                    None => Err(Failure::new("not_running")),
                    Some(_) => {
                        self.stop(io);
                        Ok(())
                    }
                };
                let _ = reply.send(r);
            }
            Command::Flash(mac, profile, reply) => {
                let _ = reply.send(self.flash(mac, *profile));
            }
            Command::Retry(mac, reply) => {
                let _ = reply.send(self.retry(mac));
            }
            Command::AutoRepeat(on, reply) => {
                let _ = reply.send(self.set_auto_repeat(on));
            }
            Command::Snapshot(reply) => {
                let _ = reply.send(self.snapshot());
            }
        }
    }

    fn start(&mut self, cfg: EngineConfig, io: &mut Option<Io>) -> Result<StartInfo, Failure> {
        if self.run.is_some() {
            return Err(Failure::new("already_running"));
        }
        let epoch = self.epoch + 1;
        let (running, new_io) = start(cfg, self.assets.clone(), self.internal.clone(), epoch)?;
        self.epoch = epoch;
        let info = running.info.clone();
        info!(interface = %info.interface, server_ip = %info.server_ip, "engine started");
        self.run = Some(running);
        *io = Some(new_io);
        self.emit(EngineEvent::Started(info.clone()));
        Ok(info)
    }

    fn stop(&mut self, io: &mut Option<Io>) {
        let Some(mut run) = self.run.take() else {
            return;
        };
        *io = None;
        for task in run.tasks.drain(..) {
            task.abort();
        }
        for dev in run.devices.values_mut() {
            if dev.is_active() {
                if let Some(s) = dev.session.as_mut() {
                    s.cancel();
                }
                self.emit(EngineEvent::Device {
                    mac: dev.mac,
                    state: DeviceState::failed(Failure::new("cancelled")),
                });
            }
        }
        info!("engine stopped");
        self.emit(EngineEvent::Stopped);
    }

    fn running(&mut self) -> Result<&mut Running, Failure> {
        self.run.as_mut().ok_or_else(|| Failure::new("not_running"))
    }

    fn flash(&mut self, mac: Mac, profile: Profile) -> Result<(), Failure> {
        profile.validate()?;
        let run = self.running()?;
        let dev = run
            .devices
            .get_mut(&mac)
            .ok_or_else(|| Failure::new("unknown_device").with("mac", mac))?;
        if dev.is_active() {
            return Err(Failure::new("device_busy").with("mac", mac));
        }
        if dev.is("done") {
            return Err(Failure::new("device_done").with("mac", mac));
        }
        dev.assigned = Some(profile.clone());
        if dev.info.is_some() {
            self.enqueue(mac, profile);
        }
        Ok(())
    }

    fn retry(&mut self, mac: Mac) -> Result<(), Failure> {
        let run = self.running()?;
        let dev = run
            .devices
            .get(&mac)
            .ok_or_else(|| Failure::new("unknown_device").with("mac", mac))?;
        if !dev.is("failed") {
            return Err(Failure::new("not_failed").with("mac", mac));
        }
        run.gate.clear_cooldown(mac);
        if dev.info.is_some() {
            self.route(mac);
        } else {
            // Failed before its hello (boot kernel transfer): forget it; its
            // next BOOTP request starts over.
            run.devices.remove(&mac);
        }
        Ok(())
    }

    fn set_auto_repeat(&mut self, on: bool) -> Result<(), Failure> {
        let run = self.running()?;
        if on && run.cfg.profile.is_none() {
            return Err(Failure::new("no_profile"));
        }
        run.cfg.auto_repeat = on;
        let waiting: Vec<Mac> = run
            .devices
            .values()
            .filter(|d| {
                d.state
                    == Some(DeviceState::Waiting {
                        reason: WaitReason::NoProfile,
                    })
            })
            .map(|d| d.mac)
            .collect();
        for mac in waiting {
            self.route(mac);
        }
        Ok(())
    }

    fn snapshot(&self) -> Snapshot {
        match &self.run {
            None => Snapshot {
                running: false,
                started: None,
                network: None,
                kernel_version: None,
                auto_repeat: false,
                profile: None,
                devices: Vec::new(),
            },
            Some(run) => Snapshot {
                running: true,
                started: Some(run.info.clone()),
                network: Some(run.net.clone()),
                kernel_version: run.kernel_version.as_ref().map(|v| v.to_string()),
                auto_repeat: run.cfg.auto_repeat,
                profile: run.cfg.profile.as_ref().map(|p| p.name.clone()),
                devices: run.devices.values().filter_map(Device::view).collect(),
            },
        }
    }

    // ------------------------------------------------------------ devices

    /// Set a device's state; report it if it changed.
    fn set_state(&mut self, mac: Mac, state: DeviceState) {
        let Some(run) = self.run.as_mut() else { return };
        let Some(dev) = run.devices.get_mut(&mac) else {
            return;
        };
        if dev.state.as_ref() == Some(&state) {
            return;
        }
        debug!(%mac, state = state.name(), "device state");
        dev.state = Some(state.clone());
        self.emit(EngineEvent::Device { mac, state });
    }

    fn ignored(&mut self, mac: Mac, reason: &'static str, now: Instant) {
        let Some(run) = self.run.as_mut() else { return };
        let last = run.ignored.get(&(mac, reason));
        if last.is_some_and(|t| now.saturating_duration_since(*t) < IGNORED_INTERVAL) {
            return;
        }
        run.ignored.insert((mac, reason), now);
        debug!(%mac, reason, "device ignored");
        self.emit(EngineEvent::Ignored {
            mac,
            reason: reason.to_string(),
        });
    }

    fn warning(&self, f: Failure) {
        warn!(code = %f.code, "{f}");
        self.emit(EngineEvent::Warning(f));
    }

    /// A discovered (or re-armed) device: queue it with its profile, or
    /// wait for one.
    fn route(&mut self, mac: Mac) {
        let Some(run) = self.run.as_mut() else { return };
        let Some(dev) = run.devices.get(&mac) else {
            return;
        };
        let active = run
            .cfg
            .auto_repeat
            .then(|| run.cfg.profile.clone())
            .flatten();
        match dev.assigned.clone().or(active) {
            Some(profile) => self.enqueue(mac, profile),
            None => self.set_state(
                mac,
                DeviceState::Waiting {
                    reason: WaitReason::NoProfile,
                },
            ),
        }
    }

    fn enqueue(&mut self, mac: Mac, profile: Profile) {
        let Some(run) = self.run.as_mut() else { return };
        let seq = run.queue_seq;
        run.queue_seq += 1;
        let Some(dev) = run.devices.get_mut(&mac) else {
            return;
        };
        dev.using = Some(profile);
        dev.queued = Some(seq);
        let active = run.devices.values().filter(|d| d.is_active()).count();
        if active < run.cfg.max_parallel.max(1) {
            self.start_prepare(mac);
        } else {
            self.set_state(
                mac,
                DeviceState::Waiting {
                    reason: WaitReason::Concurrency,
                },
            );
        }
    }

    /// Start queued devices while slots are free, oldest first.
    fn admit(&mut self) {
        loop {
            let Some(run) = self.run.as_ref() else { return };
            let active = run.devices.values().filter(|d| d.is_active()).count();
            if active >= run.cfg.max_parallel.max(1) {
                return;
            }
            let next = run
                .devices
                .values()
                .filter(|d| d.is("waiting"))
                .filter_map(|d| Some((d.queued?, d.mac)))
                .min();
            match next {
                Some((_, mac)) => self.start_prepare(mac),
                None => return,
            }
        }
    }

    fn start_prepare(&mut self, mac: Mac) {
        let epoch = self.epoch;
        let assets = self.assets.clone();
        let internal = self.internal.clone();
        let Some(run) = self.run.as_mut() else { return };
        let active_spec = run.cfg.profile.as_ref().map(|p| p.version.clone());
        let kernel_version = run.kernel_version.clone();
        let Some(dev) = run.devices.get_mut(&mac) else {
            return;
        };
        let (Some(profile), Some(info)) = (dev.using.clone(), dev.info.clone()) else {
            return;
        };
        dev.queued = None;
        dev.attempt += 1;
        let attempt = dev.attempt;
        let version = kernel_version.filter(|_| active_spec.as_ref() == Some(&profile.version));
        run.tasks.retain(|t| !t.is_finished());
        run.tasks.push(tokio::spawn(async move {
            let result = prepare(&assets, &profile, version, &info.arch).await;
            let _ = internal
                .send(Internal::Prepared {
                    epoch,
                    mac,
                    attempt,
                    result,
                })
                .await;
        }));
        self.set_state(mac, DeviceState::Preparing);
    }

    fn prepared(&mut self, mac: Mac, attempt: u64, result: Result<InstallPlan, Failure>) {
        let Some(run) = self.run.as_mut() else { return };
        let session_cfg = run.cfg.session.clone();
        let server_mac = run.net.server_mac;
        let Some(dev) = run.devices.get_mut(&mac) else {
            return;
        };
        if dev.attempt != attempt || !dev.is("preparing") {
            return;
        }
        let state = match result {
            Err(f) => DeviceState::failed(f),
            Ok(plan) => {
                let info = dev.info.clone().expect("prepared devices have said hello");
                match ServerSession::new(server_mac, info, &plan, session_cfg, Instant::now()) {
                    Ok(session) => {
                        dev.session = Some(session);
                        dev.last_progress = None;
                        DeviceState::Flashing {
                            phase: "offering".into(),
                            sent: 0,
                            total: plan.total_bytes(),
                        }
                    }
                    Err(e) => DeviceState::failed(Failure::new("invalid_plan").with("detail", e)),
                }
            }
        };
        self.set_state(mac, state);
        self.admit();
    }

    fn on_hello(&mut self, info: DeviceInfo, now: Instant) {
        let mac = info.mac;
        let Some(run) = self.run.as_mut() else { return };
        let verdict = run.gate.check(mac, now);
        if verdict != Verdict::Allow {
            self.ignored(mac, verdict.reason(), now);
            return;
        }
        let dev = run.devices.entry(mac).or_insert_with(|| Device::new(mac));
        if dev.is("done") {
            // The cooldown is over: a new round for this device.
            *dev = Device::new(mac);
        }
        if dev.info.is_some() {
            return; // already discovered (waiting, flashing, failed, ...)
        }
        dev.info = Some(info.clone());
        info!(%mac, model = %info.model, arch = %info.arch, "device discovered");
        self.emit(EngineEvent::Discovered {
            mac,
            info: DeviceInfoView::from(&info),
        });
        self.set_state(mac, DeviceState::Discovered);
        self.route(mac);
    }

    // ------------------------------------------------------------ inputs

    fn on_datagram(&mut self, r: io::Result<(usize, SocketAddr)>, buf: &[u8], io: &mut Option<Io>) {
        let now = Instant::now();
        let n = match r {
            Ok((n, _)) => {
                if let Some(io) = io.as_mut() {
                    io.recv_errors.on_success();
                }
                n
            }
            Err(e) => {
                let Some(guard) = io.as_mut().map(|io| &mut io.recv_errors) else {
                    return;
                };
                match guard.on_error(&e, now) {
                    RecvErrorAction::Fatal => {
                        self.emit(EngineEvent::Error(
                            Failure::new("runner_failed")
                                .with("service", "netinstall")
                                .with("detail", e),
                        ));
                        self.stop(io);
                    }
                    RecvErrorAction::Retry {
                        report: Some(count),
                    } => self.warning(
                        Failure::new("recv_error")
                            .with("service", "netinstall")
                            .with("count", count)
                            .with("detail", e),
                    ),
                    RecvErrorAction::Retry { report: None } => {}
                }
                return;
            }
        };
        let Ok(frame) = Frame::decode(&buf[..n]) else {
            return;
        };
        let Some(run) = self.run.as_mut() else { return };
        if frame.src == run.net.server_mac {
            return; // our own broadcast
        }
        if let Some(session) = run
            .devices
            .get_mut(&frame.src)
            .and_then(|d| d.session.as_mut())
        {
            session.handle_frame(&frame, now);
            return;
        }
        if DeviceInfo::is_hello(&frame) {
            if let Some(info) = DeviceInfo::parse(&frame) {
                self.on_hello(info, now);
            }
        }
    }

    fn on_bootp(&mut self, ev: BootpEvent) {
        let now = Instant::now();
        let Some(run) = self.run.as_mut() else { return };
        match ev {
            BootpEvent::Replied { mac, arch, ip, .. } => {
                let dev = run.devices.entry(mac).or_insert_with(|| Device::new(mac));
                if dev.is_active() {
                    debug!(%mac, "BOOTP from a device being flashed");
                    return;
                }
                if dev.is("done") {
                    *dev = Device::new(mac);
                }
                dev.boot_arch = Some(arch);
                dev.ip = Some(ip);
                dev.info = None;
                dev.queued = None;
                self.set_state(
                    mac,
                    DeviceState::BootpSeen {
                        boot_arch: arch.as_str().to_string(),
                        ip,
                    },
                );
            }
            BootpEvent::Ignored { mac, reason } => match reason {
                IgnoreReason::Denied(_) => {
                    let verdict = run.gate.check(mac, now);
                    if verdict != Verdict::Allow {
                        self.ignored(mac, verdict.reason(), now);
                    }
                }
                IgnoreReason::NoBootFile(_) => self.ignored(mac, "no_boot_file", now),
                IgnoreReason::PoolExhausted(_) => self.ignored(mac, "pool_exhausted", now),
                IgnoreReason::UnsupportedDevice(_) => self.ignored(mac, "unsupported_device", now),
                other => debug!(%mac, ?other, "BOOTP request ignored"),
            },
            BootpEvent::SendFailed { mac, error } => self.warning(
                Failure::new("bootp_send_failed")
                    .with("mac", mac)
                    .with("detail", error),
            ),
            BootpEvent::RecvError { error, count } => self.warning(
                Failure::new("recv_error")
                    .with("service", "bootp")
                    .with("count", count)
                    .with("detail", error),
            ),
            other => debug!(?other, "BOOTP"),
        }
    }

    /// The device a TFTP peer belongs to, by its BOOTP lease.
    fn tftp_device(&self, peer: SocketAddr) -> Option<Mac> {
        let run = self.run.as_ref()?;
        let IpAddr::V4(ip) = peer.ip() else {
            return None;
        };
        let mac = run.bootp.mac_of(ip)?;
        let dev = run.devices.get(&mac)?;
        (!dev.is_active() && dev.info.is_none()).then_some(mac)
    }

    fn on_tftp(&mut self, ev: TftpEvent) {
        match ev {
            TftpEvent::Started { peer, size, .. } => {
                if let Some(mac) = self.tftp_device(peer) {
                    self.set_state(
                        mac,
                        DeviceState::KernelServing {
                            sent: 0,
                            total: size,
                        },
                    );
                }
            }
            TftpEvent::Progress {
                peer, acked, size, ..
            } => {
                if let Some(mac) = self.tftp_device(peer) {
                    let state = DeviceState::KernelServing {
                        sent: acked,
                        total: size,
                    };
                    self.set_state(mac, state);
                }
            }
            TftpEvent::Completed { peer, size, .. } => {
                if let Some(mac) = self.tftp_device(peer) {
                    let state = DeviceState::KernelServing {
                        sent: size,
                        total: size,
                    };
                    self.set_state(mac, state);
                }
            }
            TftpEvent::Failed { peer, error, .. } => {
                if let Some(mac) = self.tftp_device(peer) {
                    let f = Failure::new("kernel_transfer_failed").with("detail", error);
                    self.set_state(mac, DeviceState::failed(f));
                }
            }
            TftpEvent::Rejected { peer, file, code } => self.warning(
                Failure::new("tftp_rejected")
                    .with("peer", peer)
                    .with("file", file.unwrap_or_default())
                    .with("code", format!("{code:?}")),
            ),
            TftpEvent::RecvError { error, count } => self.warning(
                Failure::new("recv_error")
                    .with("service", "tftp")
                    .with("count", count)
                    .with("detail", error),
            ),
        }
    }

    fn internal(&mut self, msg: Internal, io: &mut Option<Io>) {
        match msg {
            Internal::Kernels { epoch, result } if epoch == self.epoch => {
                let Some(run) = self.run.as_mut() else { return };
                match result {
                    Ok((version, set, fallback)) => {
                        let (boot, files) = boot_maps(&set);
                        if let Err(e) = run.bootp.set_boot_files(boot) {
                            warn!("boot file names rejected: {e}");
                        }
                        run.tftp_files.send_replace(Arc::new(files));
                        run.kernel_version = Some(version.clone());
                        if fallback {
                            self.warning(
                                Failure::new("kernels_offline_fallback").with("version", &version),
                            );
                        }
                        info!(%version, "boot kernels ready");
                        self.emit(EngineEvent::KernelsReady {
                            version: version.to_string(),
                        });
                    }
                    Err(f) => {
                        warn!("boot kernels unavailable: {f}");
                        self.emit(EngineEvent::Error(f));
                    }
                }
            }
            Internal::Prepared {
                epoch,
                mac,
                attempt,
                result,
            } if epoch == self.epoch => self.prepared(mac, attempt, result),
            Internal::RunnerExited {
                epoch,
                service,
                detail,
            } if epoch == self.epoch && self.run.is_some() => {
                self.emit(EngineEvent::Error(
                    Failure::new("runner_failed")
                        .with("service", service)
                        .with("detail", detail),
                ));
                self.stop(io);
            }
            _ => {} // from an earlier start
        }
    }

    // ------------------------------------------------------------ driving

    /// Advance sessions, send their frames, report their events, admit
    /// waiting devices and watch the interface.
    async fn drive(&mut self, io: &mut Option<Io>) {
        let now = Instant::now();
        let Some(run) = self.run.as_mut() else { return };
        let mut frames = Vec::new();
        let mut events = Vec::new();
        for dev in run.devices.values_mut() {
            let Some(session) = dev.session.as_mut() else {
                continue;
            };
            if session.poll_timeout().is_some_and(|t| t <= now) {
                session.handle_timeout(now);
            }
            while let Some(frame) = session.poll_transmit(now) {
                frames.push(frame.encode());
            }
            while let Some(ev) = session.poll_event() {
                events.push((dev.mac, ev));
            }
        }
        let dest = run.cfg.ports.netinstall_dest;
        if let Some(io) = io.as_ref() {
            for frame in &frames {
                if let Err(e) = io.socket.send_to(frame, dest).await {
                    debug!("netinstall send failed: {e}");
                }
            }
        }
        for (mac, ev) in events {
            self.session_event(mac, ev, now);
        }
        self.admit();
        self.check_link(now, io);
    }

    fn session_event(&mut self, mac: Mac, ev: ni_proto::Event, now: Instant) {
        let Some(run) = self.run.as_mut() else { return };
        let cooldown = run.cfg.cooldown;
        let Some(dev) = run.devices.get_mut(&mac) else {
            return;
        };
        let (phase, sent, total) = match &dev.state {
            Some(DeviceState::Flashing { phase, sent, total }) => (phase.clone(), *sent, *total),
            _ => (String::new(), 0, 0),
        };
        match ev {
            ni_proto::Event::PhaseChanged(p) => {
                dev.last_progress = Some(now);
                let phase = p.name().to_string();
                self.set_state(mac, DeviceState::Flashing { phase, sent, total });
            }
            ni_proto::Event::Progress {
                bytes_sent,
                bytes_total,
                ..
            } => {
                let state = DeviceState::Flashing {
                    phase,
                    sent: bytes_sent,
                    total: bytes_total,
                };
                let due = dev
                    .last_progress
                    .is_none_or(|t| now.saturating_duration_since(t) >= PROGRESS_INTERVAL);
                if due || bytes_sent == bytes_total {
                    dev.last_progress = Some(now);
                    self.set_state(mac, state);
                } else {
                    dev.state = Some(state);
                }
            }
            ni_proto::Event::Done => {
                dev.session = None;
                run.gate.start_cooldown(mac, now + cooldown);
                info!(%mac, "device flashed");
                self.set_state(mac, DeviceState::Done);
            }
            ni_proto::Event::Failed(reason) => {
                dev.session = None;
                let f = match reason {
                    FailReason::Timeout { phase } => {
                        Failure::new("flash_timeout").with("phase", phase)
                    }
                    FailReason::Rejected { phase } => {
                        Failure::new("flash_rejected").with("phase", phase)
                    }
                    FailReason::Cancelled => Failure::new("cancelled"),
                };
                warn!(%mac, "flashing failed: {f}");
                self.set_state(mac, DeviceState::failed(f));
            }
        }
    }

    fn check_link(&mut self, now: Instant, io: &mut Option<Io>) {
        let Some(run) = self.run.as_mut() else { return };
        let (Some(at), Some(every)) = (run.next_link_check, run.cfg.link_check) else {
            return;
        };
        if now < at {
            return;
        }
        run.next_link_check = Some(now + every);
        let ifaces = list_interfaces().unwrap_or_default();
        if !interface_usable(&ifaces, &run.cfg.interface, run.net.server_ip) {
            let f = Failure::new("interface_gone")
                .with("interface", &run.cfg.interface)
                .with("ip", run.net.server_ip);
            warn!("{f}");
            self.emit(EngineEvent::Error(f));
            self.stop(io);
        }
    }
}
```

```rust
#[tokio::test(flavor = "multi_thread", worker_threads = 2)]
async fn with_limit_one_the_second_device_waits_for_the_first() {
    let mut rig = rig(|cfg| cfg.max_parallel = 1).await;
    // A takes a while to "format", so B is discovered while A is busy.
    let mut slow = sim_config(A);
    slow.format_delay = Duration::from_millis(400);
    let a = boot(&rig, A, slow).await;
    let b = boot(&rig, B, sim_config(B)).await;
    rig.lan.add(a).await;
    state(&mut rig.events, A, "flashing").await;
    rig.lan.add(b).await;
    let mut events = Vec::new();
    let mut finished = 0;
    while finished < 2 {
        let e = next(&mut rig.events, |_| true).await;
        if matches!(&e, EngineEvent::Device { state, .. } if state.name() == "done") {
            finished += 1;
        }
        events.push(e);
    }
    let pos = |mac, name: &str| {
        events
            .iter()
            .position(|e| matches!(e, EngineEvent::Device { mac: m, state } if *m == mac && state.name() == name))
            .unwrap_or_else(|| panic!("{mac} never was {name}"))
    };
    assert!(events.contains(&EngineEvent::Device {
        mac: B,
        state: DeviceState::Waiting {
            reason: WaitReason::Concurrency
        }
    }));
    assert!(
        pos(A, "done") < pos(B, "preparing"),
        "B starts after A is done"
    );
    for mac in [A, B] {
        let report = rig.lan.wait_terminated(mac, WAIT).await.unwrap();
        assert_eq!(report.received.len(), 2, "{mac}");
        assert!(report.violations.is_empty());
    }
}
```

```markdown
## Facts established during Plan 4a (2026-11-06)

- Runner APIs used by the engine: `ni_bootp::serve_shared` + `BootpHandle` (`set_boot_files`,
  `set_policy(MacPolicy)`, `lease_of`, `mac_of`; the policy is asked only for supported RouterBOOT

- There is no TFTP MAC policy: the cooldown / only-MAC gate sits at BOOTP (no lease, no boot file)
  and at the Netinstall hello. The concurrency limit (default 4) counts preparing + flashing
  devices only; BOOTP and TFTP serve every device the gate allows.

  `.await`); fixed with a `+ Sync` bound and a compile-time test. Its test fixtures are exported
```
