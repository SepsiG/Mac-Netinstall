# Plan 3 — Assets (ni-assets) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A `ni-assets` crate that resolves RouterOS versions, carves the network-boot kernels out of MikroTik's official `netinstall-cli`, lists/downloads/verifies `.npk` packages, accepts user-supplied `.npk`/`.rsc` files, and caches all of it on disk — tested offline with synthetic fixtures, plus opt-in tests against the real servers.

**Architecture:** Pure, unit-tested cores (`version`, `arch`, `kernel`, `npk`, `archive`, `urls`, `cache`) under a small async façade, `Assets`, that the engine (Plan 4) will own. HTTP goes through `reqwest` (rustls) with the download/upgrade base URLs configurable, so every network path is tested against a hand-written HTTP/1.1 server on `127.0.0.1`. File work runs in `spawn_blocking`; files are written as `*.part`, verified, then renamed; a per-directory JSON index records size, SHA-256, source URL and fetch time.

**Tech Stack:** Rust stable (rustup, edition 2021, MSRV 1.88), `reqwest` 0.13.5 (`default-features = false`, feature `rustls`), `tokio` 1.54.1, `flate2` 1.1.11, `tar` 0.4.46, `sha2` 0.11.1, `serde` 1.0.229 + `serde_json` 1.0.154, `thiserror` 2, `bytes` 1, `proptest` 1 (dev). Depends on `ni-bootp` (`BootArch`) and `ni-proto` (`PlanFile`, `NPK_MAGIC`).

**Spec:** `docs/superpowers/specs/2026-11-06-mac-netinstall-design.md`
**Roadmap:** `docs/superpowers/plans/2026-11-06-00-roadmap.md`
**Builds on:** Plan 1 (`ni_proto::InstallPlan`, `PlanFile`, `message::NPK_MAGIC`), Plan 2 (`ni_bootp::BootArch`; the TFTP `FileMap` is a `HashMap<String, Bytes>`, so a `KernelSet` maps onto it directly).

- Zip entries are named `<name>-<ver>-<arch>.npk` (smips 7.25.1: `hotspot`, `tr069-client`, `wireless`).

- `netinstall-cli` 7.25.1 (an i386 ELF of 59147600 bytes) carries eight boot kernels as plain ELF images. The three PowerPC images differ only by their `Linux version 5.6.3`, `5.6.3-e500`, `5.6.3-440` banners. The host program itself is a `type 2` ELF covering the whole file (machine 3), so the scan must not skip over it.

## Design notes and deliberate choices

- **Checksums exist, so we use them.** The plan assumed none might be published; in fact every file has `<file>.sha256` from (at least) 7.16.2 on. Each download first fetches `<url>.sha256`: present → the download must match (`checksum_mismatch` otherwise); 404 → accepted on size + NPK checks alone; present but unparsable → `bad_response`. The index records `published_checksum: bool`. For kernels it refers to the tarball they were carved from.
- **Extra packages are downloaded individually** (`<name>-<ver>-<arch>.npk`), not via the zip; the zip is only used for its central directory, read with one `Range` request. Requested extras must be in that list (`unknown_package`), which also keeps arbitrary names out of URLs. Package names must match `[a-z][a-z0-9-]{0,63}`.
- **NPK size check uses the header length** (`8 + u32` LE at offset 4) rather than an HTTP header, so it also works for local files and cached files.
- **A `development` channel** was added next to `stable`, `long-term`, `testing` — the server has it, and it costs one enum variant.
- **Only RouterOS v7+** (`Version` rejects 6.x: v6 packages are bundled and named differently).
- **Kernel carving rules:** only `e_type == 2`; size = max(header, program header table end, section header table end, end of every segment); images starting inside an accepted kernel are ignored; an unknown machine (the i386 host) does not stop the scan. PowerPC needs a `Linux version` banner: no suffix → `PowerPc`, `-e500` → `E500`, `-440` → `Ppc440`, another suffix → not classified. A missing arch is `kernel_missing` (listing all of them); two images for one arch is `kernel_duplicate` (we cannot know which to serve).
- **`PkgArch` vs `BootArch`:** `BootArch::Mips` covers mipsbe *and* smips boards, so `PkgArch::for_boot_arch` returns a list; the device's own hello string (`PkgArch::from_device_arch`) is authoritative. Which strings real devices send is an open hardware check.
- **One lock per `Assets`.** All cache-changing operations are serialized with a `tokio::sync::Mutex`, including downloads (bandwidth is shared anyway). Two processes sharing a cache root are not coordinated; the atomic renames keep each file consistent.
- **Index per directory** (`<root>/<ver>/index.json`, `<root>/local/index.json`), so deleting a version directory removes its index too. A missing or unparsable index is treated as empty (everything is downloaded again). A cached file whose size or SHA-256 differs from its entry is downloaded again; a damaged *local* file is reported (`local_corrupt`) because it cannot be re-fetched.
- **Progress:** an optional `EventSink = Arc<dyn Fn(AssetEvent) + Send + Sync>`; progress events at most every 256 KiB. The engine can forward them to its own (bounded) channel.
- **HTTP:** fixed `User-Agent: mac-netinstall/<crate version>`, connect timeout 15 s, read timeout 60 s (time without data, not a total timeout), download limit 512 MiB, text responses limited to 64 KiB. reqwest's `gzip` feature stays off, so `Content-Length` is the file size. A body cut short of its `Content-Length` makes hyper fail the read, which maps to `network`.
- **Deviations from the fixed decisions:** (1) MSRV 1.80 → 1.88: reqwest 0.13 requires 1.85 and sha2 0.11 requires 1.88 (no 1.88 toolchain was installed to verify the MSRV build; only stable 1.99.1 was used). (2) reqwest 0.13 has no `rustls-tls` feature any more; its `rustls` feature uses aws-lc-rs and `rustls-platform-verifier` (macOS trust store). Still no OpenSSL. (3) No `dirs` crate: `default_cache_root()` uses `$HOME/Library/Caches/io.github.sepsig.mac-netinstall`.
- **Test helpers live in `src/testutil/`** (`#[cfg(test)]`), split by topic so each task only adds helpers it uses (no dead-code warnings at any stage). Temp directories are left in the system temp dir (`ni-assets-test-<pid>-…`) for inspection.
- **Expected warnings between Tasks 6 and 9:** crate-private HTTP items (`Http`, `MAX_TEXT`, `AssetError::io`, `Http::tail`, `Assets::max_download`) are only used once `Assets` grows, so `cargo test` prints `never used` / `never read` dead-code warnings in those tasks. They are gone by Task 10, whose clippy step uses `-D warnings`.
- **Every code block below was compiled and tested** in a prototype before this plan was written, and the plan was replayed on a fresh clone; the final tree matches the prototype byte for byte.

//! RouterOS versions and release channels.

use serde::{Deserialize, Serialize};
use std::fmt;
use std::str::FromStr;
use thiserror::Error;

/// A RouterOS v7+ version string such as `7.25.1`, `7.20rc3` or `7.26beta5`.
///
/// Validated so it is safe in URLs and file names: 1–32 characters of ASCII
/// digits, lowercase letters and dots, starting with a major version ≥ 7
/// (v6 packages are named and bundled differently).
#[derive(Debug, Clone, PartialEq, Eq, Hash, PartialOrd, Ord, Serialize, Deserialize)]
#[serde(try_from = "String", into = "String")]
pub struct Version(String);

/// Why a version string was rejected.
#[derive(Debug, Clone, PartialEq, Eq, Error)]
pub enum VersionError {
    #[error("invalid RouterOS version {0:?}")]
    Invalid(String),
    #[error("RouterOS {0} is not supported (v7 or later is required)")]
    TooOld(String),
}

impl Version {
    pub fn parse(s: &str) -> Result<Self, VersionError> {
        let s = s.trim();
        let invalid = || VersionError::Invalid(s.to_string());
        let well_formed = (1..=32).contains(&s.len())
            && s.bytes()
                .all(|b| b.is_ascii_digit() || b.is_ascii_lowercase() || b == b'.')
            && s.starts_with(|c: char| c.is_ascii_digit())
            && s.contains('.')
            && !s.contains("..")
            && !s.ends_with('.');
        if !well_formed {
            return Err(invalid());
        }
        let major: u32 = s
            .split('.')
            .next()
            .and_then(|m| m.parse().ok())
            .ok_or_else(invalid)?;
        if major < 7 {
            return Err(VersionError::TooOld(s.to_string()));
        }
        Ok(Self(s.to_string()))
    }

    pub fn as_str(&self) -> &str {
        &self.0
    }
}

impl FromStr for Version {
    type Err = VersionError;
    fn from_str(s: &str) -> Result<Self, Self::Err> {
        Self::parse(s)
    }
}

impl TryFrom<String> for Version {
    type Error = VersionError;
    fn try_from(s: String) -> Result<Self, Self::Error> {
        Self::parse(&s)
    }
}

impl From<Version> for String {
    fn from(v: Version) -> Self {
        v.0
    }
}

impl fmt::Display for Version {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        f.write_str(&self.0)
    }
}

/// MikroTik release channels (`https://upgrade.mikrotik.com/routeros/NEWESTa7.<channel>`).
#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash, Serialize, Deserialize)]
#[serde(rename_all = "kebab-case")]
pub enum Channel {
    Stable,
    LongTerm,
    Testing,
    Development,
}

impl Channel {
    pub const ALL: [Channel; 4] = [
        Channel::Stable,
        Channel::LongTerm,
        Channel::Testing,
        Channel::Development,
    ];

    /// The channel name used in the `NEWESTa7.<channel>` URL.
    pub fn as_str(self) -> &'static str {
        match self {
            Channel::Stable => "stable",
            Channel::LongTerm => "long-term",
            Channel::Testing => "testing",
            Channel::Development => "development",
        }
    }
}

impl fmt::Display for Channel {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        f.write_str(self.as_str())
    }
}

impl FromStr for Channel {
    type Err = VersionError;
    fn from_str(s: &str) -> Result<Self, Self::Err> {
        Channel::ALL
            .into_iter()
            .find(|c| c.as_str() == s)
            .ok_or_else(|| VersionError::Invalid(s.to_string()))
    }
}

/// What a profile asks for: the newest version of a channel, or an exact one.
#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "kebab-case")]
pub enum VersionSpec {
    Channel(Channel),
    Exact(Version),
}

impl FromStr for VersionSpec {
    type Err = VersionError;
    /// A channel name (`stable`, `long-term`, `testing`, `development`) or a version.
    fn from_str(s: &str) -> Result<Self, Self::Err> {
        match s.parse::<Channel>() {
            Ok(c) => Ok(VersionSpec::Channel(c)),
            Err(_) => Version::parse(s).map(VersionSpec::Exact),
        }
    }
}

/// The newest version of a channel.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Release {
    pub version: Version,
    /// Release time, seconds since the Unix epoch.
    pub released_unix: u64,
}

/// Parse a `NEWESTa7.<channel>` body: `<version> <unix timestamp>\n`.
pub fn parse_newest(body: &str) -> Option<Release> {
    let mut parts = body.split_whitespace();
    let version = Version::parse(parts.next()?).ok()?;
    let released_unix = parts.next()?.parse().ok()?;
    if parts.next().is_some() {
        return None;
    }
    Some(Release {
        version,
        released_unix,
    })
}

//! RouterOS package architectures.
//!
//! Packages are published per RouterOS architecture (`routeros-<ver>-<arch>.npk`).
//! The device names its architecture in the Netinstall hello
//! ([`ni_proto::DeviceInfo::arch`]); the boot loader only names a
//! [`BootArch`], which is not always enough (mipsbe and smips boards both
//! boot the `Mips` kernel).

use ni_bootp::BootArch;
use serde::{Deserialize, Serialize};
use std::fmt;
use std::str::FromStr;
use thiserror::Error;

/// Architectures RouterOS packages are built for (x86 is out of scope).
#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash, PartialOrd, Ord, Serialize, Deserialize)]
#[serde(rename_all = "lowercase")]
pub enum PkgArch {
    Arm,
    Arm64,
    Mipsbe,
    Mmips,
    Smips,
    Ppc,
    Tile,
}

/// A device architecture we cannot install packages for.
#[derive(Debug, Clone, PartialEq, Eq, Error)]
pub enum ArchError {
    /// Not a RouterOS architecture name we know.
    #[error("unknown device architecture {0:?}")]
    Unknown(String),
    /// A RouterOS architecture outside the MVP (x86).
    #[error("device architecture {0:?} is not supported")]
    Unsupported(String),
}

impl PkgArch {
    pub const ALL: [PkgArch; 7] = [
        PkgArch::Arm,
        PkgArch::Arm64,
        PkgArch::Mipsbe,
        PkgArch::Mmips,
        PkgArch::Smips,
        PkgArch::Ppc,
        PkgArch::Tile,
    ];

    /// The architecture as it appears in package file names.
    pub fn as_str(self) -> &'static str {
        match self {
            PkgArch::Arm => "arm",
            PkgArch::Arm64 => "arm64",
            PkgArch::Mipsbe => "mipsbe",
            PkgArch::Mmips => "mmips",
            PkgArch::Smips => "smips",
            PkgArch::Ppc => "ppc",
            PkgArch::Tile => "tile",
        }
    }

    /// Map the architecture a device reports in its Netinstall hello.
    ///
    /// Matching ignores case and surrounding whitespace. `powerpc` is
    /// accepted for `ppc`. Which exact strings real devices send is a
    /// hardware check (see the roadmap).
    pub fn from_device_arch(s: &str) -> Result<Self, ArchError> {
        let lower = s.trim().to_ascii_lowercase();
        let arch = match lower.as_str() {
            "arm" => PkgArch::Arm,
            "arm64" => PkgArch::Arm64,
            "mipsbe" => PkgArch::Mipsbe,
            "mmips" => PkgArch::Mmips,
            "smips" => PkgArch::Smips,
            "ppc" | "powerpc" => PkgArch::Ppc,
            "tile" => PkgArch::Tile,
            "x86" | "x86_64" | "i386" => return Err(ArchError::Unsupported(s.trim().into())),
            _ => return Err(ArchError::Unknown(s.trim().into())),
        };
        Ok(arch)
    }

    /// Package architectures whose devices boot the `boot` kernel.
    pub fn for_boot_arch(boot: BootArch) -> &'static [PkgArch] {
        match boot {
            BootArch::Mips => &[PkgArch::Mipsbe, PkgArch::Smips],
            BootArch::MMips => &[PkgArch::Mmips],
            BootArch::PowerPc | BootArch::E500 | BootArch::Ppc440 => &[PkgArch::Ppc],
            BootArch::Tile => &[PkgArch::Tile],
            BootArch::Arm => &[PkgArch::Arm],
            BootArch::Arm64 => &[PkgArch::Arm64],
        }
    }
}

impl fmt::Display for PkgArch {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        f.write_str(self.as_str())
    }
}

impl FromStr for PkgArch {
    type Err = ArchError;
    fn from_str(s: &str) -> Result<Self, Self::Err> {
        Self::from_device_arch(s)
    }
}

//! Synthetic ELF images shaped like the embedded boot kernels.

use ni_bootp::BootArch;

/// Shape of a synthetic ELF file.
#[derive(Debug, Clone, Copy)]
pub struct ElfSpec {
    pub class64: bool,
    pub big_endian: bool,
    pub machine: u16,
    pub e_type: u16,
    /// Append a one-entry section header table after the payload.
    pub section_headers: bool,
}

impl ElfSpec {
    pub fn exec(class64: bool, big_endian: bool, machine: u16) -> Self {
        Self {
            class64,
            big_endian,
            machine,
            e_type: 2,
            section_headers: true,
        }
    }
}

struct Out {
    buf: Vec<u8>,
    big: bool,
}

impl Out {
    fn u16(&mut self, v: u16) {
        let b = if self.big {
            v.to_be_bytes()
        } else {
            v.to_le_bytes()
        };
        self.buf.extend_from_slice(&b);
    }
    fn u32(&mut self, v: u32) {
        let b = if self.big {
            v.to_be_bytes()
        } else {
            v.to_le_bytes()
        };
        self.buf.extend_from_slice(&b);
    }
    fn u64(&mut self, v: u64) {
        let b = if self.big {
            v.to_be_bytes()
        } else {
            v.to_le_bytes()
        };
        self.buf.extend_from_slice(&b);
    }
    /// Address-sized field.
    fn addr(&mut self, class64: bool, v: u64) {
        if class64 {
            self.u64(v)
        } else {
            self.u32(v as u32)
        }
    }
}

/// A minimal valid ELF: header, one `PT_LOAD` program header covering
/// `payload`, the payload, then (optionally) a zeroed section header table.
pub fn elf(spec: ElfSpec, payload: &[u8]) -> Vec<u8> {
    let c64 = spec.class64;
    let (ehsize, phentsize, shentsize) = if c64 { (64, 56, 64) } else { (52, 32, 40) };
    let data_off = u64::from(ehsize + phentsize);
    let shoff = data_off + payload.len() as u64;
    let mut o = Out {
        buf: Vec::new(),
        big: spec.big_endian,
    };
    o.buf.extend_from_slice(b"\x7fELF");
    o.buf.push(if c64 { 2 } else { 1 });
    o.buf.push(if spec.big_endian { 2 } else { 1 });
    o.buf.push(1);
    o.buf.resize(16, 0);
    o.u16(spec.e_type);
    o.u16(spec.machine);
    o.u32(1); // e_version
    o.addr(c64, 0x8000_0000); // e_entry
    o.addr(c64, u64::from(ehsize)); // e_phoff
    o.addr(c64, if spec.section_headers { shoff } else { 0 }); // e_shoff
    o.u32(0); // e_flags
    o.u16(ehsize);
    o.u16(phentsize);
    o.u16(1); // e_phnum
    o.u16(shentsize);
    o.u16(u16::from(spec.section_headers)); // e_shnum
    o.u16(0); // e_shstrndx
    assert_eq!(o.buf.len(), usize::from(ehsize));
    // Program header: PT_LOAD.
    o.u32(1);
    if c64 {
        o.u32(5); // p_flags
        o.u64(data_off);
        o.u64(0x8000_0000);
        o.u64(0x8000_0000);
        o.u64(payload.len() as u64);
        o.u64(payload.len() as u64);
        o.u64(0x1000);
    } else {
        o.u32(data_off as u32);
        o.u32(0x8000_0000);
        o.u32(0x8000_0000);
        o.u32(payload.len() as u32);
        o.u32(payload.len() as u32);
        o.u32(5);
        o.u32(0x1000);
    }
    o.buf.extend_from_slice(payload);
    if spec.section_headers {
        o.buf.resize(o.buf.len() + usize::from(shentsize), 0);
    }
    o.buf
}

//! Boot kernel extraction from the official `netinstall-cli` binary.
//!
//! MikroTik's Linux `netinstall-cli` (an i386 ELF) carries the network-boot
//! kernels as plain ELF images appended to its data. Each image is carved
//! out by scanning for the ELF magic, and its exact size is computed from
//! its headers: the end of the furthest program segment or of the section
//! header table. Only executables (`e_type == 2`) count; the small shared
//! objects (`e_type == 3`) found inside kernels are vDSOs.
//!
//! Mapping to [`BootArch`] (verified on 7.25.1):
//!
//! | ELF machine | Class, byte order | Extra marker | Arch |
//! |---|---|---|---|
//! | 8 (MIPS) | 32-bit big-endian | | [`BootArch::Mips`] |
//! | 8 (MIPS) | 32-bit little-endian | | [`BootArch::MMips`] |
//! | 20 (PPC) | 32-bit big-endian | `Linux version 5.6.3 ` (no suffix) | [`BootArch::PowerPc`] |
//! | 20 (PPC) | 32-bit big-endian | `Linux version …-e500` | [`BootArch::E500`] |
//! | 20 (PPC) | 32-bit big-endian | `Linux version …-440` | [`BootArch::Ppc440`] |
//! | 40 (ARM) | 32-bit little-endian | | [`BootArch::Arm`] |
//! | 183 (AArch64) | 64-bit little-endian | | [`BootArch::Arm64`] |
//! | 191 (TILE-Gx) | 64-bit little-endian | | [`BootArch::Tile`] |

use bytes::Bytes;
use ni_bootp::BootArch;
use std::collections::HashMap;
use thiserror::Error;

/// One boot kernel per architecture.
pub type KernelSet = HashMap<BootArch, Bytes>;

/// Upper bound for one kernel image (real ones are 3.5–8 MiB).
pub const MAX_KERNEL_SIZE: u64 = 32 << 20;

const ELF_MAGIC: &[u8; 4] = b"\x7fELF";
const ET_EXEC: u16 = 2;
const EM_MIPS: u16 = 8;
const EM_PPC: u16 = 20;
const EM_ARM: u16 = 40;
const EM_AARCH64: u16 = 183;
const EM_TILEGX: u16 = 191;
const LINUX_VERSION: &[u8] = b"Linux version ";

/// Why a kernel set could not be built.
#[derive(Debug, Clone, PartialEq, Eq, Error)]
pub enum KernelError {
    /// No image was found for these architectures (in [`BootArch::ALL`] order).
    #[error("no boot kernel found for: {}", names(.0))]
    Missing(Vec<BootArch>),
    /// Two images map to the same architecture; we cannot tell which to serve.
    #[error("more than one boot kernel found for {0}")]
    Duplicate(BootArch),
}

fn names(arches: &[BootArch]) -> String {
    let v: Vec<&str> = arches.iter().map(|a| a.as_str()).collect();
    v.join(", ")
}

/// An ELF executable found inside a larger blob.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct ElfImage {
    /// Offset of the ELF magic in the blob.
    pub offset: usize,
    /// Image size computed from its headers.
    pub len: usize,
    /// `e_machine`.
    pub machine: u16,
    /// `ELFCLASS64`.
    pub class64: bool,
    /// `ELFDATA2MSB`.
    pub big_endian: bool,
}

/// Every well-formed ELF executable (`e_type == 2`) in `data` whose computed
/// size fits in `data` and in [`MAX_KERNEL_SIZE`], in offset order. Images
/// nested in other images are listed too.
pub fn find_elf_images(data: &[u8]) -> Vec<ElfImage> {
    let mut found = Vec::new();
    let mut from = 0;
    while let Some(pos) = find(&data[from..], ELF_MAGIC) {
        let offset = from + pos;
        if let Some(img) = parse_elf(data, offset) {
            found.push(img);
        }
        from = offset + 1;
    }
    found
}

/// Carve the boot kernels for every [`BootArch`] out of `data` (the
/// `netinstall-cli` binary).
///
/// Images starting inside an already accepted kernel are ignored, and
/// executables for other machines (the i386 host program itself) are
/// skipped. Fails if an architecture is missing or found twice.
pub fn extract_kernels(data: &[u8]) -> Result<KernelSet, KernelError> {
    let mut set = KernelSet::new();
    let mut covered = 0;
    for img in find_elf_images(data) {
        if img.offset < covered {
            continue;
        }
        let bytes = &data[img.offset..img.offset + img.len];
        let Some(arch) = classify(&img, bytes) else {
            continue;
        };
        if set.insert(arch, Bytes::copy_from_slice(bytes)).is_some() {
            return Err(KernelError::Duplicate(arch));
        }
        covered = img.offset + img.len;
    }
    let missing: Vec<BootArch> = BootArch::ALL
        .into_iter()
        .filter(|a| !set.contains_key(a))
        .collect();
    if missing.is_empty() {
        Ok(set)
    } else {
        Err(KernelError::Missing(missing))
    }
}

/// Map an image to its boot architecture; `None` if it is not a kernel we
/// know.
pub fn classify(img: &ElfImage, bytes: &[u8]) -> Option<BootArch> {
    match (img.machine, img.class64, img.big_endian) {
        (EM_MIPS, false, true) => Some(BootArch::Mips),
        (EM_MIPS, false, false) => Some(BootArch::MMips),
        (EM_PPC, false, true) => {
            let version = linux_version(bytes)?;
            if version.ends_with("-e500") {
                Some(BootArch::E500)
            } else if version.ends_with("-440") {
                Some(BootArch::Ppc440)
            } else if !version.contains('-') {
                Some(BootArch::PowerPc)
            } else {
                None
            }
        }
        (EM_ARM, false, false) => Some(BootArch::Arm),
        (EM_AARCH64, true, false) => Some(BootArch::Arm64),
        (EM_TILEGX, true, false) => Some(BootArch::Tile),
        _ => None,
    }
}

/// The kernel release from the first `Linux version <release> ` banner whose
/// release starts with a digit (e.g. `5.6.3-e500`).
pub fn linux_version(bytes: &[u8]) -> Option<&str> {
    let mut from = 0;
    while let Some(pos) = find(&bytes[from..], LINUX_VERSION) {
        let start = from + pos + LINUX_VERSION.len();
        let rest = &bytes[start..];
        let len = rest
            .iter()
            .take(64)
            .take_while(|b| b.is_ascii_graphic())
            .count();
        let release = &rest[..len];
        if release.first().is_some_and(u8::is_ascii_digit) {
            return std::str::from_utf8(release).ok();
        }
        from = start;
    }
    None
}

fn find(haystack: &[u8], needle: &[u8]) -> Option<usize> {
    let first = needle[0];
    let mut from = 0;
    while let Some(pos) = haystack[from..].iter().position(|&b| b == first) {
        let at = from + pos;
        if haystack[at..].starts_with(needle) {
            return Some(at);
        }
        from = at + 1;
    }
    None
}

/// Endian-aware reads from a slice; `None` when out of bounds.
struct Reader<'a> {
    d: &'a [u8],
    big: bool,
}

impl Reader<'_> {
    fn bytes<const N: usize>(&self, at: u64) -> Option<[u8; N]> {
        let at = usize::try_from(at).ok()?;
        self.d.get(at..at.checked_add(N)?)?.try_into().ok()
    }

    fn u16(&self, at: u64) -> Option<u64> {
        let b = self.bytes::<2>(at)?;
        Some(u64::from(if self.big {
            u16::from_be_bytes(b)
        } else {
            u16::from_le_bytes(b)
        }))
    }

    fn u32(&self, at: u64) -> Option<u64> {
        let b = self.bytes::<4>(at)?;
        Some(u64::from(if self.big {
            u32::from_be_bytes(b)
        } else {
            u32::from_le_bytes(b)
        }))
    }

    fn u64(&self, at: u64) -> Option<u64> {
        let b = self.bytes::<8>(at)?;
        Some(if self.big {
            u64::from_be_bytes(b)
        } else {
            u64::from_le_bytes(b)
        })
    }
}

/// Parse the ELF headers at `offset`; `None` unless it is a well-formed
/// executable that fits in `data`.
fn parse_elf(data: &[u8], offset: usize) -> Option<ElfImage> {
    let d = &data[offset..];
    if !d.starts_with(ELF_MAGIC) {
        return None;
    }
    let class64 = match *d.get(4)? {
        1 => false,
        2 => true,
        _ => return None,
    };
    let big = match *d.get(5)? {
        1 => false,
        2 => true,
        _ => return None,
    };
    if *d.get(6)? != 1 {
        return None;
    }
    let r = Reader { d, big };
    if r.u16(16)? != u64::from(ET_EXEC) {
        return None;
    }
    let machine = u16::try_from(r.u16(18)?).ok()?;
    let (phoff, shoff, ehsize, phentsize, phnum, shentsize, shnum) = if class64 {
        let h = |at| r.u16(at);
        (
            r.u64(32)?,
            r.u64(40)?,
            h(52)?,
            h(54)?,
            h(56)?,
            h(58)?,
            h(60)?,
        )
    } else {
        let h = |at| r.u16(at);
        (
            r.u32(28)?,
            r.u32(32)?,
            h(40)?,
            h(42)?,
            h(44)?,
            h(46)?,
            h(48)?,
        )
    };
    let (want_ph, want_sh) = if class64 { (56, 64) } else { (32, 40) };
    if phnum == 0 || phentsize != want_ph || (shnum != 0 && shentsize != want_sh) {
        return None;
    }
    let mut end = ehsize
        .max(phoff.checked_add(phnum * phentsize)?)
        .max(shoff.checked_add(shnum * shentsize)?);
    for k in 0..phnum {
        let ph = phoff + k * phentsize;
        let (p_offset, p_filesz) = if class64 {
            (r.u64(ph + 8)?, r.u64(ph + 32)?)
        } else {
            (r.u32(ph + 4)?, r.u32(ph + 16)?)
        };
        end = end.max(p_offset.checked_add(p_filesz)?);
    }
    if end > MAX_KERNEL_SIZE || end > d.len() as u64 {
        return None;
    }
    Some(ElfImage {
        offset,
        len: end as usize,
        machine,
        class64,
        big_endian: big,
    })
}

/// A `.tar.gz` holding `LICENSE.txt` and the given files.
pub fn tar_gz(files: &[(&str, &[u8])]) -> Vec<u8> {

    for (name, data) in all {

        header.set_size(data.len() as u64);

    }
    builder.into_inner().unwrap().finish().unwrap()
}

/// A stored (uncompressed) ZIP archive.
pub fn zip(files: &[(&str, &[u8])]) -> Vec<u8> {
    fn u16le(v: &mut Vec<u8>, x: u16) {
        v.extend_from_slice(&x.to_le_bytes())
    }
    fn u32le(v: &mut Vec<u8>, x: u32) {
        v.extend_from_slice(&x.to_le_bytes())
    }
    let mut out = Vec::new();
    let mut central = Vec::new();
    for (name, data) in files {
        let offset = out.len() as u32;
        u32le(&mut out, 0x0403_4b50);
        for x in [20, 0, 0, 0, 0] {
            u16le(&mut out, x); // version, flags, method, time, date
        }
        u32le(&mut out, 0); // crc (not checked by our reader)
        u32le(&mut out, data.len() as u32);
        u32le(&mut out, data.len() as u32);
        u16le(&mut out, name.len() as u16);
        u16le(&mut out, 0);
        out.extend_from_slice(name.as_bytes());
        out.extend_from_slice(data);

        u32le(&mut central, 0x0201_4b50);
        for x in [20, 20, 0, 0, 0, 0] {
            u16le(&mut central, x);
        }
        u32le(&mut central, 0);
        u32le(&mut central, data.len() as u32);
        u32le(&mut central, data.len() as u32);
        u16le(&mut central, name.len() as u16);
        for x in [0, 0, 0, 0] {
            u16le(&mut central, x); // extra, comment, disk, internal attrs
        }
        u32le(&mut central, 0); // external attrs
        u32le(&mut central, offset);
        central.extend_from_slice(name.as_bytes());
    }
    let cd_offset = out.len() as u32;
    out.extend_from_slice(&central);
    u32le(&mut out, 0x0605_4b50);
    u16le(&mut out, 0);
    u16le(&mut out, 0);
    u16le(&mut out, files.len() as u16);
    u16le(&mut out, files.len() as u16);
    u32le(&mut out, central.len() as u32);
    u32le(&mut out, cd_offset);
    u16le(&mut out, 0);
    out
}

//! RouterOS package (`.npk`) checks and checksums.
//!
//! An NPK starts with the magic `1E F1 D0 BA` followed by a little-endian
//! `u32` holding the length of the rest of the file, so a complete package
//! is exactly `8 + length` bytes (verified on 7.1, 7.12.1, 7.16.2 and
//! 7.25.1 packages).

use ni_proto::message::NPK_MAGIC;
use sha2::{Digest, Sha256};
use thiserror::Error;

/// Why a file is not a complete RouterOS package.
#[derive(Debug, Clone, PartialEq, Eq, Error)]
pub enum NpkError {
    #[error("{name} is not a RouterOS package (missing NPK magic)")]
    NotAnNpk { name: String },
    #[error("{name} is incomplete or damaged: header says {expected} bytes, file has {actual}")]
    LengthMismatch {
        name: String,
        expected: u64,
        actual: u64,
    },
}

/// Check `data` is a complete NPK (magic and header length).
pub fn check_npk(name: &str, data: &[u8]) -> Result<(), NpkError> {
    if data.len() < 8 || !data.starts_with(&NPK_MAGIC) {
        return Err(NpkError::NotAnNpk { name: name.into() });
    }
    let len = u32::from_le_bytes([data[4], data[5], data[6], data[7]]);
    let expected = 8 + u64::from(len);
    let actual = data.len() as u64;
    if expected != actual {
        return Err(NpkError::LengthMismatch {
            name: name.into(),
            expected,
            actual,
        });
    }
    Ok(())
}

/// Lowercase hex SHA-256 of `data`.
pub fn sha256_hex(data: &[u8]) -> String {
    hex(&Sha256::digest(data))
}

/// Lowercase hex encoding.
pub fn hex(bytes: &[u8]) -> String {
    use std::fmt::Write;
    bytes.iter().fold(String::new(), |mut s, b| {
        let _ = write!(s, "{b:02x}");
        s
    })
}

/// Parse a MikroTik `<file>.sha256` body (`<64 hex digits>  <file name>\n`,
/// the `sha256sum` format). Returns the lowercase digest if the line names
/// `file_name`.
pub fn parse_sha256_file(body: &str, file_name: &str) -> Option<String> {
    let line = body.lines().next()?;
    let (digest, name) = line.split_once(char::is_whitespace)?;
    let name = name.trim_start().trim_start_matches('*').trim_end();
    if digest.len() != 64 || !digest.bytes().all(|b| b.is_ascii_hexdigit()) || name != file_name {
        return None;
    }
    Some(digest.to_ascii_lowercase())
}

/// Package names are lowercase ASCII letters, digits and `-`, starting with
/// a letter, at most 64 characters (`routeros`, `wifi-qcom-be`, …).
pub fn valid_package_name(name: &str) -> bool {
    (1..=64).contains(&name.len())
        && name.starts_with(|c: char| c.is_ascii_lowercase())
        && name
            .bytes()
            .all(|b| b.is_ascii_lowercase() || b.is_ascii_digit() || b == b'-')
}

/// Package names from `all_packages-<arch>-<ver>.zip` entry names
/// (`<name>-<ver>-<arch>.npk`), sorted and de-duplicated. Other entries are
/// ignored.
pub fn package_names(entries: &[String], version: &str, arch: &str) -> Vec<String> {
    let suffix = format!("-{version}-{arch}.npk");

//! Archive readers: `netinstall-cli` from the netinstall `.tar.gz`, and
//! entry names from a ZIP central directory.

use flate2::read::GzDecoder;
use std::io::{self, Read};
use thiserror::Error;

/// Name of the Linux Netinstall binary inside `netinstall-<ver>.tar.gz`.
pub const NETINSTALL_CLI: &str = "netinstall-cli";
/// Upper bound for the extracted `netinstall-cli` (59 MB in 7.25.1).
pub const MAX_CLI_SIZE: u64 = 256 << 20;

const EOCD_SIG: [u8; 4] = [0x50, 0x4b, 0x05, 0x06];
const CDH_SIG: [u8; 4] = [0x50, 0x4b, 0x01, 0x02];
const EOCD_LEN: usize = 22;

/// Problems reading an archive.
#[derive(Debug, Error)]
pub enum ArchiveError {
    #[error("cannot read the netinstall archive")]
    Read(#[source] io::Error),
    #[error("the netinstall archive has no {NETINSTALL_CLI}")]
    MissingCli,
    #[error("{NETINSTALL_CLI} is larger than {MAX_CLI_SIZE} bytes")]
    CliTooLarge,
    #[error("malformed package archive: {0}")]
    BadZip(&'static str),
    /// The central directory starts before the fetched tail; fetch at
    /// least `needed` bytes from the end and retry.
    #[error("package archive directory needs {needed} bytes from the end")]
    NeedMore { needed: u64 },
}

/// Read `netinstall-cli` (any directory) out of a gzip-compressed tarball.
pub fn netinstall_cli_from_tar_gz<R: Read>(reader: R) -> Result<Vec<u8>, ArchiveError> {
    let mut archive = tar::Archive::new(GzDecoder::new(reader));
    for entry in archive.entries().map_err(ArchiveError::Read)? {
        let mut entry = entry.map_err(ArchiveError::Read)?;
        let is_cli = entry.header().entry_type().is_file()
            && entry
                .path()
                .map_err(ArchiveError::Read)?
                .file_name()
                .is_some_and(|n| n == NETINSTALL_CLI);
        if !is_cli {
            continue;
        }
        if entry.size() > MAX_CLI_SIZE {
            return Err(ArchiveError::CliTooLarge);
        }
        let mut data = Vec::with_capacity(entry.size() as usize);
        entry.read_to_end(&mut data).map_err(ArchiveError::Read)?;
        return Ok(data);
    }
    Err(ArchiveError::MissingCli)
}

fn u16_at(b: &[u8], at: usize) -> Option<usize> {
    Some(usize::from(u16::from_le_bytes(
        b.get(at..at + 2)?.try_into().ok()?,
    )))
}

fn u32_at(b: &[u8], at: usize) -> Option<u64> {
    Some(u64::from(u32::from_le_bytes(
        b.get(at..at + 4)?.try_into().ok()?,
    )))
}

/// Entry names from the central directory of a ZIP file, given its last
/// `tail.len()` bytes and its total size. ZIP64 archives are rejected.
pub fn zip_entry_names(tail: &[u8], total_len: u64) -> Result<Vec<String>, ArchiveError> {
    let bad = ArchiveError::BadZip;
    if tail.len() < EOCD_LEN || tail.len() as u64 > total_len {
        return Err(bad("too short"));
    }
    // The end-of-central-directory record is followed only by its comment.
    let eocd = (0..=tail.len() - EOCD_LEN)
        .rev()
        .find(|&i| {
            tail[i..].starts_with(&EOCD_SIG)
                && u16_at(tail, i + 20).is_some_and(|c| i + EOCD_LEN + c == tail.len())
        })
        .ok_or(bad("no end of central directory"))?;
    let count = u16_at(tail, eocd + 10).ok_or(bad("eocd"))?;
    let cd_size = u32_at(tail, eocd + 12).ok_or(bad("eocd"))?;
    let cd_offset = u32_at(tail, eocd + 16).ok_or(bad("eocd"))?;
    if count == 0xffff || cd_size == 0xffff_ffff || cd_offset == 0xffff_ffff {
        return Err(bad("zip64 is not supported"));
    }
    let tail_start = total_len - tail.len() as u64;
    let eocd_abs = tail_start + eocd as u64;
    if cd_offset + cd_size > eocd_abs {
        return Err(bad("central directory overlaps its end record"));
    }
    if cd_offset < tail_start {
        return Err(ArchiveError::NeedMore {
            needed: total_len - cd_offset,
        });
    }
    let mut p = (cd_offset - tail_start) as usize;
    let mut names = Vec::with_capacity(count);
    for _ in 0..count {
        if !tail.get(p..).is_some_and(|t| t.starts_with(&CDH_SIG)) {
            return Err(bad("bad central directory entry"));
        }
        let name_len = u16_at(tail, p + 28).ok_or(bad("entry"))?;
        let extra_len = u16_at(tail, p + 30).ok_or(bad("entry"))?;
        let comment_len = u16_at(tail, p + 32).ok_or(bad("entry"))?;
        let name = tail
            .get(p + 46..p + 46 + name_len)
            .ok_or(bad("entry name"))?;
        names.push(String::from_utf8_lossy(name).into_owned());
        p += 46 + name_len + extra_len + comment_len;
    }
    Ok(names)
}

//! A tiny HTTP/1.1 server for download tests, and temp directories.

use std::collections::HashMap;
use std::path::PathBuf;
use std::sync::atomic::{AtomicU32, Ordering};
use std::sync::{Arc, Mutex};
use std::time::Duration;
use tokio::io::{AsyncReadExt, AsyncWriteExt};
use tokio::net::{TcpListener, TcpStream};

/// How the test server answers one path.
#[derive(Debug, Clone)]
pub enum Reply {
    /// 200 with this body (206 for `Range: bytes=-N` requests).
    Body(Vec<u8>),
    /// Any status with an empty body.
    Status(u16),
    /// Declares `declared` bytes but sends only `body`, then closes.
    Truncated { body: Vec<u8>, declared: usize },
    /// Sends the response head, then nothing.
    Stall,
}

type Routes = Arc<Mutex<HashMap<String, Reply>>>;

/// A minimal HTTP/1.1 server on 127.0.0.1 (one request per connection).
/// Unknown paths get 404. Every request head is recorded.
pub struct TestServer {
    pub base: String,
    routes: Routes,
    log: Arc<Mutex<Vec<String>>>,
}

impl TestServer {
    pub async fn start() -> Self {
        let listener = TcpListener::bind("127.0.0.1:0").await.unwrap();
        let base = format!("http://{}", listener.local_addr().unwrap());
        let routes: Routes = Arc::default();
        let log: Arc<Mutex<Vec<String>>> = Arc::default();
        let (r, l) = (routes.clone(), log.clone());
        tokio::spawn(async move {
            loop {
                let Ok((stream, _)) = listener.accept().await else {
                    return;
                };
                tokio::spawn(handle(stream, r.clone(), l.clone()));
            }
        });
        Self { base, routes, log }
    }

    pub fn route(&self, path: &str, reply: Reply) {
        self.routes.lock().unwrap().insert(path.to_string(), reply);
    }

    /// Request heads received so far.
    pub fn requests(&self) -> Vec<String> {
        self.log.lock().unwrap().clone()
    }

    /// Request lines (`GET /path`) received so far.
    pub fn paths(&self) -> Vec<String> {
        self.requests()
            .iter()
            .map(|r| {
                r.lines()
                    .next()
                    .unwrap_or("")
                    .trim_end_matches(" HTTP/1.1")
                    .to_string()
            })
            .collect()
    }
}

async fn handle(mut stream: TcpStream, routes: Routes, log: Arc<Mutex<Vec<String>>>) {
    let mut head = Vec::new();
    let mut buf = [0u8; 1024];
    while !head.windows(4).any(|w| w == b"\r\n\r\n") {
        match stream.read(&mut buf).await {
            Ok(0) | Err(_) => return,
            Ok(n) => head.extend_from_slice(&buf[..n]),
        }
        if head.len() > 16 * 1024 {
            return;
        }
    }
    let head = String::from_utf8_lossy(&head).into_owned();
    log.lock().unwrap().push(head.clone());
    let path = head.split_whitespace().nth(1).unwrap_or("/").to_string();
    let range = head.lines().find_map(|l| {
        let l = l.to_ascii_lowercase();
        let v = l.strip_prefix("range: bytes=-")?;
        v.trim().parse::<usize>().ok()
    });
    let reply = routes.lock().unwrap().get(&path).cloned();
    let (status, extra, body, declared) = match reply {
        None => (404, String::new(), Vec::new(), 0),
        Some(Reply::Status(code)) => (code, String::new(), Vec::new(), 0),
        Some(Reply::Body(body)) => match range {
            Some(n) if n < body.len() => {
                let start = body.len() - n;
                let extra = format!(
                    "Content-Range: bytes {start}-{}/{}\r\n",
                    body.len() - 1,
                    body.len()
                );
                let part = body[start..].to_vec();
                let len = part.len();
                (206, extra, part, len)
            }
            _ => {
                let len = body.len();
                (200, String::new(), body, len)
            }
        },
        Some(Reply::Truncated { body, declared }) => (200, String::new(), body, declared),
        Some(Reply::Stall) => {
            let head = "HTTP/1.1 200 OK\r\nContent-Length: 10\r\n\r\n";
            let _ = stream.write_all(head.as_bytes()).await;
            tokio::time::sleep(Duration::from_secs(30)).await;
            return;
        }
    };
    let head = format!(
        "HTTP/1.1 {status} X\r\nContent-Length: {declared}\r\n{extra}Connection: close\r\n\r\n"
    );
    let _ = stream.write_all(head.as_bytes()).await;
    let _ = stream.write_all(&body).await;
    let _ = stream.shutdown().await;
}

/// A fresh, empty directory under the system temp dir (removed first if it
/// exists). Left behind after the test for inspection.
pub fn tempdir(tag: &str) -> PathBuf {
    static NEXT: AtomicU32 = AtomicU32::new(0);
    let n = NEXT.fetch_add(1, Ordering::Relaxed);
    let dir = std::env::temp_dir().join(format!("ni-assets-test-{}-{tag}-{n}", std::process::id()));
    let _ = std::fs::remove_dir_all(&dir);
    std::fs::create_dir_all(&dir).unwrap();
    dir
}

//! HTTP access: small text files, ranged tails and streaming downloads.

use crate::error::AssetError;
use crate::events::{AssetEvent, PROGRESS_STEP};
use crate::npk::hex;
use crate::urls;
use reqwest::header::{CONTENT_RANGE, RANGE};
use reqwest::{Client, Response, StatusCode};
use sha2::{Digest, Sha256};
use std::path::Path;
use std::time::Duration;
use tokio::io::AsyncWriteExt;

/// `User-Agent` sent with every request.
pub const USER_AGENT: &str = concat!("mac-netinstall/", env!("CARGO_PKG_VERSION"));

/// Largest text response accepted (version and checksum files are < 100 bytes).
const MAX_TEXT: u64 = 64 * 1024;

/// HTTP settings. Bases have no trailing `/`.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct HttpConfig {
    /// Where versions live: `<download_base>/<ver>/<file>`.
    pub download_base: String,
    /// Where `NEWESTa7.<channel>` lives.
    pub upgrade_base: String,
    pub connect_timeout: Duration,
    /// Longest silence while reading a response.
    pub read_timeout: Duration,
    /// Largest download accepted (the netinstall tarball is ~46 MB).
    pub max_download_bytes: u64,
}

impl Default for HttpConfig {
    fn default() -> Self {
        Self {
            download_base: urls::DOWNLOAD_BASE.into(),
            upgrade_base: urls::UPGRADE_BASE.into(),
            connect_timeout: Duration::from_secs(15),
            read_timeout: Duration::from_secs(60),
            max_download_bytes: 512 << 20,
        }
    }
}

/// Result of a streamed download.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Downloaded {
    pub size: u64,
    pub sha256: String,
}

pub(crate) struct Http {
    client: Client,
    max: u64,
}

impl Http {
    pub fn new(cfg: &HttpConfig) -> Result<Self, AssetError> {
        let client = Client::builder()
            .user_agent(USER_AGENT)
            .connect_timeout(cfg.connect_timeout)
            .read_timeout(cfg.read_timeout)
            .build()
            .map_err(AssetError::Client)?;
        Ok(Self {
            client,
            max: cfg.max_download_bytes,
        })
    }

    async fn get(&self, url: &str, tail: Option<u64>) -> Result<Response, AssetError> {
        let mut req = self.client.get(url);
        if let Some(n) = tail {
            req = req.header(RANGE, format!("bytes=-{n}"));
        }
        let resp = req.send().await.map_err(|source| AssetError::Network {
            url: url.into(),
            source,
        })?;
        match resp.status() {
            s if s.is_success() => Ok(resp),
            StatusCode::NOT_FOUND => Err(AssetError::NotFound { url: url.into() }),
            s => Err(AssetError::Status {
                url: url.into(),
                status: s.as_u16(),
            }),
        }
    }

    /// Read a whole body of at most `max` bytes.
    async fn body(url: &str, mut resp: Response, max: u64) -> Result<Vec<u8>, AssetError> {
        if resp.content_length().is_some_and(|n| n > max) {
            return Err(AssetError::TooLarge {
                url: url.into(),
                max,
            });
        }
        let mut out = Vec::new();
        while let Some(chunk) = resp.chunk().await.map_err(|source| AssetError::Network {
            url: url.into(),
            source,
        })? {
            if out.len() as u64 + chunk.len() as u64 > max {
                return Err(AssetError::TooLarge {
                    url: url.into(),
                    max,
                });
            }
            out.extend_from_slice(&chunk);
        }
        Ok(out)
    }

    /// A small text file.
    pub async fn text(&self, url: &str) -> Result<String, AssetError> {
        let resp = self.get(url, None).await?;
        let body = Self::body(url, resp, MAX_TEXT).await?;
        Ok(String::from_utf8_lossy(&body).into_owned())
    }

    /// A small text file, or `None` on 404.
    pub async fn optional_text(&self, url: &str) -> Result<Option<String>, AssetError> {
        match self.text(url).await {
            Ok(t) => Ok(Some(t)),
            Err(AssetError::NotFound { .. }) => Ok(None),
            Err(e) => Err(e),
        }
    }

    /// The last `n` bytes of a file and the file's total size. Uses a
    /// `Range` request; a server that ignores it sends the whole file,
    /// which is accepted up to the download limit.
    pub async fn tail(&self, url: &str, n: u64) -> Result<(Vec<u8>, u64), AssetError> {
        let resp = self.get(url, Some(n)).await?;
        if resp.status() == StatusCode::PARTIAL_CONTENT {
            let bad = || AssetError::BadResponse {
                url: url.into(),
                reason: "missing or invalid Content-Range",
            };
            let total = resp
                .headers()
                .get(CONTENT_RANGE)
                .and_then(|v| v.to_str().ok())
                .and_then(|v| v.rsplit_once('/'))
                .and_then(|(_, t)| t.parse::<u64>().ok())
                .ok_or_else(bad)?;
            let body = Self::body(url, resp, n).await?;
            if body.len() as u64 > total {
                return Err(bad());
            }
            Ok((body, total))
        } else {
            let body = Self::body(url, resp, self.max).await?;
            let total = body.len() as u64;
            let start = body.len().saturating_sub(n as usize);
            Ok((body[start..].to_vec(), total))
        }
    }

    /// Stream `url` into `dest` (created or truncated), hashing on the way.
    /// `dest` is removed if the download fails.
    pub async fn download(
        &self,
        url: &str,
        dest: &Path,
        file: &str,
        emit: &dyn Fn(AssetEvent),
    ) -> Result<Downloaded, AssetError> {
        let result = self.download_inner(url, dest, file, emit).await;
        if result.is_err() {
            let _ = tokio::fs::remove_file(dest).await;
        }
        result
    }

    async fn download_inner(
        &self,
        url: &str,
        dest: &Path,
        file: &str,
        emit: &dyn Fn(AssetEvent),
    ) -> Result<Downloaded, AssetError> {
        let mut resp = self.get(url, None).await?;
        let total = resp.content_length();
        if total.is_some_and(|t| t > self.max) {
            return Err(AssetError::TooLarge {
                url: url.into(),
                max: self.max,
            });
        }
        emit(AssetEvent::DownloadStarted {
            file: file.into(),
            total,
        });
        let mut out = tokio::fs::File::create(dest)
            .await
            .map_err(AssetError::io("create", dest))?;
        let mut hasher = Sha256::new();
        let (mut done, mut reported) = (0u64, 0u64);
        while let Some(chunk) = resp.chunk().await.map_err(|source| AssetError::Network {
            url: url.into(),
            source,
        })? {
            done += chunk.len() as u64;
            if done > self.max {
                return Err(AssetError::TooLarge {
                    url: url.into(),
                    max: self.max,
                });
            }
            hasher.update(&chunk);
            out.write_all(&chunk)
                .await
                .map_err(AssetError::io("write", dest))?;
            if done - reported >= PROGRESS_STEP {
                reported = done;
                emit(AssetEvent::DownloadProgress {
                    file: file.into(),
                    done,
                    total,
                });
            }
        }
        if let Some(expected) = total.filter(|&t| t != done) {
            return Err(AssetError::Truncated {
                url: url.into(),
                expected,
                got: done,
            });
        }
        out.sync_all()
            .await
            .map_err(AssetError::io("write", dest))?;
        emit(AssetEvent::DownloadFinished {
            file: file.into(),
            size: done,
        });
        Ok(Downloaded {
            size: done,
            sha256: hex(&hasher.finalize()),
        })
    }
}

//! On-disk cache: one directory per version (plus `local/`), each with a
//! JSON index of the files it holds.
//!
//! ```text
//! <root>/7.25.1/index.json
//! <root>/7.25.1/kernel-arm64.elf
//! <root>/7.25.1/routeros-7.25.1-arm64.npk
//! <root>/local/index.json
//! <root>/local/my-config.rsc
//! ```
//!
//! Files are written to `<name>.part` in the same directory, synced, then
//! renamed, so a crash never leaves a half-written file under its final
//! name. A file whose size or SHA-256 no longer matches its index entry is
//! treated as missing. A missing or unreadable index is treated as empty.

use crate::error::AssetError;
use crate::npk::sha256_hex;
use bytes::Bytes;
use serde::{Deserialize, Serialize};
use std::collections::BTreeMap;
use std::io::Write;
use std::path::{Path, PathBuf};
use std::time::{SystemTime, UNIX_EPOCH};

/// Index file name inside each cache directory.
pub const INDEX_FILE: &str = "index.json";

/// What we know about one cached file.
#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
pub struct Entry {
    pub size: u64,
    /// Lowercase hex SHA-256 of the cached file.
    pub sha256: String,
    /// Where it came from: a download URL, or `file://<path>` for local files.
    pub source: String,
    /// `true` if the downloaded file matched the checksum MikroTik publishes
    /// (`<url>.sha256`); for kernels, the checksum of the tarball they were
    /// carved from.
    pub published_checksum: bool,
    /// Seconds since the Unix epoch.
    pub fetched_at: u64,
}

impl Entry {
    pub fn new(data: &[u8], source: impl Into<String>, published_checksum: bool) -> Self {
        Self {
            size: data.len() as u64,
            sha256: sha256_hex(data),
            source: source.into(),
            published_checksum,
            fetched_at: unix_now(),
        }
    }
}

/// Contents of `index.json`.
#[derive(Debug, Clone, Default, PartialEq, Eq, Serialize, Deserialize)]
pub struct Index {
    #[serde(default)]
    pub files: BTreeMap<String, Entry>,
    /// Extra package names per package architecture.
    #[serde(default)]
    pub package_lists: BTreeMap<String, Vec<String>>,
}

/// Result of looking up a cached file.
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Lookup {
    /// Present and matching its index entry.
    Valid(Bytes),
    /// Not in the index, or the file is gone.
    Missing,
    /// The file differs from its index entry (size or SHA-256).
    Corrupt,
}

/// One cache directory.
#[derive(Debug, Clone)]
pub struct CacheDir {
    dir: PathBuf,
}

impl CacheDir {
    pub fn new(dir: PathBuf) -> Self {
        Self { dir }
    }

    /// Create the directory (and parents) if needed.
    pub fn create(&self) -> Result<(), AssetError> {
        std::fs::create_dir_all(&self.dir).map_err(AssetError::io("create", &self.dir))
    }

    pub fn path(&self, name: &str) -> PathBuf {
        self.dir.join(name)
    }

    /// The index, or an empty one if it is missing or unreadable.
    pub fn load(&self) -> Index {
        std::fs::read(self.path(INDEX_FILE))
            .ok()
            .and_then(|b| serde_json::from_slice(&b).ok())
            .unwrap_or_default()
    }

    pub fn save(&self, index: &Index) -> Result<(), AssetError> {
        let json = serde_json::to_vec_pretty(index).expect("index serializes");
        self.write_atomic(INDEX_FILE, &json)
    }

    /// Write `data` as `name` via `name.part` + rename.
    pub fn write_atomic(&self, name: &str, data: &[u8]) -> Result<(), AssetError> {
        self.create()?;
        let part = self.path(&format!("{name}.part"));
        let write = || -> std::io::Result<()> {
            let mut f = std::fs::File::create(&part)?;
            f.write_all(data)?;
            f.sync_all()
        };
        if let Err(e) = write() {
            let _ = std::fs::remove_file(&part);
            return Err(AssetError::io("write", &part)(e));
        }
        self.commit(&part, name)
    }

    /// Rename a finished `part` file to `name`.
    pub fn commit(&self, part: &Path, name: &str) -> Result<(), AssetError> {
        let dest = self.path(name);
        std::fs::rename(part, &dest).map_err(AssetError::io("rename", &dest))
    }

    /// Read `name` and check it against its index entry.
    pub fn lookup(&self, index: &Index, name: &str) -> Lookup {
        let Some(entry) = index.files.get(name) else {
            return Lookup::Missing;
        };
        let Ok(data) = std::fs::read(self.path(name)) else {
            return Lookup::Missing;
        };
        if data.len() as u64 != entry.size || sha256_hex(&data) != entry.sha256 {
            return Lookup::Corrupt;
        }
        Lookup::Valid(Bytes::from(data))
    }
}

pub(crate) fn unix_now() -> u64 {
    SystemTime::now()
        .duration_since(UNIX_EPOCH)
        .map_or(0, |d| d.as_secs())
}

//! user-supplied files, all behind one cache.

use crate::archive;
use crate::cache::{CacheDir, Entry, Lookup};

use crate::events::{AssetEvent, EventSink};

/// Cache directory name under `~/Library/Caches`.
pub const BUNDLE_ID: &str = "io.github.sepsig.mac-netinstall";

/// `~/Library/Caches/io.github.sepsig.mac-netinstall`, or `None` if `HOME`
/// is not set.
pub fn default_cache_root() -> Option<PathBuf> {
    let home = std::env::var_os("HOME").filter(|h| !h.is_empty())?;
    Some(PathBuf::from(home).join("Library/Caches").join(BUNDLE_ID))
}

/// Cache file name of the boot kernel for `arch`.
pub fn kernel_file_name(arch: BootArch) -> String {
    format!("kernel-{arch}.elf")
}

/// Downloads, verifies and caches everything an install needs.
///
/// Cache-changing operations are serialized by an internal lock, so one
/// `Assets` can be shared (`Arc`) between tasks. Two processes sharing a
/// cache root are not coordinated.
pub struct Assets {
    root: PathBuf,
    http: Http,
    download_base: String,
    upgrade_base: String,
    max_download: u64,
    events: Option<EventSink>,
    lock: Mutex<()>,
}

/// Run blocking file work off the async threads; panics propagate.
async fn blocking<T, F>(f: F) -> T
where
    F: FnOnce() -> T + Send + 'static,
    T: Send + 'static,
{
    match tokio::task::spawn_blocking(f).await {
        Ok(v) => v,
        Err(e) => std::panic::resume_unwind(e.into_panic()),
    }
}

fn check_published(file: &str, published: &Option<String>, actual: &str) -> Result<(), AssetError> {
    match published {
        Some(expected) if expected != actual => Err(AssetError::ChecksumMismatch {
            file: file.into(),
            expected: expected.clone(),
            actual: actual.into(),
        }),
        _ => Ok(()),
    }
}

impl Assets {
    /// An asset manager caching under `root` (created on first write).
    pub fn new(root: impl Into<PathBuf>, cfg: HttpConfig) -> Result<Self, AssetError> {
        Ok(Self {
            root: root.into(),
            http: Http::new(&cfg)?,
            download_base: cfg.download_base.trim_end_matches('/').to_string(),
            upgrade_base: cfg.upgrade_base.trim_end_matches('/').to_string(),
            max_download: cfg.max_download_bytes,
            events: None,
            lock: Mutex::new(()),
        })
    }

    /// Report progress to `sink`.
    pub fn with_events(mut self, sink: EventSink) -> Self {
        self.events = Some(sink);
        self
    }

    pub fn root(&self) -> &Path {
        &self.root
    }

    fn emit(&self, event: AssetEvent) {
        if let Some(sink) = &self.events {
            sink(event);
        }
    }

    fn version_dir(&self, version: &Version) -> CacheDir {
        CacheDir::new(self.root.join(version.as_str()))
    }

    /// The newest version on `channel` (always asks the server).
    pub async fn latest(&self, channel: Channel) -> Result<Release, AssetError> {
        let url = urls::newest(&self.upgrade_base, channel);
        let body = self.http.text(&url).await?;
        parse_newest(&body).ok_or(AssetError::BadResponse {
            url,
            reason: "expected `<version> <timestamp>`",
        })
    }

    /// The version a profile asks for; exact versions need no network.
    pub async fn resolve(&self, spec: &VersionSpec) -> Result<Version, AssetError> {
        match spec {
            VersionSpec::Exact(v) => Ok(v.clone()),
            VersionSpec::Channel(c) => Ok(self.latest(*c).await?.version),
        }
    }

    /// The published SHA-256 of `file` at `url`, `None` if none is published.
    async fn published_checksum(
        &self,
        url: &str,
        file: &str,
    ) -> Result<Option<String>, AssetError> {
        let sum_url = urls::checksum(url);
        match self.http.optional_text(&sum_url).await? {
            None => Ok(None),
            Some(body) => parse_sha256_file(&body, file)
                .map(Some)
                .ok_or(AssetError::BadResponse {
                    url: sum_url,
                    reason: "unexpected checksum file format",
                }),
        }
    }

    /// Boot kernels for every [`BootArch`], from the cache or carved out of
    /// `netinstall-<ver>.tar.gz` (which is not kept).
    pub async fn ensure_kernels(&self, version: &Version) -> Result<KernelSet, AssetError> {
        let _guard = self.lock.lock().await;
        let dir = self.version_dir(version);
        let tarball = urls::tarball_name(version);
        let cached = {
            let dir = dir.clone();
            blocking(move || load_kernels(&dir)).await
        };
        if let Some(set) = cached {
            self.emit(AssetEvent::CacheHit { file: tarball });
            return Ok(set);
        }
        let url = urls::file(&self.download_base, version, &tarball);
        let published = self.published_checksum(&url, &tarball).await?;
        let part = dir.path(&format!("{tarball}.part"));
        {
            let dir = dir.clone();
            blocking(move || dir.create()).await?;
        }
        let got = self
            .http
            .download(&url, &part, &tarball, &|e| self.emit(e))
            .await?;
        blocking(move || {
            let result = (|| {
                check_published(&tarball, &published, &got.sha256)?;
                let file = std::fs::File::open(&part).map_err(AssetError::io("open", &part))?;
                let cli = archive::netinstall_cli_from_tar_gz(BufReader::new(file))?;
                Ok::<_, AssetError>(extract_kernels(&cli)?)
            })();
            let _ = std::fs::remove_file(&part);
            let set = result?;
            let mut index = dir.load();
            for (arch, image) in &set {
                let name = kernel_file_name(*arch);
                dir.write_atomic(&name, image)?;
                index
                    .files
                    .insert(name, Entry::new(image, url.clone(), published.is_some()));
            }
            dir.save(&index)?;
            Ok(set)
        })
        .await
    }
}

/// All kernels of a version from the cache, or `None` if any is missing or
/// damaged.
fn load_kernels(dir: &CacheDir) -> Option<KernelSet> {
    let index = dir.load();
    BootArch::ALL
        .into_iter()
        .map(|arch| match dir.lookup(&index, &kernel_file_name(arch)) {
            Lookup::Valid(data) => Some((arch, data)),
            _ => None,
        })
        .collect()
}

    pub fn with_events(mut self, sink: EventSink) -> Self {
        self.events = Some(sink);
        self
    }

    pub fn root(&self) -> &Path {
        &self.root
    }

    fn emit(&self, event: AssetEvent) {
        if let Some(sink) = &self.events {
            sink(event);
        }
    }

    fn version_dir(&self, version: &Version) -> CacheDir {
        CacheDir::new(self.root.join(version.as_str()))
    }

    /// The newest version on `channel` (always asks the server).
    pub async fn latest(&self, channel: Channel) -> Result<Release, AssetError> {
        let url = urls::newest(&self.upgrade_base, channel);
        let body = self.http.text(&url).await?;
        parse_newest(&body).ok_or(AssetError::BadResponse {
            url,
            reason: "expected `<version> <timestamp>`",
        })
    }

    /// The version a profile asks for; exact versions need no network.
    pub async fn resolve(&self, spec: &VersionSpec) -> Result<Version, AssetError> {
        match spec {
            VersionSpec::Exact(v) => Ok(v.clone()),
            VersionSpec::Channel(c) => Ok(self.latest(*c).await?.version),
        }
    }

    /// The published SHA-256 of `file` at `url`, `None` if none is published.
    async fn published_checksum(
        &self,
        url: &str,
        file: &str,
    ) -> Result<Option<String>, AssetError> {
        let sum_url = urls::checksum(url);
        match self.http.optional_text(&sum_url).await? {
            None => Ok(None),
            Some(body) => parse_sha256_file(&body, file)
                .map(Some)
                .ok_or(AssetError::BadResponse {
                    url: sum_url,
                    reason: "unexpected checksum file format",
                }),
        }
    }

    /// Boot kernels for every [`BootArch`], from the cache or carved out of
    /// `netinstall-<ver>.tar.gz` (which is not kept).
    pub async fn ensure_kernels(&self, version: &Version) -> Result<KernelSet, AssetError> {
        let _guard = self.lock.lock().await;
        let dir = self.version_dir(version);
        let tarball = urls::tarball_name(version);
        let cached = {
            let dir = dir.clone();
            blocking(move || load_kernels(&dir)).await
        };
        if let Some(set) = cached {
            self.emit(AssetEvent::CacheHit { file: tarball });
            return Ok(set);
        }
        let url = urls::file(&self.download_base, version, &tarball);
        let published = self.published_checksum(&url, &tarball).await?;
        let part = dir.path(&format!("{tarball}.part"));
        {
            let dir = dir.clone();
            blocking(move || dir.create()).await?;
        }
        let got = self
            .http
            .download(&url, &part, &tarball, &|e| self.emit(e))
            .await?;
        blocking(move || {
            let result = (|| {
                check_published(&tarball, &published, &got.sha256)?;
                let file = std::fs::File::open(&part).map_err(AssetError::io("open", &part))?;
                let cli = archive::netinstall_cli_from_tar_gz(BufReader::new(file))?;
                Ok::<_, AssetError>(extract_kernels(&cli)?)
            })();
            let _ = std::fs::remove_file(&part);
            let set = result?;
            let mut index = dir.load();
            for (arch, image) in &set {
                let name = kernel_file_name(*arch);
                dir.write_atomic(&name, image)?;
                index
                    .files
                    .insert(name, Entry::new(image, url.clone(), published.is_some()));
            }
            dir.save(&index)?;
            Ok(set)
        })
        .await
    }
}

/// All kernels of a version from the cache, or `None` if any is missing or
/// damaged.
fn load_kernels(dir: &CacheDir) -> Option<KernelSet> {
    let index = dir.load();
    BootArch::ALL
        .into_iter()
        .map(|arch| match dir.lookup(&index, &kernel_file_name(arch)) {
            Lookup::Valid(data) => Some((arch, data)),
            _ => None,
        })
        .collect()
}

//! Packages: the extra-package list and `.npk` downloads.

use super::{blocking, check_published, Assets};
use crate::arch::PkgArch;
use crate::archive::{self, ArchiveError};
use crate::cache::{unix_now, CacheDir, Entry, Lookup};
use crate::error::AssetError;
use crate::events::AssetEvent;
use crate::npk::{check_npk, package_names, valid_package_name};
use crate::urls::{self, MAIN_PACKAGE};
use crate::version::Version;
use bytes::Bytes;
use ni_proto::PlanFile;

/// Bytes fetched from the end of `all_packages-*.zip` to read its directory.
const ZIP_TAIL: u64 = 64 * 1024;
/// Largest ZIP central directory we are willing to fetch.
const MAX_ZIP_DIRECTORY: u64 = 4 << 20;

impl Assets {
    /// Names of the extra packages published for `arch` (e.g. `wireless`,
    /// `container`), read from the directory of `all_packages-<arch>-<ver>.zip`
    /// with a ranged request and cached. The main `routeros` package is not
    /// listed.
    pub async fn available_packages(
        &self,
        version: &Version,
        arch: PkgArch,
    ) -> Result<Vec<String>, AssetError> {
        let _guard = self.lock.lock().await;
        self.package_list(version, arch).await
    }

    async fn package_list(
        &self,
        version: &Version,
        arch: PkgArch,
    ) -> Result<Vec<String>, AssetError> {
        let dir = self.version_dir(version);
        let mut index = dir.load();
        if let Some(list) = index.package_lists.get(arch.as_str()) {
            return Ok(list.clone());
        }
        let url = urls::file(
            &self.download_base,
            version,
            &urls::all_packages_name(version, arch),
        );
        let (tail, total) = self.http.tail(&url, ZIP_TAIL).await?;
        let entries = match archive::zip_entry_names(&tail, total) {
            Err(ArchiveError::NeedMore { needed }) if needed <= MAX_ZIP_DIRECTORY => {
                let (tail, total) = self.http.tail(&url, needed).await?;
                archive::zip_entry_names(&tail, total)?
            }
            other => other?,
        };
        let names = package_names(&entries, version.as_str(), arch.as_str());
        index
            .package_lists
            .insert(arch.as_str().to_string(), names.clone());
        blocking(move || dir.save(&index)).await?;
        Ok(names)
    }

    /// The main `routeros` package followed by `extras` (duplicates and
    /// `routeros` itself ignored), verified and ready for
    /// [`ni_proto::InstallPlan::packages`]. Each [`PlanFile::name`] is the
    /// package file name, e.g. `routeros-7.25.1-arm64.npk`.
    pub async fn ensure_packages(
        &self,
        version: &Version,
        arch: PkgArch,
        extras: &[String],
    ) -> Result<Vec<PlanFile>, AssetError> {
        if let Some(bad) = extras.iter().find(|n| !valid_package_name(n)) {
            return Err(AssetError::InvalidPackageName(bad.clone()));
        }
        let mut names = vec![MAIN_PACKAGE.to_string()];
        for name in extras {
            if !names.contains(name) {
                names.push(name.clone());
            }
        }
        let _guard = self.lock.lock().await;
        if names.len() > 1 {
            let available = self.package_list(version, arch).await?;
            if let Some(missing) = names[1..].iter().find(|n| !available.contains(n)) {
                return Err(AssetError::UnknownPackage {
                    name: missing.clone(),
                    arch,
                });
            }
        }
        let dir = self.version_dir(version);
        let mut files = Vec::with_capacity(names.len());
        for name in names {
            let file = urls::package_file_name(&name, version, arch);
            let data = self.ensure_npk(&dir, version, &file).await?;
            files.push(PlanFile { name: file, data });
        }
        Ok(files)
    }

    async fn ensure_npk(
        &self,
        dir: &CacheDir,
        version: &Version,
        file: &str,
    ) -> Result<Bytes, AssetError> {
        let lookup = {
            let (dir, file) = (dir.clone(), file.to_string());
            blocking(move || dir.lookup(&dir.load(), &file)).await
        };
        if let Lookup::Valid(data) = lookup {
            self.emit(AssetEvent::CacheHit { file: file.into() });
            return Ok(data);
        }
        let url = urls::file(&self.download_base, version, file);
        let published = self.published_checksum(&url, file).await?;
        {
            let dir = dir.clone();
            blocking(move || dir.create()).await?;
        }
        let part = dir.path(&format!("{file}.part"));
        let got = self
            .http
            .download(&url, &part, file, &|e| self.emit(e))
            .await?;
        let (dir, file) = (dir.clone(), file.to_string());
        blocking(move || {
            let result = (|| {
                check_published(&file, &published, &got.sha256)?;
                let data = std::fs::read(&part).map_err(AssetError::io("read", &part))?;
                check_npk(&file, &data)?;
                dir.commit(&part, &file)?;
                let mut index = dir.load();
                let entry = Entry {
                    size: got.size,
                    sha256: got.sha256,
                    source: url,
                    published_checksum: published.is_some(),
                    fetched_at: unix_now(),
                };
                index.files.insert(file.clone(), entry);
                dir.save(&index)?;
                Ok(Bytes::from(data))
            })();
            if result.is_err() {
                let _ = std::fs::remove_file(&part);
            }
            result
        })
        .await
    }
}

/// Cache file name of the boot kernel for `arch`.
pub fn kernel_file_name(arch: BootArch) -> String {
    format!("kernel-{arch}.elf")

/// Downloads, verifies and caches everything an install needs.
///
/// Cache-changing operations are serialized by an internal lock, so one
/// `Assets` can be shared (`Arc`) between tasks. Two processes sharing a
/// cache root are not coordinated.
pub struct Assets {
    root: PathBuf,
    http: Http,
    download_base: String,
    upgrade_base: String,
    max_download: u64,
    events: Option<EventSink>,
    lock: Mutex<()>,
}

/// Run blocking file work off the async threads; panics propagate.
async fn blocking<T, F>(f: F) -> T
where
    F: FnOnce() -> T + Send + 'static,
    T: Send + 'static,
{
    match tokio::task::spawn_blocking(f).await {
        Ok(v) => v,
        Err(e) => std::panic::resume_unwind(e.into_panic()),
    }
}

fn check_published(file: &str, published: &Option<String>, actual: &str) -> Result<(), AssetError> {
    match published {
        Some(expected) if expected != actual => Err(AssetError::ChecksumMismatch {
            file: file.into(),
            expected: expected.clone(),
            actual: actual.into(),
        }),
        _ => Ok(()),
    }
}

impl Assets {
    /// An asset manager caching under `root` (created on first write).
    pub fn new(root: impl Into<PathBuf>, cfg: HttpConfig) -> Result<Self, AssetError> {
        Ok(Self {
            root: root.into(),
            http: Http::new(&cfg)?,
            download_base: cfg.download_base.trim_end_matches('/').to_string(),
            upgrade_base: cfg.upgrade_base.trim_end_matches('/').to_string(),
            max_download: cfg.max_download_bytes,
            events: None,
            lock: Mutex::new(()),
        })
    }

    /// Report progress to `sink`.
    pub fn with_events(mut self, sink: EventSink) -> Self {
        self.events = Some(sink);
        self
    }

    pub fn root(&self) -> &Path {
        &self.root
    }

    fn emit(&self, event: AssetEvent) {
        if let Some(sink) = &self.events {
            sink(event);
        }
    }

    fn version_dir(&self, version: &Version) -> CacheDir {
        CacheDir::new(self.root.join(version.as_str()))
    }

    /// The newest version on `channel` (always asks the server).
    pub async fn latest(&self, channel: Channel) -> Result<Release, AssetError> {
        let url = urls::newest(&self.upgrade_base, channel);
        let body = self.http.text(&url).await?;
        parse_newest(&body).ok_or(AssetError::BadResponse {
            url,
            reason: "expected `<version> <timestamp>`",
        })
    }

    /// The version a profile asks for; exact versions need no network.
    pub async fn resolve(&self, spec: &VersionSpec) -> Result<Version, AssetError> {
        match spec {
            VersionSpec::Exact(v) => Ok(v.clone()),
            VersionSpec::Channel(c) => Ok(self.latest(*c).await?.version),
        }
    }

    /// The published SHA-256 of `file` at `url`, `None` if none is published.
    async fn published_checksum(
        &self,
        url: &str,
        file: &str,
    ) -> Result<Option<String>, AssetError> {
        let sum_url = urls::checksum(url);
        match self.http.optional_text(&sum_url).await? {
            None => Ok(None),
            Some(body) => parse_sha256_file(&body, file)
                .map(Some)
                .ok_or(AssetError::BadResponse {
                    url: sum_url,
                    reason: "unexpected checksum file format",
                }),
        }
    }

    /// Boot kernels for every [`BootArch`], from the cache or carved out of
    /// `netinstall-<ver>.tar.gz` (which is not kept).
    pub async fn ensure_kernels(&self, version: &Version) -> Result<KernelSet, AssetError> {
        let _guard = self.lock.lock().await;
        let dir = self.version_dir(version);
        let tarball = urls::tarball_name(version);
        let cached = {
            let dir = dir.clone();
            blocking(move || load_kernels(&dir)).await
        };
        if let Some(set) = cached {
            self.emit(AssetEvent::CacheHit { file: tarball });
            return Ok(set);
        }
        let url = urls::file(&self.download_base, version, &tarball);
        let published = self.published_checksum(&url, &tarball).await?;
        let part = dir.path(&format!("{tarball}.part"));
        {
            let dir = dir.clone();
            blocking(move || dir.create()).await?;
        }
        let got = self
            .http
            .download(&url, &part, &tarball, &|e| self.emit(e))
            .await?;
        blocking(move || {
            let result = (|| {
                check_published(&tarball, &published, &got.sha256)?;
                let file = std::fs::File::open(&part).map_err(AssetError::io("open", &part))?;
                let cli = archive::netinstall_cli_from_tar_gz(BufReader::new(file))?;
                Ok::<_, AssetError>(extract_kernels(&cli)?)
            })();
            let _ = std::fs::remove_file(&part);
            let set = result?;
            let mut index = dir.load();
            for (arch, image) in &set {
                let name = kernel_file_name(*arch);
                dir.write_atomic(&name, image)?;
                index
                    .files
                    .insert(name, Entry::new(image, url.clone(), published.is_some()));
            }
            dir.save(&index)?;
            Ok(set)
        })
        .await
    }
}

/// All kernels of a version from the cache, or `None` if any is missing or
/// damaged.
fn load_kernels(dir: &CacheDir) -> Option<KernelSet> {
    let index = dir.load();
    BootArch::ALL
        .into_iter()
        .map(|arch| match dir.lookup(&index, &kernel_file_name(arch)) {
            Lookup::Valid(data) => Some((arch, data)),
            _ => None,
        })
        .collect()
}

//! User-supplied files and cache maintenance.

use super::{blocking, Assets};
use crate::cache::{CacheDir, Entry, Lookup};
use crate::error::AssetError;
use crate::npk::check_npk;
use crate::version::Version;
use bytes::Bytes;
use std::path::Path;

/// Largest local `.rsc` script accepted.
pub const MAX_SCRIPT_SIZE: u64 = 1 << 20;
/// Cache subdirectory for user-supplied files.
const LOCAL_DIR: &str = "local";

/// Kind of a user-supplied file, from its extension.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum LocalKind {
    /// `.npk`: a RouterOS package.
    Package,
    /// `.rsc`: a RouterOS configuration script.
    Script,
}

/// A registered user-supplied file.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct LocalFile {
    pub name: String,
    pub kind: LocalKind,
    pub size: u64,
    pub sha256: String,
}

impl Assets {
    /// Copy a user-supplied `.npk` (checked like a download) or `.rsc`
    /// (at most [`MAX_SCRIPT_SIZE`]) into the cache under its file name,
    /// replacing an earlier file of the same name.
    pub async fn register_local_file(&self, path: &Path) -> Result<LocalFile, AssetError> {
        let name = path
            .file_name()
            .and_then(|n| n.to_str())
            .unwrap_or_default()
            .to_string();
        let kind = match name.rsplit_once('.') {
            Some((stem, "npk")) if !stem.is_empty() => LocalKind::Package,
            Some((stem, "rsc")) if !stem.is_empty() => LocalKind::Script,
            _ => return Err(AssetError::UnsupportedLocalFile { name }),
        };
        if name.starts_with('.') || name.contains('\n') || name.len() > 255 {
            return Err(AssetError::UnsupportedLocalFile { name });
        }
        let max = match kind {
            LocalKind::Package => self.max_download,
            LocalKind::Script => MAX_SCRIPT_SIZE,
        };
        let _guard = self.lock.lock().await;
        let dir = CacheDir::new(self.root.join(LOCAL_DIR));
        let path = path.to_path_buf();
        blocking(move || {
            let len = std::fs::metadata(&path)
                .map_err(AssetError::io("read", &path))?
                .len();
            if len > max {
                return Err(AssetError::LocalFileTooLarge { name, max });
            }
            let data = std::fs::read(&path).map_err(AssetError::io("read", &path))?;
            if kind == LocalKind::Package {
                check_npk(&name, &data)?;
            }
            let entry = Entry::new(&data, format!("file://{}", path.display()), false);
            dir.write_atomic(&name, &data)?;
            let mut index = dir.load();
            index.files.insert(name.clone(), entry.clone());
            dir.save(&index)?;
            Ok(LocalFile {
                name,
                kind,
                size: entry.size,
                sha256: entry.sha256,
            })
        })
        .await
    }

    /// The contents of a registered local file, verified.
    pub async fn local_file(&self, name: &str) -> Result<Bytes, AssetError> {
        let _guard = self.lock.lock().await;
        let dir = CacheDir::new(self.root.join(LOCAL_DIR));
        let key = name.to_string();
        match blocking(move || dir.lookup(&dir.load(), &key)).await {
            Lookup::Valid(data) => Ok(data),
            Lookup::Missing => Err(AssetError::LocalMissing { name: name.into() }),
            Lookup::Corrupt => Err(AssetError::LocalCorrupt { name: name.into() }),
        }
    }

    /// Delete all downloaded versions (directories named like a version);
    /// registered local files are kept.
    pub async fn clear_downloads(&self) -> Result<(), AssetError> {
        let _guard = self.lock.lock().await;
        let root = self.root.clone();
        blocking(move || {
            let entries = match std::fs::read_dir(&root) {
                Ok(e) => e,
                Err(e) if e.kind() == std::io::ErrorKind::NotFound => return Ok(()),
                Err(e) => return Err(AssetError::io("read", &root)(e)),
            };
            for entry in entries.flatten() {
                let path = entry.path();
                let is_version = entry
                    .file_name()
                    .to_str()
                    .is_some_and(|n| Version::parse(n).is_ok());
                if is_version && path.is_dir() {
                    std::fs::remove_dir_all(&path).map_err(AssetError::io("remove", &path))?;
                }
            }
            Ok(())
        })
        .await
    }
}

    assert_eq!(set.len(), 8);
    for (arch, size, sha) in KERNELS_7_25_1 {

}

fn temp_root(tag: &str) -> PathBuf {

    dir
}

  7.12.1 and older have none (404). `ni-assets` verifies against it when present and records

- 7.25.1 kernels carve to: mips 5256784, mmips 5358860, powerpc 5486936, e500 6119156,
  ppc440 5709072, arm 3501676, arm64 7838328, tile 4680160 bytes (SHA-256s in
  `crates/ni-assets/tests/network.rs`).
